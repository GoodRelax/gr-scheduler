# Contributing

English | [日本語](#日本語)

Thank you for trying GoodRelax Scheduler (GRS).

## Issues are welcome

Please open an issue in [GitHub Issues](https://github.com/GoodRelax/gr-scheduler/issues), in English or Japanese.

To report a bug, please write:

1. the steps that lead to it,
2. what you saw,
3. what you expected to see,
4. the version you used (it is shown on the download page).

A screenshot or the file you were working on helps a lot, if you can share it.

## Pull requests: not yet

During the alpha, pull requests are not accepted yet. The design is still moving quickly, and changes are made against the specification first. Ideas and bug reports in issues are the best way to help for now.

## For developers

How this project is built (the rules, the checks and the order of work) is in [docs/development-rules/](docs/development-rules/). The specification's source is [docs/spec/_source](docs/spec/_source).

## 日本語

GoodRelax Scheduler（GRS）を試していただき、ありがとうございます。

### Issue は歓迎します

[GitHub Issues](https://github.com/GoodRelax/gr-scheduler/issues) に、日本語か英語で書いてください。

不具合を報告するときは、次を書いてください。

1. そこに至る手順
2. 見えたこと
3. 本来はどうなってほしかったか
4. 使った版（ダウンロードページに出ています）

画面のスクリーンショットや、作業していたファイルを共有していただけると、とても助かります。

### プルリクエスト: まだ受け付けていません

α 版のあいだは、プルリクエストはまだ受け付けていません。設計がまだ大きく動いていて、変更はまず仕様に対して行うためです。いまは Issue での要望や不具合の報告がいちばんの助けになります。

### 開発する人へ

このプロジェクトの作り方（規則・検査・作業の順）は [docs/development-rules/](docs/development-rules/) にあります。仕様の原稿は [docs/spec/_source](docs/spec/_source) にあります。
