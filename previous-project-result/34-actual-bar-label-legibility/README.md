## 開き方と触り方

| したいこと | すること |
|---|---|
| 案を見比べる | 左のペインを見る。1 行が 1 案、いちばん上が「現状」。列は表示の倍率 50 / 75 / 100 / 150 / 200（字 4.5 / 6.75 / 9 / 13.5 / 18px） |
| テーマを替える | 上の「明るい ／ 暗い」。URL に `?theme=dark` か `#dark` を足しても替わる |
| 自分で値を動かす | 右のペインのスライダー 17 本。最後の行「自分の案」だけが動く。「この案の値を写す」で、どれかの案から始められる。縁取りの割合・不透明度・字の太さ・反転の入り切り・色相は両テーマに、色の明度と彩度（字・縁取り・反転字・実績・予定）はいま見ているテーマの側だけに掛かる |
| 値を伝える | 右下の灰色の塊をそのまま貼る |
| ペインの幅 | 2 つのペインのあいだの棒を引く |

各行の左には、その案の色から WCAG 2.1 の式で求めた比を出している（赤は、字なら 4.5 : 1、形なら 3 : 1 を割るもの）。

## 測ったこと

### 1. 色どうしの比（WCAG 2.1 の式）

HSL を 8 ビットの sRGB へ丸め、相対輝度 L から (L1 + 0.05) ÷ (L2 + 0.05) を求めた。

| | 明るい | 暗い |
|---|---|---|
| 字 : 実績の塗り | **2.59** | **2.84** |
| 字 : 予定の塗り | 12.43 | 10.70 |
| 字 : 縁取り | 21.00 | 17.99 |
| 縁取り : 実績の塗り | 8.11 | 6.34 |

字と実績の塗りは、両テーマとも 4.5 : 1 どころか 3 : 1 も割る。読めるかどうかを縁取りが一人で担っている。

### 2. 画面に届いた画素（掃引）

**方法**: Playwright（Edge）で開き、1 つ目のタスクの名称ラベルの箱を、実績バーの内側（線を 1px 除く）と重なる所だけ切り取って撮る。撮った PNG をページの canvas に戻して全画素の相対輝度を出し、暗い側から 2% と明るい側から 2% の画素を取って、それぞれを実績の塗りと WCAG の式で比べた。「字の芯 : 実績」は、字の色の側（明るいテーマの黒字なら暗い側、反転した白字なら明るい側）の値である。画素の倍率（deviceScaleFactor）は 1 と 2。

**較正**: 出荷ビルド（`dist/index.html`、`0c215684`）の、パレットの半透明の面に覆われていない最初のラベル（`task-4`「Planning phase」。`elementFromPoint` で覆いが無いことを確かめた）を同じ方法で測り、見本の「現状」に同じ字を描かせて比べた。

| | 明・×1 | 明・×2 | 暗・×1 | 暗・×2 |
|---|---|---|---|---|
| 出荷ビルド（暗い 2% : 実績 ／ 明るい 2% : 実績 ／ 両者） | 1.68 / 4.92 / 8.29 | 2.59 / 5.74 / 14.86 | 1.48 / 2.69 / 3.98 | 2.11 / 2.84 / 6.00 |
| 見本の現状、同じ字 | 1.91 / 5.37 / 10.24 | 2.59 / 5.74 / 14.86 | 1.58 / 2.78 / 4.40 | 2.11 / 2.84 / 6.00 |

×2 では小数 2 桁まで一致する。利用者が `file://` で開くルートの作業木の `dist/index.html`（2026-10-03 の時点で、本フォルダーを作った作業木の dist とはファイルが違う）でも、ラベルの値（黒字・白い縁取り 0.45px・9px・太さ 600・実績 `hsl(214 62% 34%)`）と上の表の 4 つの数は同じであった。×1 は 1 割ほどずれる —— 字を置く位置の端数（出荷ビルドは x = 803.75）が違い、1 画素に何が混ざるかが変わるためである。

⚠️ 最初の測りは、パレットの面の下にあるラベル（`task-3`「Research phase」）を測ってしまい、出荷ビルドの比が実際より低く出た。⛔ 実物の字を測るときは、覆いが無いことを確かめてから測れ。

**縁取りが画面に届いた量**（明るいテーマ、画素の倍率 1、表示の倍率 100。「明るい 2% : 実績」）: 現状 6.94、A 8.11、B 4.80、F 8.11。

**縁取りの面の広さ**（明るいテーマ、画素の倍率 1。ラベルの箱のうち実績の塗りより 2 : 1 以上明るい画素の割合。列は倍率 50 / 75 / 100 / 150 / 200）: 現状 54 / 62 / 47 / 45 / 40%、A 83 / 80 / 63 / 61 / 61%、F 87 / 87 / 66 / 69 / 72%。⚠️ 案 D の数（90 / 78 / 66 / 58 / 49%）は白い字そのものを数えているので、縁の広さではない。

## 何が効いているか

| 疑ったもの | 測った結果 | 効くか |
|---|---|---|
| 縁取りの割合（`S-34`） | 0.05 → 0.15 にしても、字の芯 : 実績は 1 つも上がらない（1.95 → 1.75）。上がるのは字の周りの白い縁だけ（6.94 → 8.11）で、字は「白い縁取りの中の暗い字」になる —— これまでの裁定が嫌った白抜きである | 字そのものには効かない |
| 縁取りの色 | 予定の塗りにすると、縁は柔らかくなるが、縁 : 実績が 8.11 → 4.80 に下がる | 効かない（弱める） |
| 縁取りの不透明度 | 1 より下げると縁 : 実績が下がるだけ | 効かない（弱める） |
| 字の太さ（`S-245`） | 600 → 700 で、字の芯 : 実績は変わらない（1.95 → 1.95） | 効かない |
| 字の色（`S-168`） | 実績の上だけ反転すると 2.59 → 8.11（暗 2.84 → 7.40） | **効く** |
| 実績の塗りの明度（`S-157`） | 34% → 50% で黒字 2.59 → 4.57。ただし実績 : 予定が 4.80 → 2.72 に落ち、3 : 1 を割る。暗いテーマは 3.77 → 2.33 | 効くが、予定と実績の見分けを壊す |

**原因**: 字の色（`S-168` の黒）と実績の塗り（`S-157` の濃い青）の比が 2.59 : 1 しかない。縁取りがそれを補っていたが、`JDG-147` と `JDG-856` で 0.17 → 0.05 まで細くなり、表示の倍率 100 で字の外に 0.225px しか出ない。1 画素に満たない縁は字の輪郭を少し白く濁らせるだけで、字の芯は画面で 1.95 : 1 しか出ない（暗いテーマは 2.80 : 1 なので、明るいほうがより読みにくい —— 細い黒い線が濃い青に沈むため）。

縁取りの割合を上げれば字は「縁で」読めるようになるが、それは以前に白抜きとして退けた姿に戻ることであり、字の芯は暗いままである。

## 案

| 案 | 変える値 | 何が良く、何が悪いか |
|---|---|---|
| 現状 | — | 字 : 実績 2.59 |
| A | `S-34` 0.05 → 0.15 | 縁で読める。字の芯は暗いまま。縮めたときの白抜きが戻る |
| B | `S-34` 0.15、`S-169` を予定の塗りに | A より柔らかいが、縁が実績に対して 4.80 に下がる |
| C | `S-157` の明度 明 34 → 50 ／ 暗 64 → 50 | 黒字が 4.57 に届くが、実績と予定の見分けが 3 : 1 を割る |
| D | 実績の上に掛かる部分だけ、字を反転色（明: 白、暗: 黒）で描く。外は今のまま | 両テーマ・全倍率で最もよく読める（7.94 ／ 6.33、倍率 100）。字が実績の端を越えると、途中で色が替わる |
| E | `S-245` 600 → 700 | 字の芯は変わらない |
| F | `S-34` 0.05 → 0.30（範囲の上限） | 倍率 100 以上では、白い縁が字の周りを埋めて白地の上の黒字として読める。倍率 50・75 ではラベルの面の 87% が白くなる。同じ値を読む担当・進捗の札と期限の印の縁も 6 倍の太さになる |

## 決まったこと

⭐ **案 F —— `S-34` を 0.05 → 0.30 にする**（`JDG-1170`、2026-10-03）。利用者は倍率 50・75 を画素 1 倍で描いて 4 倍に拡げた絵（[`zoom4-small-scales-light.png`](zoom4-small-scales-light.png)・[`zoom4-small-scales-dark.png`](zoom4-small-scales-dark.png)）を見たうえで、「いったん、0.30でやってみよう。  これなら変化点は最小だろ？」と答えた。試す値なので、出荷ビルドで見て詰め直す。不具合の行は `DFC-1750`。

- 変える仕様: 表 T-201 の `S-34`（`docs/spec/_source/settings.json`）の既定と注。src は `npm run gen` で `document-settings.ts:269` が変わる。
- 一緒に変わるもの（設定の行は増やさない）: 名称ラベル（`schedule-task-figures.ts:647`）、担当・進捗の札（同 `:663`）、期限の印の縁（`task-figures.ts:618`、表 T-304 の `DA-3`）。
- 覆す裁定: `JDG-856`（0.10 → 0.05）と `JDG-147`（0.17 → 0.10）の「細くする」。
- 採らなかった案: D（実績の上だけ字を反転）。測った数では最もよく読めるが、利用者は値 1 つの変更を選んだ。
