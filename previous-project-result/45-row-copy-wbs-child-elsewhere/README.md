# 45 行を写して貼るとき、WBS の子が別の行に居る場合の見本（2026-10-08）

⭐ **台帳の `DFC-1240`（裁定待ちだった行）を利用者に問うために作った見本である。**
行見出しで行を写して貼る（Ctrl+C → Ctrl+V、`CM-28`）とき、その行のタスクの WBS の子が別の行に載っていると、いまは貼り付けを断る（表 T-223 の `DU-2` が子の写しを載せる行を定めていない）。
場面は「1 回目の工程の行を写して 2 回目を作る」とし、案ごとに貼った後の日程表を並べた。
裁定は `JDG-1631`「案3でいいんじゃない？ …」 —— 写すのは選んだ行に載るタスクだけで、別の行の WBS の子孫は写さない。

⚠️ 問いの途中で、利用者は行の写しを変更前の予定（`IC-4`）の機能と取り違えていた。本見本の「参考」の絵は、そのときの問い「シンプルにタスクの uid で紐づけたらどうなるの？」に答えるために足した。

| ファイル | 中身 |

| `index.html` | 1 ファイルの見本（外部の読み込み無し）。6 枚の絵を並べる |

## 開き方

`index.html` をブラウザで開く（`file://` でよい。サーバーは要らない）。

## 6 枚の絵

| 絵 | 中身 |
|---|---|
| 写す前 | 行「1 回目」にタスク「1 回目 まとめ」、その WBS の子「資料作成」は行「資料」 |
| いま: 断る | 貼っても何も起きない |
| 案 1 | 子の写しも、貼った行に一緒に置く |
| 案 2 | 子の写しは、子の元の行「資料」に置く |
| 案 3（採った） | 別の行に居る子は写さない |
| 参考 | 写しが元の「資料作成」を UID で子に取ると、WBS の親は 1 つなので元から子を奪う |

点線の矢印は WBS の親 → 子、桃色の枠は貼り付けで新しくできたタスク（新しい UID）。写しは見分けやすいよう右へずらして描いた（日付の扱いはこの問いと関係しない）。
