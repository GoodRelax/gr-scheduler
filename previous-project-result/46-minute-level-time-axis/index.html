46 分単位の時間軸の見本

ズーム（1 時間の幅）

ホイール = 左右へ送る ／ Ctrl + ホイール = ズーム ／ 空き地を引く = 送る ／ 棒の中ほどを引く = 動かす ／ 棒の両端を引く = 開始・終了を変える ／ Alt を押しながら引く = 1 分刻み

表示

オフ: ズームしても日の列だけ（今の GRS と同じ見た目・寄せは日）。オン: ズームすると「時」の段、30 分の点線と毎正時の実線を出す。日時はどちらでも時刻まで読む。

基準のタイムゾーン

時刻を一斉にずらす（タイムシフト）

すべてのタスクの日時を同じ時間だけ動かす。暦は動かさない。PDT → JST を「瞬間を保つ」で変えたあと -16 時間ずらすと、「数字を保つ」で変えたのと同じ数字に戻る（夏時間の間。11/1 以降の PST は -17 時間）。

表示するタイムゾーン（最大 4）

時刻を表示するときだけ、目盛りの下に段を足す。
