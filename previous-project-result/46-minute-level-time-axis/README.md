## 触れるもの

| 所 | 中身 |
|---|---|
| ズーム | スライダー・[−] ／ [+]・Ctrl ＋ ホイール。上の行に「1 時間 ＝ ○px」と、いまの GRS の最大（1 時間 16px）を出す |
| [☰] 時刻を表示する | オフ: 棒は日の列で描き、目盛りは日まで、寄せは日（今の GRS と同じ見た目）。オン: ズームすると「時」の段と、30 分の点線・毎正時の実線 |
| 基準のタイムゾーン | 「瞬間を保つ（数字を書き換える）」と「数字を保つ（瞬間が動く）」。瞬間を保つときは「暦の稼働時間も同じ瞬間へ移す」を選べる |
| タイムシフト | すべてのタスクの日時を ±N 時間ずらす。暦は動かさない |
| 表示するタイムゾーン | 4 つまで。目盛りの下に段を足し、表に列を足す。選択肢は `JDG-1712` の 28 個（「(UTC+09:00) 東京」の形で見せ、値は地域名） |
| 棒を引く | 中ほど ＝ 動かす、両端 ＝ 開始・終了。寄せは日 ／ 1 時間 ／ 30 分（ズームで変わる）、Alt で 1 分 |
| 表 | 基準の開始・終了、稼働時間での所要、MSPDI の `Duration`、表示するゾーンでの日時。稼働時間の外のタスクは赤 |

## 最初の日程

基準は `America/Los_Angeles`（PDT）。暦は月〜金 08:00-12:00・13:00-17:00。タスクは 2026-10-28（水）〜11-03（火）の 6 件（打合せ・作業A・確認・節目・作業B・作業C）。米国の夏時間は 2026-11-01 に終わるので、11/2 以降は PST になる。

## 見本だけの決めごと（仕様ではない）

- しきい値（「時」の段は 1 時間 12px 以上、30 分の点線は 30 分 6px 以上）とズームの最大（1 時間 120px）は仮の値で、設定パネルで変えられる。
- 「暦も同じ瞬間へ移す」は、暦の時刻を元の地域の時刻のまま読むことで見せている。実物では、新しい基準の時刻に書き直すと日をまたぐ時間帯を曜日ごとに切り直す必要がある。
- 棒を動かすと、開始と終了の間の経過時間を保つ（稼働時間を保つかは決めていない）。
- Undo は無い。[最初に戻す] で戻る。
