# 44 依存線の続きの印が描ける範囲の外に出るときの見本（2026-10-08）

⭐ **台帳の `DFC-1460`（束 2026-10-07 の問 5）を利用者に問うために作った、触れる見本である。**
最上段に描かれた行のタスクから、隠した行のタスクへ向かう依存線の「続きの印」（3 つの点、表 T-303 の `EL-9`）が、`Row Area` の上端より上に出て見えず押せない件を、4 つの描き方で並べた。
裁定は `JDG-1604`「今のまま（既知の限界）」 —— 利用者は 1 つ目の答えで「押せる範囲だけ広げる」「内側に折り返す」の意味を問い、本見本を見てから決めた。

## 開き方

`index.html` をブラウザで開く（`file://` でよい。サーバーは要らない）。

## 4 枚の絵

| 絵 | 描き方 |
|---|---|
| 今: 2 点が切れる | 短い線は上へ折れ（`EL-7`）、3 点のうち上の 2 点は時間軸の側に出て描かれず押せない |
| 案 A 押せる範囲だけ広げる | 描き方は「今」と同じ。点が在るはずの所（時間軸の帯の下端）を押しても線が選ばれる |
| 案 B 横へ折り返す | 上へ曲がる場所が無いときだけ、`EL-8` の横の形（右へ伸ばし点を横に 3 つ） |
| 案 C 上向きのまま縮める | 上へ進む短い線を描ける所まで縮め、3 点を `Row Area` の上端の内側に収める |

点（または点が在るはずの所）を押すと線が選ばれて太くなり、白い所を押すと外れる。上の「押して当たる範囲を桃色の破線で見せる」で当たり判定の範囲を見せる。

## 寸法

表示の倍率 100 の値で描き、SVG を枠の幅まで拡大している —— 出口の走り 6（`S-298`）、縦の短い線 6（`S-360`）、点の径と間 2（`S-362`）、横の短い線 12（`S-361`）。行の高さ 24、バーの高さ 12 を行の中央に置いた模型であり、出荷版の行の高さとは限らない。
