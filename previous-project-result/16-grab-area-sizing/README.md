# 掴み代の大きさ —— 数を触って決めるための見本

- 日付: 2026-09-18
- 見本: [`grab-area-sizing-sample.html`](grab-area-sizing-sample.html)
  （**1 ファイルで完結。ダブルクリックすれば開く。** サーバーも通信も外部の書体も要らない）

⛔ **これは仕様書ではない。** 数を決めるための素描である。
⭐ **13-grab-areas が「どこを掴めるか」を決めた見本**であるのに対し、本書は **「どれだけの広さで掴めるか」を決める**ためのものである。

## 何ができるか

- **触れる。** バーの本体を引けば横に動き、端を引けば伸び縮みする。マイルストーンも矢印のタスクも引ける。日の単位に吸い付く。
- **フェードは形ごと追従する。** □ を引くと、掴み点と一緒に予定バーの角が動き、表 T-012a の `FD-1` どおりの台形になる（`GR-1` は左上の点 4、`GR-2` は右下の点 2）。
- **札の置き方は「入るなら開始から、入らないなら終了から」**（2026-09-18 の利用者の案）。実績があれば実績の幅で、無ければ予定の幅で判じる。マイルストーンは図形の中心から。図の下に、いまどちらかを出す。比べ用に「マーカーは常に終端」の切り替えも付けた。
- **掴み代が面で見える。** 予定の端（外側）・実績の端（内側）・ダミー・マーカー・フェード・マイルストーンを、色の面として描く。**横の広がりと縦の広がりがそのまま面の形である。**
- **数を変えられる。** 掴み代の px、縦の広がり（帯の外へ何 px 出すか）、全体のズーム、1 日の幅、バーの高さ、ポインタの矢印の一辺。
- **ポインタの形が出る。** 面の上にポインタを置くと、その掴み代に割り当てた矢印（予定＝白抜き、実績＝塗りつぶし）が実際のカーソルとして出る。12 / 14 / 16 / 20 / 24px の見比べも付けた。
- **進捗マーカー・タスク名・進捗 ％・担当者は、それぞれ表示・非表示を切り替えられる。**
- **札はタスクに追従する。** タスクを引いて動かせば、名前・％・担当者も一緒に動く。
- **マーカーは札の位置によらず、常に実績のすぐ右に立つ。** 札はそのさらに右へ出る。
- **札と実績の間隔**、**札の字の大きさ**（実績の高さに対する比）も、つまみで変えられる。
- **掴み代は、予定・実績・ダミーで別々に決められる** —— 横（予定は外側、実績は内側、ダミーは片側）と、縦（帯の外へ上下へ何 px 出すか）をそれぞれ持つ。細い帯でも押せるようにする**縦の下限**は共通の 1 つ。
- **札の置き方は仕様に合わせた** —— 担当者と完了率は **1 枚の札**で予定バーの**左に右寄せ**（表 T-038 の `OC-2`、並びは `OR-1`）。タスク名は形状の右（`OC-1`）。
- 画面の最後に、**いまの値が 1 つの塊でまとまる**。そのまま貼って裁定に使える。

## 3 つの場面

| 場面 | 何を確かめるためのものか |
|---|---|
| ① 予実のあるタスク | 予定の端・実績の端・マーカー・フェードが同じ行に並んだときの、掴み代の重なりと余り |
| ② 未着手（ダミー） | ダミーの印は小さい（マーカーの径の半分）。押せる幅をどこまで広げるか |
| ③ マイルストーン | 図形の外側へどれだけ掴み代を出すか |
| ④ 矢印（`--->`、表 T-012 の `SH-3`） | 実績を下へずらして描く形での、端の掴み代（フェードは持たない） |

## いまの仕様の値（見本の初期値）

| 掴む対象 | 描く大きさ | 掴み代 |
|---|---|---|
| 予定の開始点・終了点 | 端の線 | 端から外側へ 12px（`S-90`）。縦は予定バーの帯 |
| 実績の開始点・終了点 | 端の線 | 端から内側へ 12px（`S-91`）。縦は実績バーの帯 |
| 実績ダミー | マーカーの径 × 0.5（既定で 5px） | 描いた印そのもの（左右それぞれ約 2.5px） |
| 進捗マーカー | 円 | 描いた正方形（一辺はバーの高さに連動） |
| フェードの掴み点 | 5 × 5px（`S-109`） | 8 × 8px（`S-92`） |
| ポインタの矢印 | — | 一辺 24px（`S-249`） |

⚠️ **掴み代は表示の倍率で縮まない**（`DS-7`）。見本もそのとおりに作ってある。
