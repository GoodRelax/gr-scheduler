# ヘルプを 1 画面に収める —— 実物の組み替えで測る

- 作った日: 2026-10-04
- 測り: [`measure-help-fit.cjs`](measure-help-fit.cjs)（Playwright。出荷ビルドを開いて `F1` でヘルプを開き、DOM を組み替えて高さを読む。`src/` には触れない）
- 測った木: `e7d889f1` の `dist/index.html`
- 利用者の言葉と裁定: [`rulings.md`](../../docs/development-records/rulings.md) の `JDG-1390`〜`JDG-1396`
- 変更要求: [`CR-665`](../../change-request/CR-665-the-help-fits-one-screen-on-a-150-percent-display.md)

## 測り方

リポジトリの根の `node_modules` の Playwright を使う（作業木には `node_modules` が無い）。

```bash
node previous-project-result/37-help-fits-one-screen/measure-help-fit.cjs <根の node_modules> dist/index.html <出力のフォルダ> 1280 627 1234f
```

- 1280×627 は利用者の画面の CSS の大きさである。利用者の写し（Edge、ブックマークバーなし）から、ヘルプの箱の幅 1808 物理 px ÷ 1.5 ≒ 1205 と、内容の領域の高さ 940 物理 px ÷ 1.5 ≒ 627 を読み、1280×627 で開いたヘルプの箱（1216×568）がそれと合うことで確かめた。
- `steps` の数字は利用者の 4 点（`JDG-1391`）のどれを当てるか、`f` は本文の字を 12px にすること（`JDG-1393`）。
- 「余り」は本文の領域の `scrollHeight - clientHeight`。0 なら縦にスクロールしない。

## 結果

| 形 | 1280×627 日本語 | 1280×627 英語 | 1920×1080 |
|---|---|---|---|
| いま（`e7d889f1`） | 788 / 549（239 あふれる） | 788 / 549 | 979 / 979（収まる） |
| 4 点を当てる、字 12.8px | 576 / 549（27 あふれる） | 593 / 549（44 あふれる） | — |
| 4 点を当てる、字 12.0px（`S-203` 0.75） | 549 / 549（余り 0） | 549 / 549（余り 0） | 979 / 979（日英とも余り 0） |

（数は本文の高さ ／ 見える高さ、単位は CSS px）

- 字の大きさの掃引（4 点を当てた形、※1 をライセンスの上に置いた形）: 日本語は 12.2px で 2px、12.0px で 0px あふれる。英語は 12.4px で 9px、12.2px で 2px、12.0px で 0px。
- 最も高い段は英語のヘッダー（`HC-2`、12.8px で 532px）である。パレットをさらに動かしても、この段は低くならない。
- ※1 とライセンスを同じ行に並べると、日本語は 1 行に入るが英語は入らない（利用者は ※1 をライセンスの上に置くと決めた —— `JDG-1396`）。

## 限り

- 組み替えは DOM の上の手当てであり、生成器と描画が作る形と px 単位で同じとは限らない。当てる波は出荷ビルドで測り直す（`PND-720`）。
- `CR-658` が `IC-142` をパレットの 3 つ目の群へ移すと、`HC-3` が 1 行伸びる。いまの最も高い段は `HC-2` なので収まりは変わらない見込みだが、測っていない。
