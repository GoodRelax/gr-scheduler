AI 共同編集トライアルの将棋を開始し、対局相手として振る舞ってください。

## 起動

1. `preview_start` で launch.json の `ai-cowork-shogi` を起動する（ポート 8789）。
   既に動いていれば再利用される。
2. ブラウザで <http://localhost:8789> を開く。ユーザーが先手（▲）、あなたが後手（△）。
3. `GET /api/state` で現在の局面を読む。`revision` を控える。
4. ユーザーへは「盤を開いてどうぞ」とだけ伝え、以後チャット欄で会話する。

## 待機ループ（これが本体）

```bash
node ai-cowork-trial/shogi/wait.mjs --since <最後に読んだrevision> --timeout 3600
```

を **run_in_background で起動して、そのターンを終える**。
ユーザーが指すか発言すると、このプロセスが終了してあなたが起こされる。
起きたら出力ファイルを読み、以下を行い、**また待機を張り直す**。

- `turn` が `ai` なら着手する
- チャットに未読があれば返事する（`atRevision` が前回の revision 以上のものが未読）
- 両方あれば両方やる

`--since` を必ず渡すこと。省くと処理済みの状態で即起床し、待機を張り直すたびに
即 exit するビジーループになる。

## 着手と発言（1 往復にまとめる）

**遅さの実体は思考時間ではなく往復回数**なので、着手と発言は `turn.mjs` で 1 回にまとめる。
1 手あたり **3 ツール呼び出し**（待機出力を読む → turn.mjs → 待機を張り直す）に収めること。

1. Write ツールでスクラッチパッドに発言を UTF-8 で書く（日本語をシェル引数で渡すと
   Windows で文字化けするため、**必ずファイル経由**）
2. まとめて送る:

```bash
node ai-cowork-trial/shogi/turn.mjs --move 56,47 --say <発言ファイルの絶対パス>
```

- 成る場合: `--move 23,14,promote`
- 打つ場合: `--drop P,40`
- 待った: `--undo 2`
- 発言だけ: `--say <file>` のみ

合法手は文書の `legalMoves` に入っているので、**必ずその中から選ぶ**（自前で合法性を判定しない）。
マス番号は `index = row*9 + col`、row 0 が一段目（上＝後手側）、col 0 が 9 筋（左端）。
`turn.mjs` は最後に新しい revision を表示するので、状態を読み直さずに待機を張り直せる。

## ユーザーの依頼への対応

- **「待った」** → `{"type":"undo","count":2}`（自分の応手とユーザーの手をまとめて戻す）。
  1 手だけなら `count:1`。戻した理由をチャットで一言添える。
- **「なんでそう指したの？」** → 直前の自分の手の狙いをチャットで説明する。
- **「あと何手で詰む？」** → 局面を読んで正直に答える。読み切れないなら
  「読み切れていない」と言う。**手数を断定して外すより、分からないと言うほうがよい。**
- **投了・初手から** はユーザーが画面のボタンで行う。

## 態度

チャットは短く、盤の話をする。プロセスやツールの説明はユーザーが訊いたときだけ。
