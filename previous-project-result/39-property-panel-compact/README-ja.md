# 39 プロパティパネルを詰める見本（7 版、2026-10-08）

`index.html` をブラウザで開く（1 ファイルで動き、どこにも保存しない）。

利用者の指示（`JDG-1552` 〜 `JDG-1571` の帯と、2026-10-08 の追加の指示）を当てた見本である。プロパティパネルに出る 3 つの場面を並べる。

- ① タスクを選んだとき: 左が今のアプリ、右が提案。
  - 今は、タスクの欄の後ろに、そのタスクが載るタスクグループの欄（名称・最小高さ・編集権限・色）が続く。
  - 提案は、タスクの欄だけを出す。開始日と終了日は別の行。チェックは左詰め。
  - 色の 3 行は一番下に、枠線幅 → 枠線色 → 塗潰し色 の順。
  - 色の欄は 1 欄 2 段（1 段目: 5 色＋[T]、2 段目: 5 色＋市松＋[O]）。選んでいるものは太枠。
- ② タスクグループを選んだとき（提案）: タスクグループ名・最小高さを設定する・最小高さ・現在の高さ・編集権限・色。
  - 切り替えで、欄名に「タスクグループの」を付けた形と比べられる。
- ③ ヘッダーの［三］で開く文書の設定（提案）: テーマ色の真下に、全体表示時の期間の欄と行見出しパネルの幅の欄を置く。
  - 期間の欄: 固定するチェック、期間 yyyy/mm/dd - yyyy/mm/dd、現在表示中の期間、［全体表示時の期間に設定］。
  - 幅の欄: 固定するチェック、幅の px、現在の幅。
  - 「親子の進捗の疑義が許す日数」は、その下に下げた。

上の切り替え: ライト／ダーク、見本の倍率。パネルの寸法はアプリの値（幅 280px、字 11.9px、見本 17px）に見本の倍率を掛けたもの。色の値は表 T-294（`S-314` 〜 `S-323`）から写した。
