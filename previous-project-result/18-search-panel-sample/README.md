## 何を確かめるための見本か

`JDG-619` は「パネルの寸法は触れる見本で決める」とした。この見本は、`CR-571` の案の振舞いを実データの上で動かし、次の 2 つを利用者が手で確かめられるようにする。

1. **振舞い** —— 開く・探す・絞り込む・並べ替える・押して飛ぶ・最小化・最大化・閉じる、が案の表のとおりで使いやすいか。
2. **寸法** —— 表 T-206 の「未定 🔎」の値。右上の「見本の寸法」で変えられる。見本の初期値は次のとおりで、**どれも仮である**（決めてはいない）。

| 行 | 値 | 見本の初期値 |
|---|---|---|
| `S-421` / `S-422` | 既定の幅・高さの比 | 0.5 / 0.5（`JDG-612` の「画面の 1/4」） |
| `S-423` / `S-424` | 幅・高さの下限 | 360px / 160px |
| `S-425` | 列の幅の下限 | 64px |
| `S-426` | 縁を掴める幅 | 6px（縁の内と外にそれぞれ。「縁を色で見せる」で掴める所が見える） |
| `S-427` | 表の行の高さ | 28px |
| `S-428` | 飛んだ先の日付と左端のあいだ | 24px |
| `S-429` | 表の字の大きさ | 14px（地の 16px に対して） |

## 見本が案のとおりに作ったもの

- **入口**: ヘッダーの Fit の右に虫眼鏡（ツールチップ「検索 (Ctrl+F)」）。`Ctrl+F` はブラウザの検索を止めてパネルを開く。開いていて焦点が外にあれば、入力欄へ焦点を戻して語をすべて選び、最小化していれば戻す（`SV-2`）。
- **パネル**: 既定は日程の領域の幅と高さの 1/2 ずつ、左下（`SV-9`）。見出しの帯で動かし、縁と角で大きさを変え、日程の領域の外へは出ない（`SV-10`・`SV-11`）。見出しは「検索パネル」・`===` タスク・コメントボックス、右に `-` 最小化（見出しだけ残す）・`□` 最大化／戻す・`X` 閉じる。〇 の入口は無い（`JDG-612`）。
- **一致**: タスク名・担当者名（1 人ずつ）・コメントボックスの本文への部分一致。`NFKC` で正規化して大文字と小文字を畳む —— 「ｅｒｐ」は「ERP」に当たり、「れびゅー」は「レビュー」に当たらない（`SV-4`）。1 文字打つたびに作り直す（`SV-5`）。
- **表**: タスクの表は「タスク（マイルストーン）｜担当者名｜予定開始｜予定終了｜状態｜最上位までの階層」、コメントボックスの表は「本文｜行タイトル｜日付」（2026-09-26 の答え: 見出しは「本文」）。見出しの行を縦に、担当者名の列（コメントボックスの表は本文の列）までを横に固定する（`SV-6`）。状態は表 T-019a の 5 つ、階層は「 → 」で繋ぐ。名前の無いダミーのタスクも載る。
- **列の絞り込みと並べ替え**: どの列にも Excel のような絞り込み（一覧の中の検索・値ごとのチェック・「（空白）」・すべて表示／すべて外す）と昇順・降順。日付の 2 列は「いつから」「いつまで」を宿主の日付の入力（カレンダー）で選ぶ。絞り込んだ列の見出しには印が付く（`SV-7`・`SV-8`）。
- **押して飛ぶ**: 名前（本文）のセルを押すと、載っている行と祖先のすべてを `expanded` にする（隠した行も、確かめを問わない）。そのタスク（コメントボックス）を選び、行をピン止めの帯のすぐ下へ、開始日（日付）を左端から `S-428` だけ内側へ寄せる。ピン止めの行なら横だけ。ピン止めで余地が無ければ「ピン止め行が多くて検索結果を表示できません。ピン止めを減らしてください。」[OK] を出し、行は開くが寄せない。最大化していれば先に戻す（表 T-332）。
- **取り消し**: 飛んで行の木が変われば「未保存の編集」になり、取り消しの 1 段になる。`Ctrl+Z`（焦点が入力欄に無いとき）か「取り消す」で戻る。何も変わらなければ段を積まない（`JDG-598`・`JDG-21`）。
- **閉じる**: 焦点がパネルの中にあるときの `Esc`、または `X`。語・表・絞り込み・並べ替え・位置・大きさは覚えていて、開き直すと戻る（`SV-14`）。
- **日英**: 右上の「ja / en」。英語は `CR-571` 11 節の問い 1 の案（2026-09-26 に受けた）。

## 見本が真似ているだけのもの（仕様の答えではない）

- **日程の絵**: 行・レーン・バー・菱形・コメントボックスの付箋は簡単な HTML で描いた。アプリの描き方・色・寸法ではない。
- **縦の倍率**: 倍率の代わりに「倍率で描く深さ」（1 か 2）で表 T-329 の `TD-4` を真似た。行の木は `CR-570` の値のうち `auto`・`collapsed`・`expanded`・`hidden` の 4 つだけで、`temporarilyExpanded` と [vv] は無い。[v]・[^^]・[^] の遷移も表 A のうち主な升だけである。
- **全体表示（Fit）**: 横を合わせるだけで、行の木を `auto` へ戻さない。
- **ピン止め**: 行ごとの押し札と「ピン止めを増やす」（深さ 1 の行をすべて留める）で真似た。
- **通知**: `RS-66` は `NT-3a` の通知の代わりに、画面の中央のダイアログで出す。
- **プロパティパネル**: ヘッダーの下の 1 行の読み出しで代えた。
- **足したデータ**: 元のファイルにはコメントボックスも中断のタスクも名前の無いタスクも無い。見本のために、コメントボックス 6 つ（本文はどれも見本の作文）・中断のタスク 2 つ（再開日未定と再開予定あり）・名前の無いダミーのタスク 1 つを足した。
- **辞書に無い語**: 「いつから」「いつまで」の英語（From / To）、件数の書き方、入力欄の薄い字、見本の操作の札、「（名前なし）」は見本だけの語である。「本文」の英語（Text）もまだ誰も与えていない。
- **しないこと**: `Agent API`（`AM-16`・`AM-25`）、ホイールの割当（表 T-023 の後の段）、ヘルプ、書き出し、ファイルへの保存。

## 始めの状態（飛ぶと開くのが見えるように）

- 「4. 業務設計(ブループリント)」と「7. データ移行」は `collapsed`、「CRM 連携」は `hidden`。
- 「1.5 ステアリングコミッティ」と「12. プログラム完了」をピン止め。
- 試し方の例: 「品目マスタ」で探して押す（畳んだ行の中）、「CRM 連携」で探して押す（隠した行の中）、コメントボックスの表で「ベンダー」、「ピン止めを増やす」の後に押す（通知）。

## 確かめたこと

Playwright（Chromium、`file://`）で 1920×1080 と 1280×720 の両方を押し、どちらも 46 項目すべてが通った（コンソールのエラー 0 件）。項目は、`Ctrl+F` で開いて焦点が入ること、「移行」「伊藤」「ｅｒｐ」の当たり、畳んだ行・隠した行・コメントボックスへ飛んで行がピン止めの帯のすぐ下に来ること、ピン止めの行では横だけ動くこと、通知、`Ctrl+Z`、絞り込み・並べ替え・固定の列、動かす・大きさを変える・最小化・最大化、`Esc` で閉じて語を覚えていること。探索子はセッションの作業場に置き、リポジトリには入れていない。
