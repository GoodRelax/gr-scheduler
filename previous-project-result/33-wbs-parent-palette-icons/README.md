# 33 — パレットの親子判別と親定義（触れる見本）

`JDG-1062` の ③「親子判別アイコンと親定義アイコンをパレットに足せ」の詳細を、触れる見本で決めた記録である。

## 決まったこと

利用者の答えは `docs/development-records/rulings.md` の `JDG-1100`〜`JDG-1109`・`JDG-1120`（と調整役が記録した `JDG-1118`）に逐語で在る。
変更要求は `change-request/CR-631-the-palette-shows-and-sets-the-wbs-parent.md`。

- 親子判別（群 `表示`）は、指した・選んだタスクの家族だけに、子から親への矢印を描く。実線は明記の親、破線は期間から導いた親（保存しない）。
- 親定義（群 `揃える`）は構え。クリックは子を選び、子から親のバーへのドラッグは選んだ子すべてを結ぶ。
- 実線の矢印を選んで `Del`、またはプロパティパネルの × で親を外す。点線は選べない。
- タスクと矢印が混ざったら 2 択で 1 種類に絞る。
- 最上位の行のタスクは親なし（`DFC-1681`）。

## 見本で試すこと

1. 「2 つの親と、それぞれ 2 つの子を見せる」を押す。
2. 「子を先に 2 つ選んでから構える」を押し、「製作」へドラッグする。
3. 子のバーと矢印をまとめて囲み、2 択を見る。
4. 子をマイルストーン「節目 A」へドラッグし、面の文言を見る。
