色の入力の並べ方の見本（CR-606 の参照）

利用者の指示 JDG-863 の並び（ライト／ダーク → プロジェクトテーマ色 → 見本 5×2 → なし／その他の色、枠線幅 1〜10px）と、 JDG-922（枠線幅はタスクもボックスも 1〜10px、細・中・太は 1・2・3px）を、プロパティパネルの模型で触れるようにしたものです。 左がタスク、右がハイライトボックスの欄です。値はすべて仕様の行から写しています（下の表と README-ja.md）。 パネルの字はアプリでは 11.9px（項目名 10.71px）ですが、このページでは読めるように「見本の倍率」を掛けています。

言語
明暗

1. パネルの欄と、描かれる絵

見本を押すと、保存するのは色の名（例 red）です（CV-1）。 ライト／ダークの行には、その名が表 T-294 で持つ明暗それぞれの値が出ます。 「その他の色」は押したときだけ閲覧環境の色の入力を出し、いま描いている明暗の側だけを決めます（CV-4）。 絵は選んだ明暗に関係なく、明るいテーマと暗いテーマの両方で描きます。 ハイライトボックスの枠線色の破線の空き枠は「線なし」の場所です（仕様は枠の透明を禁じる。FR-019・PR-22）。

2. 使っている値

パレット色は表 T-294（S-314〜S-324）。テーマの色は表 T-236 の式に上の色相を入れた値です（FR-041）。

3. 決まっていないこと

  • ハイライトボックスの枠線色には「線なし」を置いていません。仕様は枠の透明を禁じています（FR-019・PR-22）。JDG-863 の並びと食い違うので、場所を空けるか、ボタンごと消すかは未定です。
  • ハイライトボックスの「塗潰しなし」（transparent）と「プロジェクトテーマ色」（null → S-370 の既定の透明）は、既定では同じ絵になります。2 つを並べる意味を仕様は述べていません。
  • ハイライトボックスの「プロジェクトテーマ色」は、枠では注記の色 S-312（色相に追随しない）を描きます。語「プロジェクトテーマ色」が合うかは未定です。
  • 枠線幅に「テーマ（既定）へ戻す」入口を置くか。いまの列は null を取れます（AT-104・AT-145）。この見本は数だけを置いています。
