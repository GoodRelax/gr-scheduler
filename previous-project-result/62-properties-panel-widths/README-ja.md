# 62 プロパティパネルの中身ごとの幅 —— 出荷の描き方で測る見本（2026-10-17、`CR-787`）

`index.html` をブラウザで開く（1 ファイルで動き、外のスクリプトもフォントも読まず、どこにも保存しない）。

## 何の見本か

利用者の報告（2026-10-17）の 3)・4) と確かめ表の 5)（`JDG-2463`〜`JDG-2466`）に応える見本である。
右のプロパティパネルを、出す中身の種（文書の設定・タスク・マイルストーン・タスクグループ・コメントボックス・ハイライトボックス・依存線）ごとに 1 枚ずつ並べ、横のスクロールバーが出ず、どの項目名も 2 行以内に収まる最も小さい幅を測る。

- ⭐ **パネルは出荷の描き方そのものである。** `sample-entry.ts` が `src/` の `properties-panel.ts`（面の中身）と `properties-panel-drawing.ts`（描き方）を読み、`build-sample.mjs` が rolldown で 1 ファイルに束ねる。手で写した見本ではないので、字の倍率（`S-197`・`S-198`）や名の欄の割合（`S-189`）を写し損ねない。
- 文書は起動の見本（`startup-template.json`）の先頭 40 タスクに、コメントボックスとハイライトボックスを 1 つずつ足したもの。
- タイムゾーンの欄には、いちばん長い選択肢（`ZN-54`「東ヨーロッパ夏時間（カイロ・ヘルシンキ）」/ "Eastern European Summer Time (Cairo, Helsinki)"、基準は `ZN-51`）を持たせた —— 幅のいちばん厳しい場合で測る。

## 測り方（`sweep.mjs`）

- 表 T-025 の `msedge`、窓 1363×900。パネルは縦のスクロールバーを出し（`overflow-y:scroll`）、高さ 760 px。
- 幅を 900 px から 10 px ずつ狭め、次の 3 つが全部成り立つ最も小さい幅（それより広いどの幅でも成り立つ所まで）を答える:
  1. パネルの中身が横にはみ出さない（`scrollWidth <= clientWidth`）。
  2. どの項目名も 2 行以内。
  3. ja では、タイムゾーンの選択肢が 2 行に収まる（地名を欄の中で折らない）。en は地名が欄の中で折れてよい（`JDG-2541`）。
- 1 つ狭い幅で何がはみ出すか（`limited by`）も出す。

```
node previous-project-result/62-properties-panel-widths/build-sample.mjs
node previous-project-result/62-properties-panel-widths/sweep.mjs [画面写しの置き場]
```

（`node_modules` の無い作業木では `ROLLDOWN=../../../node_modules/rolldown/dist/index.mjs`・`PLAYWRIGHT=../../../node_modules/playwright/index.mjs` を前に付ける。）
