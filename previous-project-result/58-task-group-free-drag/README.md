## 案 B の骨組み（見本が動かしている規則）

1. 掴み代 `⋮⋮` を掴むと、そのタスクグループは配下ごと持ち上がる。持ち上げた配下は落ち先の候補から外れる（自分の子孫の下へは落とせない）。
2. 縦で **隙間** を選ぶ —— 描かれている 2 つのタスクグループ U（上）と L（下）のあいだ。いちばん上の上、いちばん下の下も隙間。
3. 横で **段** を選ぶ —— 置ける段は 下限 = L の段（L が無ければ 1）、上限 = U の段 + 1（U が無ければ 1）。さらに配下の深さ込みで 5 を超えない。刻みは字下げ（`S-37`、16px）。範囲の外へ引くと端で止まる。
4. 段 d の親は、U から上へたどって最初の段 d − 1 のタスクグループ（d = 1 なら最上段）。
5. 離す前に、選んだ段の字下げから差し込み線を引き、親になるタスクグループを枠で示す。
6. 元の場所なら何も書かない。1 回のドラッグが Undo の 1 手。`Esc` で取り消す。
7. パネルの上下の縁（見本では 36px）へ運ぶと、パネルが自動で送られる。

## 試すこと

画面の右の「試すこと」と同じ。要点だけ書く。

1. [最も浅い段を 1 階層展開する] を押す —— 利用者のログ（2026-10-15 23:08）と同じ、最上段だけの畳んだ画面になる。
2. 「予備」を「設計」の下の隙間へ運び、右へ引く。右の 質問 2 の a / b / c を切り替えて違いを見る。
   - a: 線が段 1 で止まり、「中へは置けない」と告げる。
   - b: 「設計」の行の上で 0.7 秒止めると「設計」が開き、中の隙間を選べる。
   - c: 線が「設計」の内側へ入り、「設計」に太枠と「中へ」の札が付く。離すと「設計」の末子になり、「設計」は畳んだまま（`+8` が `+9` になる）。
3. 「保守」をいちばん上の「企画」より上へ、2 段目の「データ」を同じ所へ運んで左へ引く —— どちらも 1 回で最上段の先頭になる。
4. [すべて開く] のあと、「画面」を「移行」の下へ運んで右へ引く —— 段 2 で線が黙って止まる。「形式」と「移行」のあいだでは線が出ず、離しても何も起きない。
5. いちばん下の「臨時」を掴んでパネルの上の縁へ運ぶ —— 自動で送られる。

## 見本が決めていないこと（数は仮）

- 自動送りの帯の幅 36px と速さ（1 描画あたり最大 14px）、案 b の止まる時間 0.7 秒 —— どちらも測って決めた値ではない。
- 絞り込み中の扱い、複数の選択をまとめて動かすこと、キーボードの入口、親だけを動かすこと —— 見本は扱わない（聞き取りの残り②〜⑤）。
- 見本のタスクグループ名は、木の形を見せるための仮の名である。
