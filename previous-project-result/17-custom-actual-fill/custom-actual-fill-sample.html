カスタムカラーの実績の塗り —— いまの式（CV-6）と別案

裁定（JDG-540、2026-09-24）: 案 D を既定の値で採る。仕様への反映は change-request/CR-564（表 T-017b の CV-10、表 T-206 の S-415 ・ S-416）。

予定バー（外の太い帯）はカスタムカラーそのもの、実績バー（中の細い帯）はその色から導いた色で描きます。 縁はテーマの縁のまま（予定は S-156、実績は S-158）—— 木 1d5f8867 の dist/index.html で実測した描き方と同じです。 高さの比は actualOfPlan = 0.5715（予定 28 に対し実績 16）。 数字の見方: 「実/予」は実績と予定の塗りのコントラスト比（表 T-017a の CT-3、3 以上が要る）。 「色味」は実績を #rrggbb に丸めた後の各成分の最大 − 最小（0 〜 255。0 は無彩色＝黒・白・灰）。

どこで壊れるか —— 選んだ行の色相で、彩度 × 明度を掃いた地図

満たす 実/予 < 目標（CT-3 割れ） 黒か白に潰れる（色味が消える） 灰に色が付く テーマと逆向き（テーマ自身の予定→実績は、明で暗く・暗で明るくなる。その逆。LM-18 のとおり暗いテーマの向き自体が FR-007 と逆である点に注意）

全体の数 —— #rrggbb の各成分を 0, 17, 34, …, 255 の 16 段で掃いた 4096 色

測り方: 実績の値を HSL で導き、各成分を 0 〜 255 の整数に丸めてから WCAG 2.1 の相対輝度 （PoC poc-integrated.html :608-620 と同じ式、閾値 0.03928）でコントラスト比を求めた。 「潰れる」は、選んだ色の色味が 16 以上なのに実績の色味が 16 未満になったもの。 「灰に色」は、選んだ色の色味が 4 未満なのに実績の色味が 8 以上になったもの。 モノクロの切り替えは本表にも効く（無彩色にしてから測る。CV-7）。

案 B / D / E の帯（実績の明度の床と天井）

案 A（いまの式）は常に 0〜100 に収めるだけで、灰色にも彩度を足す（色相 0 = 赤みになる）。

案 D の目標

CT-3 は 3.0。帯の中で届かなければ、逆向きへ同じ量だけ振る。

案 E のしきい値（選んだ色を実績とみなす明度）

しきい値を越えた濃い（暗いテーマでは明るい）色は、そのまま実績に使い、予定は逆向きのずらしで導く。予定バーが選んだ色でなくなる —— CV-6「選んだ値をそのまま」を変える案。

案の中身

A いまの式: 明 S+16 / L−46、暗 S+30 / L+38、0〜100 に収める（CV-6）。
B 床と天井: A と同じずらしを、明度だけ [Lmin, Lmax] に収める。
C 比で縮める: 明 L×34/80、暗 L+(100−L)×38/74 —— テーマの予定→実績（S-155→S-157）の比。彩度は A と同じ。
D 比を守る: B の結果が目標に届かなければ、逆向きに同じ量だけ振る（帯に収める）。それでも届かなければ比の大きいほうの端。モノクロのときは灰で比を測る。
E 役割を明度で決める: 濃い色は実績そのもの、予定は逆向きに導く（予定は 0〜100 に収めるだけ）。薄い色は B と同じ。
