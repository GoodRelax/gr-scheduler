## 見本で分かったこと

- ヘッドレスの Playwright は `--hide-scrollbars` を付けて起動するので、スクロールバーの押下を試せない。`sweep-sample.mjs` はその既定の引数を外している。

- `Shift` ＋ ホイールはこのアプリでは横のズーム（`MK-3`）であり、横スクロールではない。
- 着地の線は経路の全体を描くので（`EL-19`）、送った先から元の端へスクロールで戻ると、線を途切れずに辿れる。
