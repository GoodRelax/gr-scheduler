# 43 テーマ色の解き方の見本（2026-10-04）

⭐ **`CR-683` の色の値を選ぶための、触れる見本である。** 台帳の行は `DFC-865`（色相ごとの寄せと地の彩度）・`DFC-1220`（暗いテーマの注記の色）・`DFC-729`（フェードの掴み点の 2 色）・`DFC-728`（行の上で溶ける予定の塗り）・`DFC-1655`（ツールチップの色）。
裁定は `JDG-453`（寄せと地の彩度の解きを入れる）・`JDG-777`（値は触れる見本で選ぶ）・`JDG-1486`（床は地だけに掛ける）・`JDG-1487`（掴み点は既存の行を借りる）。

| ファイル | 中身 |
|---|---|
| `index.html` | 1 ファイルの見本（外部の読み込み無し）。左に日程の模型、右に解の数と測った組の比 |

## 開き方

`index.html` をブラウザで開く（`file://` でよい。サーバーは要らない）。

## つまみ

| つまみ | 見せるもの |
|---|---|
| 色相 | `TH-1` 〜 `TH-10`（表 T-305）と 0 〜 359 の滑り |
| 明暗・モノクロ | 明るいテーマ／暗いテーマ、モノクロ（HSL の明度を保ち彩度 0） |
| 描き方 | V0 いまの出荷（寄せも解きも無い）／ V1 `CR-683`（寄せ ＋ 地の彩度の解き、地の明度と彩度の上限は 表 T-236 の `S-146` の値）／ V2 試作の数（地の明度 97 ／ 10、彩度 0 〜 70） |
| 地の彩度の上限 | V1 の暗いテーマの上限（既定 12%）を上書きして、地の色味の強さを見る |
| 注記の色 | 表 T-236 の `S-312` の暗いテーマの候補（推奨 `#df670c`） |
| 掴み点 | 面 `S-146` ／ 縁 `S-156`（`CR-683`）と、いまの固定色（白 ／ `#374151`） |

右の「360 の色相の数」の押しボタンは、いまの描き方で 360 の色相と明暗・モノクロを全部解き、寄せの量・地の彩度・割る組を数える。
「貼り返す要約」は、選んだ値を 4 行にまとめたもの —— 調整役へそのまま貼り返せる。

## 測り方

比は WCAG 2.1 のコントラスト比で、HSL を 8 ビットの sRGB へ丸めた値から求める（`CR-683` の 7 節、表 T-294 の前文と同じ）。
解き方は `docs/spec/01-04-requirements.md` の `FR-041` の 表 T-366（`CF-1` 〜 `CF-6`）を写した。数は 表 T-206 の `S-516` 〜 `S-522`。

## 決まっていないこと（利用者が見本で選ぶ）

1. 地の色: V1（いまの地のまま、寄せだけが効く）か、V2（試作の数 —— 明るいテーマの地が色相の色を帯び、暗いテーマの地は濃い色になる）か、V1 の上限を上げた中間か。
2. 注記の色の暗いテーマの値: 推奨は `#df670c`（hsl(26 90% 46%)、地・パネルの地・行の地のすべてに 3 : 1 をカラーでもモノクロでも満たす最小の明度）。
