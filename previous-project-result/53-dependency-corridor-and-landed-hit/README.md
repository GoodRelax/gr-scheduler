## 問い 1 —— 行を飛ばす線の通路の高さ

見本 50 の案 C（`JDG-1901` で決まった）は、段を斜めにまたぐ線（表 T-222 の `RP-2` / `RP-3`）を通路に通す形だった。そのとき見本 50 は、通路を **後続のすぐ上の行間** に置いた。仕様の `LF-5`（とアプリの `corridorY`）は **先行と後続の中点** に置く。隣り合う行どうしでは同じ高さだが、間に別の行があると違う。

| 案 | 通路の高さ | 3 本の線で、横に潜る所 ／ 縦に横切る所 |
|---|---|---|
| A（推奨） | 後続のすぐ隣の行間 | 0 ／ 3 |
| B | 先行と後続の中点（今の `LF-5`） | 2 ／ 4 |
| C | 先行のすぐ隣の行間 | 0 ／ 1 |

- 3 本は、1 行飛ばして下へ（`RP-2`）、1 行飛ばして上へ（`RP-3`）、2 行飛ばして左へ戻る（`RP-4`）線である。
- 縦に横切る所は 表 T-018a の `RT-5` が許すので数えるだけにした。横に潜る所は、横の走りが間の行の棒・札・マーカー・名前の下を通る所である。
- 数は 2026-10-15 に Playwright で見本を開き、案のボタンを押して表の 1 行目を読んだ。見本 50 の 9 本では、案 A の形で潜る所 0 を数えてある。案 C は見本 50 で測っていない。

## 問い 2 —— 印を付けた線の当たり

先行は画面の上の外、後続だけが見えている。続きの印を押して送ると、印を付けた線は経路の全体を太く描き、続きの印は描かない（表 T-303 の `EL-19`）。

| 案 | 長い横の走りの上 | 元の続きの印の所 | 矢じり |
|---|---|---|---|
| A（推奨） | 線が応える（選ぶ） | 線が応える（この見本では印の所が経路の上に乗る） | 線が応える |
| B（今のアプリ） | 何も応えない | 続きの印が応える（もう一度送る）—— 印は描かれていない | 線が応える |

- 当たりの太さはどちらも印の無いときの線の太さ ＋ 2px（`S-285`）。違うのは長さだけである（`CR-596` の決定 6 の太さは変えない）。
- 数は 2026-10-15 に Playwright で、3 つの点 (150, 139.2)・(244, 140)・(248, 150) にポインタを置いて読んだ。

## 決まったこと（2026-10-15）

| 問い | 答え | 裁定 |
|---|---|---|
| 問い 1 —— 行を飛ばす線の通路の高さ | **C 先行のすぐ隣の行間**（推奨の A ではない） | `JDG-2110` |
| 問い 2 —— 印を付けた線の当たり | **A 描いた経路の全体と矢じりで応え、描いていない続きの印の所は応えない** | `JDG-2111` |
| （見本の外）親タスクの矢印の矢じり | **依存線と一緒に 4 × 4px に縮める** | `JDG-2112` |

⚠️ 問い 1 の C は、見本 50 の 9 本では潜る所を数えていない（見本 50 の 0 は A の形で数えた）。`CR-758` を当てる体が、見本 50 の線を C の通路で数え直す。

## 作りの注

- 寸法は表示の倍率 100 で描いた px（見本 50 の案 C）。棒は予定の形だけを描き、実績は描かない。
- 経路は FS だけで、表 T-222 の `RP-2` / `RP-3` / `RP-4` を通路の形で描く。矢じりは 4 × 4px の三角。
- 当たりは 1px の格子で塗っている。塗りの所と、ポインタで出す字は同じ関数（`answerAt`）が答える。
