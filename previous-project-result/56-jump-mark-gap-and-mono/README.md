## 測り方

- 隙間: 等倍の SVG で `getBBox()` を読み、形の外接矩形の 4 辺と囲みの線の内縁との差を測った。16 個の囲み × 4 表示で、すべて候補の値と一致した（セッションの一時フォルダの Playwright の probe、msedge headless。木には置いていない）。
- 問 3: ✓ の左端と形の右端の距離を `getBBox()` で測った（A 印あり 4.5 ／ 印を消すと 0、B いつも 4.5、C・D 0）。
- 灰: `FR-041` のとおり HSL の明度を保ち彩度 0 にした（8 ビットの sRGB の (最大 + 最小) ÷ 2）。比は WCAG 2.1 の式。
- 形と寸法は出荷版の決まりに寄せた模型であり、実物の割付けではない。
