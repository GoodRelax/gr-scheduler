## 完了率について

GRS は `GRS JSON` を読むと完了率を日付から数え直す（`FR-012`）。そのため、調整役の目安（push 済み 100・合流済み 80・実装済み 50・起草 10）はファイルに持てない —— 各タスクのメモに「段階」として書いた。
ファイルの完了率は、アプリが数え直した値をそのまま書いてある（開いても数え直しの知らせは出ない）。

ℹ️ 最初の版（`efd7a749`）では、予定どおりに終えたタスクが 100% を超えて見えた（例 `CR-658` 150%）—— 分母（予定の期間）が終わりの日を数えなかったためである。`CR-667`（`4dd80ac7`）が両端の日を数えるように直したので、完了率を `adbc875f` の数え直しの値に書き直した（12 行）。中身は 2026-10-04 10:20 のスナップショットのままである。
