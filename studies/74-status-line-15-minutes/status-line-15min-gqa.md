## 決まったこと

| 問い | 決まったこと | 裁定 |
|:---|:---|:---|
| どの線を動かすか | 基準日線と、デュアルカーソルの両方。ガイドカーソル（縦・十字）とそろえる | JDG-3201 |
| 刻み | 15 分 | JDG-3202 |
| 範囲 | 時刻を表示し、目盛りが「時」の段にあるとき、タスクの端・バーを引いて作る・マイルストーン・コピー・基準日線・デュアルカーソル・ガイドカーソルの札を、すべて 15 分で寄せる。Alt の 1 分は消す | JDG-3203 |
| 日の段 | 時刻を表示しないとき、または目盛りが日の段のときは、今どおり 1 日刻み | JDG-3204 |
| 基準日の欄 | 時刻を表示するとき、文書の設定の面の「基準日 / Status Date」欄は日時の欄になり、打った分をそのまま書く | JDG-3205 |
| 🔄 *「基準線」の意味* | 🔄 *あなたの「基準線」は基準日線（Status Line）を指す* | 🔄 *JDG-3570* |
| 🔄 *刻みの確かめ* | 🔄 *15 分のまま出す* | 🔄 *JDG-3571* |
| 🔄 *X-3a* | 🔄 *ホットリリースに含める。SUB が Alt の引数を 3 か所から取り除いた* | 🔄 *JDG-3572* |
| 🔄 *出す動き* | 🔄 *develop の今の動き（下の表）のまま出す* | 🔄 *JDG-3573* |

🔄 ***出す動き:***

| 操作 | 時刻を表示し、目盛りが「時」の段 | 日の段、または時刻を表示しない |
|:---|:---|:---|
| 基準日線を左右に引く | 15 分ずつ動き、離した所に線が立つ（10:07 で離すと 10:00、10:08 で離すと 10:15） | 1 日ずつ動き、離した日の終業時刻を書く |
| 基準日線の位置 | 基準日の時刻の所に立つ。イナズマ線も同じ所を通る | 基準日の日の列の左端に立つ |
| 「基準日 / Status Date」欄に打つ | 日時の欄。10:37 と打てば 10:37 のまま書く | 日付の欄。日を打てば終業時刻を書く |
| タスクの端・バーを引いて作る・マイルストーン・コピー | 15 分ずつ | 1 日ずつ |
| Alt を押しながら引く | Alt を押さないときと同じ 15 分 | 1 日ずつ |
| デュアルカーソルを置く | 15 分の所に立つ | 日の境に立つ |
| ガイドカーソル（縦・十字）の札 | 15 分ずつ変わる。線はポインタに付いたまま | 日付だけ |
