# 遅延診断レポートの字の段と上の段 —— 触れる見本

- 作った日: 2026-10-04
- 見本: [`delay-report-font-steps.html`](delay-report-font-steps.html)（1 ファイルで完結する。ダブルクリックで開く。サーバーも通信も要らない）
- 利用者の言葉: 「フォントが大きすぎる。より小さいフォントから3段階にしろ。」ほか（逐語は裁定の行）
- 裁定: [`rulings.md`](../../docs/development-records/rulings.md) の `JDG-1230`〜`JDG-1237`
- 台帳: [`defects.md`](../../docs/development-records/defects.md) の `DFC-1857`（字の段）・`DFC-1859`（上の段）

## 開き方と触り方

| したいこと | すること |
|---|---|
| 段を巡る | 左の窓の右上の `Aa` を押す。右で決めた 3 段を順に巡る |
| 段の値を変える | 右のスライダー 3 本（8〜20 px、0.5 刻み）。小さい段が大きい段を越えないよう押し上げる |
| 既定の段を選ぶ | 右の「既定の段」 |
| 見出しの行も段に従わせる | 右の「見出しの行（窓の名）も段に従う」。外すと、いまのアプリと同じく 16 px のまま |
| 言語を替える | 右上の「日本語 ／ English」 |
| 値を伝える | 右下の灰色の塊をそのまま貼る |
| ペインの幅 | 2 つのペインのあいだの棒を引く |

右の「見比べる字」は、`e82dfee4` の `dist/index.html` で測ったアプリの字である（日程表のタスク名 9 px、まとめの行の名 13.1 px、上の帯の文書名 13.3 px、いまのレポートの既定 16 px）。

## 選ばれた値

| 項目 | 値 | 裁定 |
|---|---|---|
| 段 | 9 / 10 / 12 px | `JDG-1232` |
| 既定の段 | 1（9 px） | `JDG-1232` |
| 見出しの行 | 段に従う | `JDG-1232` |
| 共有 | 検索パネルと同じ 1 つの段の表 | `JDG-1232` |
| 上の段 | 凡例なし、まとめを横 1 行（窓の幅で項目の切れ目から折り返す） | `JDG-1235`・`JDG-1236` |
| `IC-108` の ja の札 | Copy | `JDG-1234` |

⚠️ 見本の語（ステータス・欄の見出し・理由の文）は仮である。語は別の席の裁定 `JDG-1220`〜`JDG-1229` に従う。表の行と値は見本のための作り物で、アプリの診断の結果ではない。
