# 29 ファイル選択の面が開くフォルダの見本（2026-10-01）

⭐ **`CR-619`（読み書きしたフォルダを覚える）の材料にする、触れる見本である。** 指示は `JDG-998`（`docs/development-records/rulings.md`）。
本見本は、ブラウザが「最後に選んだフォルダ」を `file://` で開いた頁についても覚えるかを、利用者の手元のブラウザで確かめるためにある。仕様を決めない。

| ファイル | 中身 |
|---|---|
| `index.html` | 1 ファイルの見本（外部の読み込み無し）。GRS と同じ File System Access API（`showOpenFilePicker` / `showSaveFilePicker`）を 4 通りの渡し方で呼ぶ |

## 開き方

`index.html` を **ダブルクリックで開く**（`file://`。GRS の利用者と同じ開き方）。Chrome か Edge で開く —— 表 T-003 の `CN-2` が対象とするブラウザであり、Firefox と Safari はこの API を持たない。
⚠️ Claude のブラウザペインは頁を `data:` の写しで描くので、API が無く、確かめに使えない。

## 4 通りの渡し方

| 行 | 渡すもの | 意味 |
|---|---|---|
| A | 何も渡さない | **いまの GRS と同じ**（`src/framework/file-system-access-file-store/file-system-access-file-store.ts` の開く `{ multiple: false }`・保存 `{ suggestedName }`） |
| B | `id: "grs-document"`（開く・保存で同じ） | ブラウザが id ごとに最後のフォルダを覚える。GRS は何も覚えない |
| C | `id: "grs-open"` ／ `id: "grs-save"` | 目的ごとに別のフォルダを覚える |
| D | `startIn: 同じ起動で最後に選んだ取っ手` | GRS が上書きのために既にメモリに持つ取っ手（`FR-060`）を渡す。頁を閉じれば消える（保存しない） |

## 確かめること

| # | 手順 | 見るもの |
|---|---|---|
| 1 | ある行の「開く」で、既定と違うフォルダのファイルを選ぶ | — |
| 2 | 同じ行の「開く」をもう一度 | 同じ起動の中で、そのフォルダで開くか |
| 3 | 同じ行の「保存」（キャンセルで閉じてよい） | 開くと保存でフォルダを共にするか |
| 4 | 頁を再読み込み（F5）して同じ行の「開く」 | 起動をまたいで覚えるか |
| 5 | ブラウザを閉じて開き直し、同じ行の「開く」 | ブラウザの再起動をまたいで覚えるか |

頁の上の枠に `window.origin` が出る。File System Access の仕様は、最後に選んだフォルダを起源ごとに覚える（「recently picked directory map」）。起源が読み込みごとに変わるならば A・B・C は再読み込みで忘れる —— ⚠️ ただし `docs/review/inventory/A03-agent-open-items.md:89` は、`file://` で IndexedDB に入れた取っ手が再読み込みをまたいで残ったと記しており（起源は変わらなかった）、いまの GRS が既定のフォルダに戻る理由は分かっていない。D だけは、理由によらず同じ起動の中で効く。

⚠️ 保存の面で「保存」を押すと、ブラウザは空のファイルを作ることがある（この頁は何も書かない）。試すときは「キャンセル」で閉じるか、捨ててよいフォルダを選ぶ。
⭐ この頁は `localStorage`・`IndexedDB` を使わない。何も覚えない。

## 結果（2026-10-01、`JDG-1021`）

利用者の Edge 154 で `file://` から開いた。上の枠は `window.origin = null`・`isSecureContext = true`・2 つの面は在る。

| 行 | 同じ起動の中で前のフォルダから開いたか |
|---|---|
| A（何も渡さない、いまの GRS） | いいえ |
| B（`id` を 1 つ） | いいえ |
| C（目的ごとの `id`） | いいえ |
| D（`startIn` に取っ手） | **はい** |

⇒ `file://` で開いた頁では、ブラウザは最後のフォルダを覚えない（`id` でも）。効くのは D だけである。`CR-619` は D を要にし、起動した直後の最初の面はブラウザの既定のまま（`JDG-1022`）。
