# タスクとマイルストーンの置き方 —— 4 つの申し立てを、押して確かめる見本

- 日付: 2026-09-07
- 見本: [`task-milestone-operation-sample.html`](task-milestone-operation-sample.html)
  （**1 ファイルで完結。ダブルクリックすれば動く。**サーバーも通信も要らない）

⛔ **これは仕様書ではない。** 実装する前に**意図した動きを手で触っていただく**ための素描である。
⛔ **見た目は判定の対象ではない。** 色も間隔も図形の寸法もわざと素っ気なくしてある。
⭐ **判定していただきたいのは動きだけ**である。

---

## 1. 何に答える見本か

2026-09-07 に出荷物に対して 4 つの申し立てがあった。**この見本は、その 4 つを 1 画面に集めて、
「こう動くはずである」という姿を先に触れるようにしたもの**である。

| # | 申し立て（いまの姿） | この見本が置く姿 |
|---|---|---|
| ① | 形アイコンを押しても、**選択中だと武装しないことがある** | ⭐ **押せば必ずその武装に入る。**選択していようが、別の形を武装していようが、拒まない |
| ② | **離すまで何も描かれない。**しかもマイルストーンを武装しているのに**タスクの形**が出るように見える | ⭐ **押している間、ポインタに素描が追随し、引けば伸びる。**素描は**置かれるものと同じ形**である |
| ③ | 離したあとの名前の確定と、そのあとの後片づけ | ⭐ **離すと名前欄が出る。`Enter` で確定し、欄が閉じ、選択が外れる**（＝次が素の状態から始まる） |
| ④ | 続けて置けるか／どう解くか | ⭐ **武装は続く**（押し直さずにもう 1 つ置ける）。**`Esc` で武装が解ける** |

### ⭐ ② が本題である —— タスクとマイルストーンで**素描の振る舞いが違う**

| | タスク（4 形） | マイルストーン（4 形） |
|---|---|---|
| 押している間 | **始点から今のポインタまで横に伸びる**（期間を引き出している） | **ポインタに追随するだけ。伸びない**（点なので長さが無い） |
| 離したとき決まるもの | 始点と終点（引いた分だけ）。⛔ 裁定⑤（2026-09-07）：引かずに離すと**何も置かれない** | 離した位置の 1 日だけ。クリックだけで置ける（変わらず） |

⛔ **この差が読めないと、置いたあとで「思っていた長さと違う」が必ず起きる。**
見本は状態欄に `9/9 → 9/17（9 日ぶん・伸びます）` / `9/26（点・伸びません）` と**日本語で出す**ので、
図を睨まなくても差が判る。

## 2. どう押すか —— 4 つの手つき

**画面右の「4 つのふるまい」は読み物ではない。**⭐ **その手を実際に打つと、印が自動で立つ。**
6 つの印がすべて `✓` になれば、4 つとも通ったということである。

| # | 打つ手 | 何を見るか |
|---|---|---|
| ① | 1 つ置く → **置いたものを押して選択** → **別の形アイコンを押す** | 上の状態欄の「武装」が変わる。⛔ **拒まれない** |
| ② | 形アイコンを押す → 行の上を**押したまま横へ引く**（まだ離さない） | タスクなら**横に伸びる**／マイルストーンなら**伸びずに移る**。**形は武装したものと同じ** |
| ③ | 離す → 名前を打つ → **`Enter`** | 名前欄が閉じ、状態欄の「選択」が**「なし」に戻る** |
| ④ | 確定したあと、**アイコンを押し直さずに**もう 1 度引く → そのあと **`Esc`** | 2 つめが置ける。`Esc` で「武装」が「なし」に戻る |

### ⛔ 申し立ての側も、その場で再現できる

画面右に**既定オフのスイッチが 3 つ**ある。⭐ **入れて引き比べていただきたい。**

| スイッチ | 入れると |
|---|---|
| **押している間、何も描かない** | 離すまで何も出ない。⇒ 申し立て ② の前半そのもの |
| **マイルストーンでもタスクの形で素描する** | ◇ を武装しているのに**矩形が横に伸びる**。⇒ 申し立て ② の後半そのもの |
| **選択中は形アイコンを拒む** | 選択していると押しても武装しない。⇒ 申し立て ① そのもの |

⭐ **4 つめのスイッチだけは性格が違う**（「武装したら選択を外す」）。**2026-09-07、利用者の裁定は「受理」だった**
（既定のまま、外す側）。下の 4. の ① を参照。

## 3. パレット —— 置ける 8 形

⭐ **タスクもマイルストーンも、確定している呼び名の図形をそのまま使った。**

| 種別 | 識別子 | 呼び名 | 目印 |
|---|---|---|---|
| タスク | `rectangle` | 矩形 | `===` |
| タスク | `chevron` | 矢羽根 | `>===>` |
| タスク | `arrow` | 矢印 | `--->` |
| タスク | `endpointSpan` | 端点スパン | `*----*` |
| マイルストーン | `circle` | 〇 | |
| マイルストーン | `diamond` | ◇ | |
| マイルストーン | `hexagon` | 六角形 | |
| マイルストーン | `pentagon` | 五角形 | |

⭐ **8 形とも実際に置ける。**⛔ **見本の中に図形を描く関数は 1 種類しか無い。**
パレットの絵・追随する素描・置かれたもの、**この 3 つは同じ関数を通る。**
⇒ **「武装した形と素描の形が食い違う」は、構造上、起こしようが無い**（上のスイッチを入れたときだけ、
1 箇所で意図的に差し替えている）。

## 4. ✅ 2026-09-07、利用者の裁定が下りた（6 件とも）

**指示が決めていなかったので、こちらで仮に決めて動かしていた 6 件。利用者に触っていただき、全件に裁定が出た。**
⛔ **②と⑤は却下**（＝いまの見本の動きを変える必要がある）。**利用者の言葉はそのまま引用する**。
残る 4 件は受理（変更なし）。

| # | こちらが仮に決めていたこと | 裁定 | 裁定後の姿 |
|---|---|---|---|
| ① | 武装したら選択を外す | **受理**（変更なし） | 外す側のまま。⭐ 見本ではスイッチで両方試せる |
| ② | 同じアイコンをもう一度押しても何も変わらない（武装したまま） | **却下** —— 「反対。トグルにせよ。 ユーザーに選択肢がある。」 | **トグルにした。**武装中のアイコンをもう一度押すと武装が解ける（`Esc` でも解ける）。⛔ **何を選んでいても同じ** —— 選択の有無で押し直しの意味は変えない。⚠️ ①は生きている：それは**別の**アイコンについての規則であり、別のアイコンなら何を選んでいても必ず武装する |
| ③ | 名前欄の `Esc` は欄だけ閉じ、置いたものは「無題」で残る。武装は解けない | **受理**（変更なし） | もう一度 `Esc` を打つと武装が解ける、という 2 段構えのまま |
| ④ | 名前を打っている間は次を置けない | **受理**（変更なし） | 名前欄が開いている間、行は押しても始まらないまま |
| ⑤ | 引かずに離したら 1 日として置く | **却下** —— 「タスクはドラッグ必須。」 | **タスクはドラッグしないと置かれない。**押して、動かさずに離すと何も置かれない（理由がログと状態欄に出る）。⚠️ マイルストーンは点なので、この裁定のあとも**クリックだけで置ける**。この対比がこの見本の主題である |
| ⑥ | 左へ引いても始点と終点を入れ替えて成立させる | **受理**（変更なし） | 入れ替えて成立させるまま |

## 5. この見本が省いていること

**利用者が省いてよいと言われたもの**: 行は 1 本だけ。木も入れ子も無い。行の見出しは 1 語だけ。
依存も、カレンダー（休日の詰め）も、取り消しも、保存も、拡大縮小も、スクロールも無い。

⚠️ **日付軸は期間に意味を持たせるためだけに置いてある。**土日は薄く赤いが、
**働かない日として扱ってはいない**（引けば普通にまたぐ）。⛔ **ここで日数を検算しないこと。**

## 6. ⭐ 書いたあとで、実際に押して確かめた

⛔ **「書いたから動くはず」では報告しない。**Chromium（1280×800、`file://` で直接）で
**6 つの手つきを端から端まで打った**。測ったのは次のとおり。

| 見たもの | 実測 |
|---|---|
| **タスクの素描が伸びること** | 矢羽根を 9/9 から押さえたまま 3 日・6 日・9 日へ引いた ⇒ 素描の幅 **90px → 186px → 282px**（1 日 32px ちょうど） |
| **マイルストーンの素描が伸びないこと** | 六角形を押さえたまま 9/26 → 9/27 へ引いた ⇒ 素描の幅 **21px のまま**、位置だけ **x=614 → x=646**（＝ 1 日ぶん） |
| **選択中に形アイコンを押したとき** | 「結合試験」を選択した状態で六角形を押した ⇒ **武装＝六角形**に変わった（拒まれない） |
| **`Enter` の後片づけ** | 名前を打って `Enter` ⇒ **名前欄が DOM から消え、選択＝なし、武装は矢羽根のまま** |
| **武装が続くこと** | 確定後、パレットに触らずにもう 1 度引いた ⇒ 2 本目が置けた |
| **`Esc`** | 武装＝なしに戻った |
| **8 形すべて** | 8 つ置いて、描画要素の寸法を 1 つずつ読んだ ⇒ **すべて別の図形として出た** |
| **読みやすさ** | 本文 **16px / 行間 27.2px（＝1.7）**、ページ中の最小フォント **12px**、横スクロール **0**（1280px で右列が本文の横に並ぶ） |
| **例外** | ページ内のエラー **0 件** |

⚠️ **測っている途中で 1 度、見本ではなく計測の側が間違えた。**
右列の設定を押すとページがスクロールするのに、行の座標を最初に測ったまま使い回していたため、
**行を押したつもりが設定を押していた。**⇒ **手を打つたびに測り直す**ように直してから、上の数を取り直している。

⛔ **やり残し**: タッチ（指）とキーボードだけでの配置は試していない。**ポインタでの手つきだけを見た。**
