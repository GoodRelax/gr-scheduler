## 比べる 3 つの形

| 形 | 前例 |
|---|---|
| A 押した所の横に浮く一覧 | 混ざった選択の 2 択（`QN-12`、33 の見本）、担当者欄の候補 |
| B 中央の窓 ＋［決める］ | 「ファイルを開く」（`CR-623`、`JDG-1163`）、33 の見本の「「X」の親を選ぶ」窓 |
| C コマンドパレットで絞る | 無い（パレットは絵だけで、文字で絞る場所が仕様に無い） |

3 つとも、次は同じにしてある。

- 候補は表 `T-318` の `IP-4` の順に並ぶ（① 子を両端で含む → ② 子と重なる → ③ 端が近い）。① の中は期間の短い順、② の中は両端のずれの和の小さい順、③ の中は離れている日数の小さい順にした。この中の順は見本が置いたもので、仕様にはまだ無い。
- 絞り込みは `SV-4` と同じで、NFKC と大文字小文字をそろえた部分一致（18 の見本、36 の見本）。
- ↑↓ は端で折り返し、Enter で選ぶ。変換中の Enter は無視する（担当者欄と同じ）。
- Esc は書かずに閉じる。「親なし」は置かない（`JDG-1137`）。
- 文字の大きさは検索パネルの A ボタンと同じ 12 → 14 → 16 → 20 の巡り（`JDG-646`）。

候補は `sample-schedule/sample-large-erp-program.ja.xml` のまとめタスクから取った 41 本である。
1 つ上の行にこれだけのバーが並ぶ大きな表を想定して、長い名と似た名（「業務設計 - 生産管理」と「構築 - 生産管理」）が混ざる場合で比べた。
期間は見本のために置いたものである。
