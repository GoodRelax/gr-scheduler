# 検索パネルの [表示] 列と「チェックしたものだけ表示」 —— 触れる見本

- 作った日: 2026-10-04
- 見本: [`show-only-checked-sample.html`](show-only-checked-sample.html)（1 ファイルで完結する。ダブルクリックで開く。サーバーも通信も要らない）
- 利用者の言葉: 「新機能として「指定した担当者名だけ表示」機能を足したい。  検索パネルの一番左に[表示] チェック列をつけて、チェックしたタスクのみを表示するモードを付ける。 詳細検討用に提案チップを出せ。 取り込みタイミングはお前が調停役として決めろ。」（2026-10-04）
- 変更要求の起草: [`CR-661`](../../change-request/CR-661-the-search-panel-shows-only-the-checked-tasks.md)（起草だけ、未適用）
- 裁定: [`rulings.md`](../../docs/development-records/rulings.md) の `JDG-1375`〜`JDG-1387`（2026-10-04）。Q1〜Q5・Q7 は推奨の A。⭐ Q6 は B —— 利用者の答えは「モードも終わってOK。  編集したい場合は検索パネルを最小化すればいいでしょ？」（`JDG-1381`）。閉じれば終わり、最小化では続く

## 開き方と触り方

見本は、左上の予定表（約 16 件のタスク、依存線 9 本、里程標 2 つ）、その下に置いた動かせる検索パネル、右の「比べる択」の 3 つでできている。最初はモードが切れていて、何もチェックされていない。

4 手で一巡できる。

1. パネルの表の 担当 の見出しにあるじょうごを押し、「すべて外す」のあと「伊藤 直子」だけに印を付ける。
2. 表の一番左、[表示] の見出しにあるチェックを押す（一覧に出ている行だけが、まとめて入る）。
3. パネルの見出しにある「チェックしたものだけ表示」のトグルを押す。
4. 予定表が伊藤 直子のタスクだけになり、上に黄色い帯が出る。右の択を切り替えて、見え方の違いを見る。

| したいこと | すること |
| --- | --- |
| パネルを動かす | 見出しの帯（「検索パネル」の文字のあたり）をつかんで動かす |
| 1 件ずつ表示に入れる | 表の一番左の行ごとのチェックを押す |
| 一覧の行をまとめて入れる／外す | [表示] の見出しのチェックを押す。一覧に出ている行だけに効く。全部が入っていれば外し、一部なら全部入れる。印は「全部／一部／なし」の 3 状態で出る |
| 表示に入れた行だけ（入れていない行だけ）を一覧に出す | [表示] の見出しのじょうごを押し、「表示に入れた」「入れていない」を選ぶ |
| 担当で絞る | 担当 の見出しのじょうごを押す。上の検索枠は値の一覧を狭めるだけで、印は変わらない。「すべて入れる」「すべて外す」は、いま見えている値に効く |
| 絞り込みを閉じる | もう一度じょうごを押すか、Esc。枠の外を押しても閉じない |
| 検索語で絞る | パネル上の検索枠（タスク名か担当名の一部。大小文字は区別しない） |
| モードに入る／出る | パネル見出しのトグル。チェックが 0 件のあいだは押せない（理由が出る）。予定表の帯の「すべて表示に戻す」でも出られる（チェックは残る） |
| パネルを閉じる／開く | 見出しの [×] か Esc で閉じる。予定表の右上の「検索パネルを開く」で開く（Q6 で挙動が変わる） |
| 予定表のタスクを選ぶ | 帯を押すと外枠が付く。もう一度押すと外れる。見えていないタスクは選べない |
| 表からタスクへ飛ぶ | 表の青い下線のタスク名を押す。帯が 1 秒だけ橙の枠で点滅する。モード中の未チェックの行は Q7 に従う |
| 選んだ値を人に伝える | 右下の「伝える値」を見るか、「写す」で写す |

Esc の順序は、じょうごが開いていればじょうごだけを閉じ、開いていなければパネルを閉じる。Esc でモードを終えることはない。

チェックは、検索語や列の絞り込みを変えても動かない。行が一覧から消えても、チェックはタスクの番号で覚えている（一覧の下の件数に「うち一覧に出ていない」として出る）。

## 比べる択

| 問い | A | B | C | 推奨の理由 |
| --- | --- | --- | --- | --- |
| Q1 チェックしていないタスク | 描かない | 薄く描く（20% の不透明度、押せない） | —— | 「この人のだけ」という目的に、他人の帯は雑音になる。位置の見当は行の見出しで足りる |
| Q2 チェックしたタスクが 1 つも載らない行 | 行ごと詰める（祖先は見出しとして残す） | 行は残し、空のまま | —— | 詰めないと絞った結果が空白だらけになる。見出しが残るので所属は失われない |
| Q3 積み（重なる段） | 見えるタスクだけで積み直す | 元の段のまま（隙間が残る） | —— | 重なりが消えたら 1 段に戻るほうが、絞った結果が低く収まる |
| Q4 依存線の相手が見えないとき | 見えている側に短い線と「…」 | 線を描かない | 相手を薄く描いて線を引く | 「相手がいる」事実だけを残し、名前は「…」に載せれば分かる。C は Q2 の詰めを弱める |
| Q5 モードの入り方 | パネルの見出しのトグルで入る | 1 つでもチェックしたら自動で入る | —— | 1 件ずつ入れる途中で予定表が変わると、まとめて入れる前に画面が動いて紛らわしい |
| Q6 パネルを閉じたとき | モードは続き、帯で知らせる | モードも終わる | —— | パネルを閉じて予定表だけを見るのが、このモードの主な使い方。帯で状態は見失わない |
| Q7 未チェックの名を押したとき | そのタスクを表示に入れてから飛ぶ | モードを終えてから飛ぶ | —— | 絞り込みを壊さずに目的のタスクへ行ける。戻すときは帯のボタンで足りる |

## この見本が決めないこと

- 保存と読み込み（チェックやモードをファイルに残すか、残すならどの列で）。
- 書き出し（画像・表・交換形式で、モード中に何を出すか）。
- Agent API から見えるか、操作できるか。
- キーボード操作（チェック列の移動、トグルの手順、絞り込みの開き方）。
- 元に戻す／やり直し（チェックやモードを履歴に載せるか）。
- 行の見出しの開閉（見本の三角は飾りで、押しても動かない）。
- 依存線の経路の細かい作り（見本は肘形の簡易な経路）。

上は CR-661 で決める。この見本は、見え方の択の違いを触って比べるためのもの。
