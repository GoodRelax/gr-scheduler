### (a) と (b) —— どちらが簡素か（`JDG-910` の問い）

- **(b) は 1 か所で済む。** 今の囲みは、もともと前面の専用の層で描いている（`src/adapter/svg-renderer/schedule-task-figures.ts:609` の `aroundTaskSvg` → `:905`、層は `endOutlineParts`）。(b) はそこで「予定と実績の外接矩形」を「予定のバー（またはマイルストーン）の形そのもの」に替え、色を `S-159` にするだけで、バーを描く道には触れない。
- **(a) はバーを描く道の全部に手が入る。** `barSvg`（`:450`）と `layerSvg`（`:418`）は、予定・実績・固定・マイルストーンの層ごとに輪郭を描く。そこへ「端のタスクか」を通す必要がある。さらに太い輪郭は塗りを内側へ半分削り、輪郭はバーの層にあるので、依存線・イナズマ線・マーカーに上から切られる。
- **重ならない所では同じ絵である。** 違いは重なる所だけ —— `zoom-outline-a-own-zoom3.png` では依存線とイナズマ線が輪郭の上を通り、`zoom-outline-b-front-zoom3.png` では囲み線が上に出る。
