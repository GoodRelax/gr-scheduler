# 表の面の印 —— 触れる見本

- 作った日: 2026-10-10
- 見本: [`table-marks-sample.html`](table-marks-sample.html)（1 ファイルで完結する。ダブルクリックで開く。サーバーも通信も要らない）
- 利用者の言葉: 「フィルタを適用している列ヘッダーを緑色にしてフィルタ適用中の意図を表せ」「ソート適用については列のヘッダーの表示を緑に変えるな」（2026-10-10）
- 裁定: [`rulings.md`](../../docs/development-records/rulings.md) の `JDG-1800`〜`JDG-1829`（2026-10-10）。緑は G1（`JDG-1822`）。赤は、表示の絞り込みを掛けている表の起動アイコンと目だけ（`JDG-1813`）
- 台帳: [`defects.md`](../../docs/development-records/defects.md) の `DFC-2320`〜`DFC-2329`、[`pending-decisions.md`](../../docs/development-records/pending-decisions.md) の `PND-850`〜`PND-853`

## 触り方

| したいこと | すること |
| --- | --- |
| 列に絞り込みを掛けたことにする | 列の見出しの漏斗を押す（中身は開かない）。もう一度押すと外す |
| 並べ替えだけを掛ける | 見出しの「↑↓」を押す。緑にはならない |
| 列の絞り込みと並べ替えを戻す | 題の行の、漏斗に × の入口を押す。戻すものが無いあいだは灰色 |
| 表の Visibility を日程表に掛ける | 題の行の目を押す。目と、上のヘッダー（担当者名簿はパレット）の起動アイコンが赤くなる |
| 行を Hide にする | 一番左の表示の列のチェックを外す |
| 見え方を比べる | 右の択で G1〜G3（緑）・R1〜R2（赤）・明るい／暗いを切り替える |

## 比べた択

| 択 | 見え方 | 結果 |
| --- | --- | --- |
| G1 | 見出しのセルを `S-183`（#1f7a3d ／ #6fc98d）で塗り、字を地の色に | ⭐ 採った（`JDG-1822`） |
| G2 | セルを薄い緑に、字と漏斗を緑に | — |
| G3 | 漏斗だけを緑で塗る | — |
| R1 | 赤（`S-154` と同じ値）で箱を塗り、絵を白に | ⭐ 採った（`JDG-1828`） |
| R2 | 絵と縁だけを赤に | — |

⭐ 赤は、基準日線の朱色（#eb6101、`JDG-378`）と箱の塗りで見分けられる。表の中身は見本のための作り物で、担当者名簿の列の並び（表示・担当者名・選択・担当タスク数・担当タスク、`JDG-1827`）のうち選択の列は描いていない。
