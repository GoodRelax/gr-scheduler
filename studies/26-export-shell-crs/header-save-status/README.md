`CR-610` の 11 節の問い 2（下段の字の大きさ）を選ぶための見本である。⭐ 2026-10-01 に利用者が推奨の候補 A を選んだ（`JDG-971`、「それ以外は、全部推奨で」）。`header-save-status-sample.html` をブラウザで開くだけで動く（外のファイルを読まない）。

## 見るもの

- 見出しは、アプリの `App Header` と同じ寸法で組んだ: 入口の箱 16px（`S-138` ・ `S-141` ・ `S-237` に `S-235` を掛けた）、`Document Title` 13.3px（`S-225` × `S-235`）、上下の余白 0.375em、行の高さ 1.2。
- 5 つの見出しを縦に並べた: 基準（ファイルの状態を描かない）、いま、候補 A ・ B ・ C。各見出しの下に、測ったヘッダーの高さと、2 段の字がヘッダーの枠からはみ出した量を出す。
- 候補の字の大きさは、宿主の地の文字に `S-235`（0.6667）を掛け、上段にはその行の係数、下段には `S-210` の係数を掛けた（`FR-051` のとおり）。
- 候補の 2 段の箱は、ヘッダーの流れの中で高さを取らない（高さ 0 の箱の上下へ、2 段が均等にかかる）。⇒ どの候補もヘッダーの高さを変えない。字が大きすぎれば、ヘッダーの縁で切れる（はみ出し量が赤で出る）。
