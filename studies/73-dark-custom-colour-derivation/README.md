# 任意色のもう一方の明暗 —— 見本

- 作った日: 2026-10-24
- 見本: [`dark-custom-colour-sample.html`](dark-custom-colour-sample.html)（1 ファイルで完結する。ダブルクリックで開く）
- 不具合の行: `DFC-3394`
- 裁定: `JDG-3183`（式 A —— HSL の明るさ L を 1 − L にし、色相と彩度は動かさない）
- 変更要求: `CR-848`（起草は `CR-851` の形が決まってから）

## 触り方

- 左上のボタンでページ全体をライトとダークで切り替える。
- [色を選んだ側] で、ライトで選んだ色からダークを導くか、その逆かを選ぶ。選んだ側のモードでは 3 案とも選んだ色のまま同じ絵になる。
- [試す色を足す] で好きな色を 1 行目に足せる。
- 各セルは 1 本のタスク —— 上が予定バー（塗りと縁が任意色）、下が実績バー（塗りは今の仕様 `CV-10` で予定の色から導く）。パレットの行の右端は 表 T-294 の値。

## 3 つの式

| 案 | 式 |
|---|---|
| A 明るさの反転（採った） | L → 1 − L。色相と彩度はそのまま |
| B 今の裁定のまま | L → 1 − 0.92·L、彩度 × 0.71 |
| C 明るさだけパレットに合わせる | L → 1 − 0.92·L、彩度はそのまま |

B と C の係数は、表 T-294 のパレットの淡い 6 色（L 0.80 → 0.26、彩度 0.45 → 0.32）と白・黒・灰色の組から測った。
