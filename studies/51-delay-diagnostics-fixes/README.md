# 遅延診断の直す案 —— 触れる見本

- 作った日: 2026-10-10
- 見本: [`index.html`](index.html)（1 ファイルで完結する。ダブルクリックで開く。サーバーも通信も要らない）
- 利用者の言葉: 「機械的な作業は提案の上、人間の了承を得て、一旦ファイルを保存した後自動で修正させる。」
- 裁定: [`rulings.md`](../../docs/development-records/rulings.md) の `JDG-1940`〜`JDG-1948`
- 変更要求: [`CR-731-delay-diagnostics-fixes-what-it-can-and-helps-with-the-rest.md`](../../change-request/CR-731-delay-diagnostics-fixes-what-it-can-and-helps-with-the-rest.md)（起草済み。仕様・コードには未適用）

## 触り方

| したいこと | すること |
| --- | --- |
| 診断結果と直す案を切り替える | 遅延診断レポートの見出しの下の「診断結果」「直す案」を押す。直した後は「直した記録」も出る |
| 直す案の行を直す対象に入れる、外す | 左端のチェックを押す。直し方が「機械」の行は最初から入っている |
| 連鎖の行の動きを見る | 準備の行のチェックを外す。すぐ下の「└ 連鎖」の行も外れて押せなくなる。入れ直すと戻る |
| 選ぶ行を直す | 修正後の欄で案を選ぶ。選ぶとチェックが入る |
| 日付の候補を直す | 日付を確かめ、要るなら直してから、チェックを自分で入れる（最初は外れている） |
| 直せない行を見る | 外部の受け入れの行。灰色で、理由は行に重ねた説明に出る |
| タスクの場所を見る | 青い下線の名前を押す。日程表のその行に帯が掛かり、関わるタスクが縁取られ、プロパティパネルの該当欄が縁取られて入力できる状態になる |
| 人が直す行を順に回る | 「前へ」「次へ」を押す（選ぶ・日付の候補・手で直すの行だけを回る）。回数は「人が直す k / n」 |
| 保存して直す | 「上書きして直す」を押す。または「控えを別名で残して直す」を押し、名前を決めて「保存」（「キャンセル」なら何も直さない） |
| 直した結果を見る | 「直した記録」を見る。日時・指摘・タスク・列・修正前・修正後が並ぶ |
| 直したのを戻す | ヘッダーの「取り消し」を 1 回押す。直した全部が一度に戻る |
| 文にして持ち出す | 「.md」で文を見る。「コピー」で貼り付け用にする（書けない環境では文を出して選ばせる） |
| 行を絞る | 絞り込み欄に文字を入れる。今のタブの行だけが絞られる |
| 見え方を比べる | ヘッダーの「暗い表示」「明るい表示」を押す |

見本の中身は作り物で、日程表の絵は直した結果を確かめるための最小限にしてある。ファイルへの保存は押した感じを見せるだけで、実際には何も書かない。

## 測ったこと

| 画面 | 明るい表示 | 暗い表示 |
| --- | --- | --- |
| 1280x800 | コンソールのエラー 0 件、横スクロール 0（scrollWidth 1280 = clientWidth 1280）、レポートの窓は画面内、表の字の切れ 0 件 | 同じ |
| 1920x1080 | コンソールのエラー 0 件、横スクロール 0（scrollWidth 1920 = clientWidth 1920）、レポートの窓は画面内、表の字の切れ 0 件 | 同じ |

方法: Playwright（Chromium）で 4 通りの画面を開き、チェックの連鎖・選ぶ行の自動チェック・上書きして直す（直した記録 9 件、直す案 14 件から 5 件）・取り消しで元に戻ること・「次へ」3 回で現在行と開いた欄が合うこと・控えの保存とキャンセル・絞り込みを順に押して数えた。
