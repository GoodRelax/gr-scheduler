#### 🔄 *❓ 問 13. 命名の観点をこれでよいか*

🔄 *別のエージェントは、用語集の残りの 834 語（画面 381・MCP の説明 3・仕様とコード 450）の名を、下の観点で 1 語ずつ見ます。観点に合わない語には、直した名の案と理由を付けます。持ち主は、案のある語を 1 枚の表で判断し、案の無い語をまとめて OK します。観点は、基準書の NDD と R2 の命名の節、GRS の規則 03 の 2 節、GRS JSON の名の決まり（N-1〜N-17）、Agent API の名の決まり（P-1〜P-12）から集めました。*

| 🔄 *#* | 🔄 *観点（はい = よい）* | 🔄 *例: 悪い → 良い* |
|:---|:---|:---|
| 🔄 *V1* | 🔄 *名だけで、指す物の意味・働き・役目が読めるか。`data`・`info`・`manager`・`helper` のような何でも入る名を避けているか* | 🔄 *`TaskData` → `Task`* |
| 🔄 *V2* | 🔄 *1 つの物を、画面・仕様・コード・GRS JSON・Agent API で 1 つの名で呼んでいるか* | 🔄 *画面「作業」・コード `job`・GRS JSON `task` → 3 つとも `task`（日本語の名は「タスク」）* |
| 🔄 *V3* | 🔄 *違う物に違う名を付け、同じ物の言い換えを 1 つの名にまとめているか* | 🔄 *「期限」と「締切」が同じ物 → 1 つ* |
| 🔄 *V4* | 🔄 *品詞が働きに合うか: 物は名詞、操作は動詞と目的語、真偽は `is`・`has`・`can` で始まる肯定の句、集まりは複数形、起きた事は過去形* | 🔄 *`hasNoParent` → `isTopLevel`* |
| 🔄 *V5* | 🔄 *単位の決まった量は名に単位を持つか。範囲の名は端を含むかが読めるか（`min`・`max`・`first`・`last` は含む、`begin`・`end` は終わりを含まない）* | 🔄 *`timeout` → `timeoutMs`* |
| 🔄 *V6* | 🔄 *英語の名が正で、日本語の名は日常の言葉か（ダウンロード・インストール・フラグのように、利用者がふだん使う語）* | 🔄 *「旗」 → 「フラグ」* |
| 🔄 *V7* | 🔄 *略は許した 9 つ（`uid`・`id`・`Px`・`Utc`・`dx`・`dy`・`min`・`max`・`hex`）と、外の規格が決めた名だけか。MSPDI の名は規格のとおりに書いているか* | 🔄 *`dur` → `duration`* |
| 🔄 *V8* | 🔄 *業種の名と他社の製品の名を避けているか* | 🔄 *特定の業界の語 → 一般の語* |
| 🔄 *V9* | 🔄 *名を、指す物に照らした適切さだけで選んだか（直す手間を理由に、合わない名を残していないか）* | 🔄 *意味がずれた名を手間で残す → 意味に合う名へ改める* |
