# part root	根と帳簿
ScheduleDocument	GRS JSON の 1 ファイル
  $schema	スキーマの所（URL）
  schemaVersionUtc	スキーマの版（形が最後に変わった UTC の時刻）
  buildVersionUtc	書いた GRS のビルドの版（UTC の時刻）
  documentStamp	文書刻印
    scheduleDataUpdatedAt	データが変わった時（UTC）
    documentUpdatedAt	文書が変わった時（UTC）
    fileSavedAt	保存した時（UTC。初めて保存するまでは無い）
    lastEditedBy	最後に編集した者（型 Editor）
      type	判別子
        "user"	人が画面で編集した
        "template"	まだ誰も編集していない（ひな形のまま）
        "agent"	AI が Agent API で編集した
      name	AI が名乗った名（agent のときだけ）
  documentSettings	文書設定（下の「文書設定」）
  scheduleData	スケジュールデータ（下の 2 つの群）
  changeLogEntries[]	変更履歴
    changedAt	変更の時（UTC）
    changedBy	変更した者
      editorType	書き手の種類（GRS が自動で書く。判別子ではない）
        "user"	人が画面で書いた行
        "agent"	AI が Agent API で書いた行
      name	人が打った名か、AI が名乗った名
    affectedArea	及んだ部分
    changeDescription	何が変わったか
    reason	理由
    remarks	そのほか

TaskTableWindow	タスクの表の見せ方（検索ウィンドウ・遅延診断レポート）
  isScheduleFilteredByChecks	チェックで日程表を絞るか（チェックしたタスクだけを描く）
  checkedTaskUids[]	チェックしたタスク
  columnFilters[]	列のフィルタ（掛けた列ごとに 1 つ）-> ColumnFilter
  columnSort	表の並べ方（列と向き）-> ColumnSort
ResourceTableWindow	担当の表の見せ方（担当リスト）
  isScheduleFilteredByChecks	チェックで日程表を絞るか（チェックした担当のタスクだけを描く）
  checkedResourceUids[]	チェックした担当
  isUnassignedChecked	（担当なし）の行をチェックしたか
  columnFilters[]	列のフィルタ（掛けた列ごとに 1 つ）-> ColumnFilter
  columnSort	表の並べ方（列と向き）-> ColumnSort
ColumnFilter	列のフィルタ
  type	判別子
    "values"	値で絞る
    "dateRange"	日の範囲で絞る
  column	列（列が見せる値の名）
    "progressStatus"	検索・タスク: ステータス（進捗ステータス）
    "percentComplete"	検索・タスク、遅延診断: 進捗
    "taskType"	検索・タスク、遅延診断: タスク種別（タスクかマイルストーンか）
    "taskName"	検索・タスク、遅延診断: タスク（マイルストーン）
    "resourceNames"	検索・タスク、遅延診断: 担当名（そのタスクのすべての担当）
    "start"	検索・タスク: 予定開始
    "finish"	検索・タスク: 予定終了
    "actualStart"	検索・タスク: 実績開始
    "actualFinish"	検索・タスク: 実績終了
    "taskGroupPath"	検索・タスク: 最上位までの階層
    "text"	検索・コメントボックス: 本文
    "taskGroupName"	検索・コメントボックス: 線先が立つタスクグループの名
    "leaderTargetDay"	検索・コメントボックス: 線先が立つ日
    "diagnosisStatus"	遅延診断: ステータス（診断の結果）
    "planDates"	遅延診断: 予定日（開始〜終了）
    "actualDates"	遅延診断: 実績日（開始〜終了）
    "diagnosisReason"	遅延診断: 理由
    "resourceName"	担当リスト: 担当名
    "isSelected"	担当リスト: 選択（その担当を選んでいるか）
    "assignedTaskCount"	担当リスト: 担当タスク数
    "assignedTaskNames"	担当リスト: 担当タスク
  hiddenValues[]	隠す値（values）。状態の列は用語集の英語の名（例 finished・delay・task・selected、JDG-3735）、ほかの列はセルの値
  isBlankHidden	空の行を隠すか（values）
  firstDay	最初の日（dateRange）
  lastDay	最後の日（dateRange）
ColumnSort	並べ替え
  column	列（ColumnFilter.column と同じ値）
  direction	向き
    "ascending"	小さい順
    "descending"	大きい順
Paint	塗り
  color	色 -> Color
  opacityPercent	不透明度（%）
Stroke	線（描かないときは書かない）
  color	色 -> Color
  opacityPercent	不透明度（%）
  widthPx	太さ
ShapeStyle	形の見た目（TaskStyle・CommentBoxStyle・HighlightBoxStyle が共にする）
  fill	塗り -> Paint
  stroke	線 -> Stroke
