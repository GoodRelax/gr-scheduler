##### 🔄 *❓ 問 5-2. 台帳の名の頭の `x-`*

🔄 ***答え（慣わしです）:***

- 🔄 *JSON Schema の決まりでは、検証する道具は、自分の知らないキーワードを無視し、注記として残します。台帳 `x-grsChanges` は検証には使わない、GRS の自前の注記です。*
- 🔄 *名の頭の `x-` は、API の定めの書式 OpenAPI から広まった慣わしで、「標準のキーワードでない、自前の拡張」を名で示します。JSON Schema が後で新しいキーワードを足しても、`x-` で始まる名とはぶつかりません。*
- 🔄 *α のスキーマも同じ名 `x-grsChanges` で台帳を持っていました（今は空）。β はそれを受け継ぎ、`JDG-3765` のとおり CR-851 の 1 行を入れました。*
