## 2. 前提: GRS と、4 つのボタンの動き

GoodRelax Scheduler（GRS）は、ブラウザだけで動く日程表（ガントチャート）のアプリです。縦に **タスクグループ** と呼ぶ横長の **帯** が積まれ、帯は親子の木を作ります。画面の左の欄に帯の名が木の形で並び、各帯の名の横にボタンが並びます。例はすべてこの木で書きます（字下げが親子）。

```text
A
├─ B
│   ├─ B1
│   │   └─ B1a
│   └─ B2
└─ C
```

**縦のズームが自動で深さを決めます。** 縦に縮めると深い帯から自動で描かれなくなり、広げると戻ります。最上位の帯（深さ 1）はズームでは落ちません。人がボタンで決めた帯は、ズームより優先します。

**保存する物と、導く物（決定済み）:** 各帯は **自分自身についての人の意図** を 3 つのうち 1 つだけ保存します。

| 保存する意図 | 意味 |
|:---|:---|
| `show` | 画面に出せ（ズームで縮めても出す） |
| `hide` | 画面から消せ（ズームで広げても出さない） |
| `automatic` | ズームの深さ（とピン止めなど）に任せる |

画面に実際に出ているか（`visible`／`invisible`）は、意図とズームと木から **導く結果** で、保存しません。決まり（不変条件）: **`hide` の帯の子孫は、みな `hide`**（消えた帯の下に見える帯は作れない）。3 つの値の名（`show`・`hide`・`automatic`）は今の案で、まだ決定ではありません。

**各ボタンが書くもの（帯 B で押す）:**

| ボタン | 動き | 書く意図 | 押した帯 B 自身 |
|:---|:---|:---|:---|
| ∨ | 直下の子だけを出す。孫より下は今のまま | B の子に `show` | 書かない |
| ∨∨ | 配下をすべて出す | B の子孫すべてに `show` | 書かない |
| ∧∧ | 配下をすべて消す。B は残る | B の子孫すべてに `hide` | 書かない |
| ∧ | **B 自身を配下ごと消す**（親 A の中へしまう） | B と子孫すべてに `hide` | **`hide` にする** |

**前後の絵**（「…」は、その帯の配下が描かれていないこと）:

```text
[∨ を B で押す]        前              後
                       A               A
                       ├─ B …          ├─ B
                       └─ C            │   ├─ B1 …
                                       │   └─ B2
                                       └─ C
[∨∨ を B で押す]       前              後
                       A               A
                       ├─ B …          ├─ B
                       └─ C            │   ├─ B1
                                       │   │   └─ B1a
                                       │   └─ B2
                                       └─ C
[∧∧ を B で押す]       前              後
                       A               A
                       ├─ B            ├─ B …
                       │   ├─ B1       └─ C
                       │   │   └─ B1a
                       │   └─ B2
                       └─ C
[∧ を B で押す]        前              後
                       A               A （B は A の中へしまわれた）
                       ├─ B            └─ C
                       │   ├─ B1
                       │   │   └─ B1a
                       │   └─ B2
                       └─ C
[続けて A の ∨ を押す] 前              後
                       A               A
                       └─ C            ├─ B …（B だけ戻る。B の子は消えたまま）
                                       └─ C
```

- ∧ で消えた B を戻す専用の場所はありません。**親 A の ∨ で戻ります**（A の ∨∨ なら配下ごと戻る）。仕様はこれを「1 本の上向きで親へ折りたたみ込み、親の 1 本の下向きで戻る」と書き、∧ と親の ∨ を対として設計しています。
- **∧ の「1 段だけ畳む」版が無い理由:** 上の不変条件があるので、「B の直下の子だけを消す」は ∧∧ と同じ絵になります。上向きで中身に効く操作は 1 つしか区別できず、4 つ目の場所を「自分をしまう」が埋めています。
- 「全体を収める」（Zoom to Fit）は `show` を `automatic` へ戻し、`hide` は残します。
- **パネルの頭（帯の欄の見出し）** にも ∨・∨∨・∧∧ があります。頭は「最上位の帯のさらに上にある、深さ 0 の根（帯ではない）」として働きます。頭の ∨ は最上位の帯に `show`、∨∨ はすべての帯に `show`、∧∧ はすべての帯に `hide` を書きます。頭の ∧∧ の後は帯が 1 本も描かれず、頭の ∨ で最上位が戻ります。**頭に ∧ とピンはありません**（しまう先の親が無く、根は留められない）。
- よく知られた道具（エディタやファイルの木、表計算のアウトライン、アウトライナ、ガントの道具）に「自分ごと親へしまう」ボタンは見当たりません（これまでの調べ。記憶に基づく）。借りられる名がありません。

## 3. 私たちの今の案（審査してほしい物）

### 3-1. 原則

| # | 原則 | 中身 |
|:---|:---|:---|
| P1 | collapse／expand の目的語 | **押した帯の中身（子・子孫）だけ**。押した帯自身は残る（木の UI の慣わし: WAI-ARIA の `aria-expanded`、エディタやファイルの木など）。collapse を「自分が消える」の意味に使わない |
| P2 | ∧ だけ動詞が違う | ∧ は帯自身に効くので、collapse／expand で名づけると嘘（中身でなく自分）か遠回り（親という別の物を持ち出す）になる。∧ だけ別の動詞にするのは、名の失敗ではなく働きの事実と見る |
| P3 | 対称は「組」で作る | ∨∨ と ∧∧ は同じ範囲語 **Below** の鏡。∨ と ∧ は **親をはさんだ鏡**（∨ は帯から子を出し、∧ は帯を親へしまう。しまった帯は親の ∨ で戻る）。この対を ∧ の説明の文に書く |
| P4 | 層で語を分ける | ボタン（動詞）は Expand／Collapse 系。保存する値は `show`／`hide`／`automatic`。導く結果は `visible`／`invisible`。ボタンの名・説明の文に show・hide・visible を使わない |

### 3-2. 帯のボタンの名

| ボタン | 英語の札 | 日本語の札 | 出来事の名（今 → 案） |
|:---|:---|:---|:---|
| ∨ | Expand One Level（今のまま） | 1 階層だけ展開する（今のまま） | `oneLevelOpenPressed` → `expandOneLevelPressed` |
| ∨∨ | Expand Below（今のまま） | 配下をすべて展開する（今のまま） | `allBelowOpenPressed` → `expandBelowPressed` |
| ∧∧ | Collapse Below（今のまま） | 配下をすべて折りたたむ（今のまま） | `allBelowFoldPressed` → `collapseBelowPressed` |
| ∧ | **Collapse → Put Away** | **折りたたむ → 親へしまう** | `hidePressed` → `putAwayPressed` |

- ∧ の説明の文: 「Put this task group, with everything under it, away into its parent; the parent's Expand One Level brings it back.」／「このタスクグループを配下ごと親へしまう。親の「1 階層だけ展開する」で戻る」。
- 今の ∧ の札「Collapse」（説明「Collapse this task group itself」）は、∧∧ の Collapse Below と同じ collapse が「自分が消える」と「中身が消える」の 2 つを指しているので直す。出来事の名は、今 Open・Fold・hide に割れていて札と合わないので、札にそろえる。
- Put Away を選んだ理由: 目的語が帯自身で collapse に 2 つ目の意味を作らない。2 語で短い。英語の put away は「元の置き場へしまう」で、「親の中へしまい、親の ∨ で取り出す」に合う。製品の中のほかの語（下の 5 節）とぶつからない。
- 自分で見た弱い所: 英語の札だけでは行き先（親）を言わない。「片付けた ＝ 済んだ」と読む人がいるかもしれない。

### 3-3. 頭のボタン ＝ 帯のボタンを根で押したもの

| ボタン | 英語の札 | 日本語の札 | 出来事 |
|:---|:---|:---|:---|
| 頭の ∨ | **Expand One Level**（今は Show Top Level Only） | **1 階層だけ展開する**（今は 最も浅い段を 1 階層展開する） | 帯と同じ `expandOneLevelPressed`（押した物 ＝ 根） |
| 頭の ∨∨ | Expand All（今のまま） | すべて展開する（今のまま） | 帯と同じ `expandBelowPressed`（押した物 ＝ 根） |
| 頭の ∧∧ | Collapse All（今のまま） | すべて折りたたむ（今のまま） | 帯と同じ `collapseBelowPressed`（押した物 ＝ 根） |

- 「One Level」は押した物から見た語なので、根でもそのまま正しい。範囲語 Below は根では All と言う（見出しの Expand All／Collapse All は世の慣わし）。用語集に 1 行で書く。
- 頭の ∨ の説明の文: 「Show the top-level task groups; what is under them stays as it is.」／「最上位のタスクグループを出す。その配下は今のまま」。
- 出来事を共有するとき、根を「空の値」（null など）で運ばない。押した物が根であることを明示の印で運ぶ。

### 3-4. 根と最上位

- **根は木の節の 1 つ。根だけの保存の値を持たない。** 「根が畳まれた」＝ 最上位の帯が全部 `hide`。その結果、頭の ∧∧ の後に頭で帯を足す・検索で帯へ飛ぶと、足した帯（飛んだ先までの道）だけが出て、ほかの最上位は消えたまま（今は全部戻る）。残りは頭の ∨ 1 押しで戻る。
- **最上位の帯（深さ 1）に特別の決まりを置かない。** 「ズームで落ちない」は深さの範囲の下限（深さ 1 はいつも範囲の内）だけで言う。人の `hide` は最上位にも勝つ（頭の ∧∧ はパネルを空にしうる。戻り道は頭の ∨）。
