# 初見の質問状（1 段目）: この 4 つの名から、どんな形を思い浮かべますか

**答え方: 日本語で、1 つのコードブロック（```markdown で始めて ``` で閉じる）の中に、3 節の型で書いてください。コードブロックの外には何も書かないでください。**

## 1. 頼みたいこと

ある日程表アプリ（ガントチャート）は、タスクの期間を横長の図形で描きます。図形の形は、文書（JSON）のキー `taskShape` の値で選びます。値は 4 つあります。

```json
{ "taskShape": "rectangle" }
{ "taskShape": "chevron" }
{ "taskShape": "arrow" }
{ "taskShape": "endpointSpan" }
```

それぞれの値の名だけから、どんな形の図形を思い浮かべるかを教えてください。

- 名の意味の説明は、わざと書いていません。名だけから読んでください。
- 私たちの意図を推し量らないでください。似た製品を調べたり、ほかの資料から当てたりしないでください。欲しいのは初見の読みです。外れても構いません。外れた読みがいちばん役に立ちます。
- この答えの後に、同じ会話で 2 段目（絵と、名の問い）を送ります。

## 2. 答えに含めてほしいこと

- 4 つの値のそれぞれについて、思い浮かべた形を 1 文で言い、文字で描いた絵（例 `[======]`）を 1 つ添える。
- その形がどのくらい確かに浮かんだか（確か ／ たぶん ／ 当て推量）。
- 4 つのうち、形が浮かびにくい名があれば、どれで、なぜか。

# 質問状（2 段目）: 4 番の形に、名を付けてください

**答え方: 日本語で、1 つのコードブロック（```markdown で始めて ``` で閉じる）の中に、5 節の型で書いてください。コードブロックの外には何も書かないでください。1 段目の答えは直さないでください。**

## 1. 絵の説明

添えた絵は、4 つの値の図形を、同じタスク（3 日目に始まり 9 日目に終わる）で描いたものです。

- 1 `rectangle`: ふつうの塗りつぶしのバー。
- 2 `chevron`: 始まりに切り欠きがあり、終わりが尖ったバー。
- 3 `arrow`: 終わりに矢じりのある細い線。
- 4 （名を付けたい形）: 両端に点のある細い線。左の点が始まり、右の点が終わり。

## 2. 名が守る決まり

- JSON の値として書く。英語、ASCII、lowerCamelCase（例 `rectangle`・`endpointSpan`）。
- 兄弟の 3 つ（`rectangle`・`chevron`・`arrow`）と同じ種類の名にそろえたい。兄弟はどれも「形の名」である。
- 名だけで形が浮かぶこと（NEIM: Name Explains Its Meaning）。世界中の日程表の利用者が、初見で読める語がよい。特定の分野の専門語や、特定の製品の言葉に頼らない。
- 略語を避ける。長すぎない（目安 20 文字まで）。
- 画面に出す日本語の名も 1 つ付ける（例: rectangle ＝ 矩形、chevron ＝ 矢羽根、arrow ＝ 矢印）。

## 3. 頼みたいこと

- 4 番の形の名の候補を、あなたが良いと思う順に 3〜5 つ挙げてください。各候補に、日本語の名と、良い点・弱い点を 1 文ずつ。
- 4 節の 4 つの候補を、2 節の決まりで採点してください。

## 4. 採点してほしい候補

| 候補 | 中身 |
|:---|:---|
| `endpointSpan` | 今の名。「両端の点」と「期間の幅（span）」を言う |
| `dotEndedLine` | 「点で終わる線」と、形を字のとおりに言う |
| `spanLine` | 「期間の線」。短い |
| `dumbbell` | 2 つの点を線で結ぶ形の見立て。データの図の世界では dumbbell chart という呼び名がある |
