# 追加の質問（前回の質問状「木の 4 つのボタンの名」の続き）

**答え方: 答えはすべて日本語で、1 つのコードブロック（```markdown で始めて ``` で閉じる）の中に、末尾の型で書いてください。コードブロックの外には何も書かないでください。**

前回の答え、ありがとうございました。同じ質問状を 2 つの AI に出し、第一案は **Collapse Self** と **Collapse Into Parent** でした（どちらかがあなたの案です）。答えを照らして、その後こう決めかけています。

**決めかけている案**
- 原則: collapse／expand の目的語は **押した帯の中身だけ**（押した帯は残る）。∧ は帯自身に効くので、∧ だけ別の動詞にする（名の失敗ではなく働きの事実と見る）。
- 対称は「組」で作る: ∨∨ と ∧∧ は同じ範囲語 Below の鏡。∨ と ∧ は親をはさんだ鏡（∧ で帯を親へしまい、親の ∨ で戻す）。

| ボタン | 英語の札 | 日本語の札 | 出来事の名 |
|:---|:---|:---|:---|
| ∨ | Expand One Level | 1 階層だけ展開する | `expandOneLevelPressed` |
| ∨∨ | Expand Below | 配下をすべて展開する | `expandBelowPressed` |
| ∧∧ | Collapse Below | 配下をすべて折りたたむ | `collapseBelowPressed` |
| ∧ | **Put Away** | **親へしまう** | `putAwayPressed` |

- ∧ の説明の文: 「Put this task group, with everything under it, away into its parent; the parent's Expand One Level brings it back.」
- 頭のボタン ＝ 帯のボタンを根で押したもの: 頭の ∨ は **Expand One Level**（「Show Top Level Only」の Only は嘘なので外す）、∨∨・∧∧ は Expand All・Collapse All のまま。出来事は帯と共有し、根は明示の印で運ぶ。
- 根は木の節の 1 つで、根だけの保存の値を持たない。最上位の帯に特別の決まりを置かない。保存する値は `show`・`hide`・`automatic`。

**ところが持ち主は「putAwayか... 俺は唐突感がある。」と言いました。**（前には Collapse Into Parent に「悪くない... がなんかこうダサい」とも。）

**退けた名と理由**（前回の答えから出た物を含む）

| 名 | 退けた理由 |
|:---|:---|
| Collapse Self（第一案の 1 つ） | collapse が「中身を畳む」と「自分が消える」の 2 つの意味になる。今の札「Collapse（this task group itself）」の病そのもの |
| Collapse Into Parent（第一案の 1 つ） | 決まりはすべて満たす。だが 3 語で説明臭く、持ち主が「ダサい」と感じた |
| Fold In | 3 つ目の動詞が増える。fold はプログラムの中で ∧∧（中身を畳む）の意味にすでに使っている。英語の fold in は「混ぜ込む」とも読める |
| Open／Close の系 | open は製品で「ファイルを開く」の語。close は窓を閉じると読める |
| Reveal／Conceal の系 | reveal は製品で「その帯へ飛ぶ」の出来事の語。conceal は保存する値 `hide` の言い換え |
| Hide | 保存する値 `hide` と同じ語になり、ボタン ＝ 値と読める。表の列の Show／Hide とも同じ語 |
| Expand Children（∨） | 「各々の子を展開する（孫が出る）」と読める |
| Expand Top Level（頭の ∨） | 「最上位の帯の中身（深さ 2）を出す」と読め、働きと逆 |
