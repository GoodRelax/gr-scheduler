## 3. 冗長（R）

R1〜R30 は 3 つの型に分かれる: (a) 名をなぞるだけの真偽の説明（R1〜R9）、(b) `grs` の物の同じ説明の繰り返し（R10〜R16）、(c) 制約の繰り返し（`Only when type is …`、日時の形、真偽の「false か無いときは」、R17〜R29）、(d) 自明（R30 並べ方の向き）。`JDG-3327` は「すべてのプロパティに易しい英語の説明」を決めているので、説明を丸ごと消すかは方針の問い。→ **持ち主に問う**（どこまで削るか）。

AI-A の総評: 説明は全体として長すぎる（「This value is…」の頭、必須・既定・判別の決まりの繰り返し、`grs.passthrough` の同じ文）。
