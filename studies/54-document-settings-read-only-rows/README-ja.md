## 並べ方の規則

組も行も、「人が自分で切り替える回数が多く、いまどうなっているかを確かめたくなるもの」を上に置いた。

1. 表示の切り替え —— 予定・実績・印。切り替えると絵がいちばん大きく変わり、「今どれが出ているか」を確かめたくなる。

3. 見えている範囲 —— ズームは最もよく使う操作なので倍率を先頭に置く。送りの細かい値（日の中の位置など）は画面そのものが示すので下。
