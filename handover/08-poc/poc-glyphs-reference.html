1. 形状 5 種 — 実績は予定と同じ形状で描く

実績だけ四角にすると強い違和感が出る。予定が矢羽根なら実績も矢羽根、予定が矢印なら実績も矢印、予定がマイルストーンなら実績もマイルストーンで描く。

上下に幅がある形状（rectangle / chevron） -> 実績を内側に重ねる ＋ フェードあり 幅がない形状（arrow / endpointSpan / milestone） -> 実績を下にずらす ＋ フェードなし どちらの場合も 実績の形状 = 予定の形状

薄い帯が 1 段の占有高さ。形状ごとに縦幅が違うことを確かめる欄である （2026-07-30 の指示）。---> と *----* は === の 1/2 — 縦に薄く詰め込めることがこの形状の取り柄だから。 ◇ は 1.5 倍 — 目立たせるため。 縦幅の大小関係は フォント < 実績 < 予定（=== と >===> に対する要件。細線はラベルを内側に持てないので対象外）。

2. 色の既定

予定と実績は同一の色相。予定＝中彩度でやや薄く、実績＝高彩度で濃く。原色は使わない。青い予定に緑の実績は無し。依存線は橙で固定。

※ 予定の塗り単体は背景と 1.7:1 しかない（薄い色なので当然）。予定バーの輪郭は線が担保しており、その線は両モードで 5:1 以上ある。

3. Progress Marker（進捗マーカー）— 大きさは文字サイズから決める

固定ピクセルではなく、文字サイズを起点に決める。基準は 1920×1080・全画面・拡大率 100%・ヘッダー縦 50px。

完了(✓) 常時
中断( \ ) 常時。斜線は左上から右下
期限超過(!) 常時。未完了かつ 基準日 > finish
未完了( ) 選択したときだけ薄く
操作クリックで 未完了 → 完了 → 中断 → 未完了 と巡る
離す距離実績バー右端から固定 4px
占有幅含める（4px ＋ マーク幅）。低ズームでは先に Outline のレベルが減るので支配的にならない
非表示documentSettings.progressMarkerVisible（既定 true）

1 段の高さを下げていくと下限で止まる。下限より小さい文字が必要になったら、描画する Outline のレベルを減らすのが規則であり、文字やマークをさらに縮めることはしない。

4. Resume アイコン（中断のときだけ出る）

L 字の折れ矢印（角丸）。再開日が未定のときは出さない。

矢先の高さ = 実績バーの高さの中心 = マークの高さの中心 矢印の下端 = マークの下端

補助線が、矢先の高さと下端の位置がそれぞれ実績バーの中心・マークの下端に一致していることを示す。

5. タスクの 4 状態

「中止」は独立した状態ではない。再開日が未定の中断である。だから状態は 4 つで足りる。

未着手 actualStart が無い 進行中 actualStart があり actualFinish が無く 中断していない 中断・再開予定あり resume があり resumeValid = true 中断・再開日未定 resumeValid = false

6. イナズマ線の頂点 — 段ごとに分けて計算する

頂点の規則は 1 文。動いているべき日を過ぎているものだけ、その日に頂点を打つ。

完了 打たない 中断・再開日未定 打たない 中断 resume に打つ 未着手 start に打つ 進行中 実績バーの右端に打つ 同一行で【同じ段】に複数あるとき 最も遅れた頂点が勝つ 同一行で【段が違う】とき 段ごとに頂点を分けて計算する

赤い折れ線がイナズマ線。灰色の縦線が基準日。行 5 は 1 段に 3 タスクなので最も遅れた頂点が勝つ。行 6 は 3 段に分かれているので段ごとに頂点が分かれる。
