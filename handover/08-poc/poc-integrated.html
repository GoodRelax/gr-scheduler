PoC: 統合 — 確定した規則を 1 枚で確かめる

2. 形状の基準 — 確定内容をそのまま描いた物差し

この頁は案ではない。確定した規則を素直に描いたもので、 他の描画が正しいかを判定するために使う。

2-1. タスク形状 5 種と実績の置き方

1. 実績の形状 = 予定の形状（07 §2-2-1） 2. actualPlacement = 'inside' rectangle / chevron 実績を予定の内側に重ねる ＋ フェード掴み点あり actualPlacement = 'below' arrow / endpointSpan / milestone 実績を予定の下にずらす ＋ フェードなし 3. 幅がないタスク形状でも実績ぶんの高さを常に確保する（表示を切り替えても行の高さが動かない）

2-2. 進捗マーカー — 出うるパターンの全数

記号は 4 つだけ。完了 (✓) / 遅れ (!) / 中断 ( \ ) / 未完了 ( ) (!) を出す条件は 3 つ 1. finish を過ぎた 2. 未着手で start を過ぎた 3. 中断で resume を過ぎた 規則は 1 文「動いているべき日を過ぎたのに動いていなければ (!)」（07 §2-4） ( ) は選択したときだけ薄く出る。完了率の数字は描かない（仕様に無い） 実績バーの右端から固定 4px。実績バーが無いときは予定バーの右端から。記号は SVG で描く

2-3. 再開アイコン（Resume Icon）

中断のときだけ、進捗マーカーの右に出る 矢先の高さ = 実績バーの高さの中心 = マーカーの高さの中心 矢印の下端 = マーカーの下端 resume が空なら薄い〇。日付が入ったら resume の位置へ移り、実績バーの右端から破線で繋がる（07 §2-5）

2-4. 文字色の見本 — 何の上に載るか

文字色はライト = 黒 / ダーク = 白で固定。バーの上では背景色の縁取りを付ける（07 §2-7） 縁取りがあるので文字が接する色は常に背景色になり、比は 21:1 に固定される 予定と実績にまたがるラベルは、途中で背が変わっても読めなければならない

2-5. すべての色見本

予定と実績は同一の色相。予定=中彩度・やや薄い / 実績=高彩度・濃い（原色は使わない） 依存線は橙で固定。実績 ÷ 予定 ≧ 3:1（WCAG 1.4.11）（07 §2-6） 比は現在のテーマの実測値。テーマを切り替えると測り直す

3. マルチバー — 1 行に複数の Task が入るときの積み順

overlap が 1 つでもあれば不合格。 担当・完了率・名称・進捗マーカー・依存線をすべて描いたうえで段を割り当てる。

1. 占有区間を求める（はみ出すラベルの幅を左右に加算する） 2. 並べる順序は決定的 milestone を優先 → start 昇順 → finish 降順 → uid 昇順 3. 重ならない最も浅い段へ置く（貪欲割当） 4. stackOrder が指定されていればそれを優先（null = 自動） 5. 積み順に機能上の上限は設けない。安全弁に到達したら人に知らせる（§6-1）

4. レベル遷移 — 拡大縮小で表示が狙いどおり増減するか

3 系統（時間軸 / アイテム（軸A・WBS 深さ）/ 行階層（軸B））について、 狙った閾値と実測した遷移点を突き合わせる。 単調であること（縮小したのに表示が増える逆転が無いこと）が要件。

5. 色と縁取り — 文字を黒/白に固定したときに使える色

確定した文字色は ライト = 黒 / ダーク = 白。 この 1 つの決定が色の選び方をどこまで縛るかを数字で出し、 縁取り（文字の周りに背景色の縁を付ける）で縛りを外せるかを性能とあわせて測る。 ヘッダーの「テーマ」ボタンで両テーマとも確かめられる。

満たすべき条件
  1. 文字 ÷ 予定バー ≧ 4.5:1（WCAG 1.4.3。ラベルは 12px＝通常の文字）
  2. 文字 ÷ 実績バー ≧ 4.5:1（同上。ラベルは予定と実績の両方にまたがって載る）
  3. 実績 ÷ 予定 ≧ 3:1（WCAG 1.4.11。../07-plan-actual/handover-plan-actual-decisions-ja.md §2-6 の確定）
  4. 予定の輪郭線 ÷ 背景 ≧ 3:1（形を担保するのは線。同 §2-6）
  5. 予定の塗り ÷ 背景 ≧ 1.3:1（塗りが背景に溶けると帯として読めない）

5-1. 色相ごとの解 — 確定色からの「最小の移動」

各色相について、上記 5 条件をすべて満たす組のうち、§2-6 の確定値から最も動かさずに済む点を探す。 上段が確定値そのまま、下段が解。赤い数字が落ちている条件。

5-2. 縁取りを付けると縛りはどうなるか

文字の周りに背景色の縁（SVG の paint-order="stroke fill"）を付けると、 文字が接する色はバーではなく縁になる。条件 1 と 2 がバーの色から外れるので、 確定色（§2-6）をそのまま使える。ただし描画が重くなるなら採れない。

5-3. 縁取りの性能

大きい日程表を実際に描いて、縁取りの有無だけを変えて比べる。 文字数・要素数・その他の描画はすべて同一。
