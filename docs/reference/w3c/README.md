# Canonical XML の正本（入手手順）

**このフォルダの実体は git 管理外である。** `docs/reference/mspdi/` と `docs/reference/wcag/` と
同じ扱いで、**第三者の著作物をこのリポジトリで再配布しない**という方針による。
必要になったら下の手順で取り直す。

## 何のためにあるか

`docs/spec/05-07-design.md` の `SWS-6`（Chapter 6.1）が、**MSPDI を比べる前の正規化を
「W3C の Canonical XML に従う」と定めている。** その一次資料の置き場である。

⛔ **要約や記憶で規格を書かない。** `FR-021`（`docs/spec/01-04-requirements.md:2824`）が
挙げる 4 つの揺れは、**この原文と 1 つずつ突き合わせて確かめること。**

```
1. 属性の並び
2. 要素の間の空白と改行
3. 自己終了タグの綴り方
4. 名前空間の接頭辞
```

> ⭐ **突き合わせは済んだ**（2026-08-22）。**結果は `docs/review/c14n-vs-fr021-2026-08-22.md` が持つ。**
> ⛔ **4 つのうち覆うのは 2 つだけである** —— ①属性の並びと③自己終了タグは覆い、
> **②要素の間の空白は覆わず、④名前空間の接頭辞は半分しか覆わない**（余分な宣言は削るが接頭辞は保存する）。
> ⚠️ **`SWS-6` はまだ裁定前の文のままである。** 狭めるか補うかは、同記録の第 4 節が問うている。

## 取得

```bash
mkdir -p docs/reference/w3c
curl -sS -L -o docs/reference/w3c/xml-c14n10.html "https://www.w3.org/TR/xml-c14n10/"
curl -sS -L -o docs/reference/w3c/xml-c14n11.html "https://www.w3.org/TR/xml-c14n11/"
```

> ⛔ **短縮名 `xml-c14n` で 1.0 は取れない。** 実測（2026-08-22）で
> `https://www.w3.org/TR/xml-c14n/` は **1.1** を返す。**1.0 の短縮名は `xml-c14n10` である。**
> ⚠️ **1.0 の原文は自分の `Latest version` を `http://www.w3.org/TR/xml-c14n` と書いており、
> その先はいま 1.1 である** —— 2 本が同じ短縮名を指し、勝っているのは 1.1 のほうである。
> ⭐ **版を固定したいときは、下の表の日付入り URL を使う。**

| 事項 | 1.0 | 1.1 |
|---|---|---|
| 取得日 | 2026-08-22 | 2026-08-22 |
| 取得した版 | **W3C Recommendation 2001-03-15** | **W3C Recommendation 2008-05-02** |
| 版を固定する URL | `https://www.w3.org/TR/2001/REC-xml-c14n-20010315` | `https://www.w3.org/TR/2008/REC-xml-c14n11-20080502/` |
| 取得に使った URL | `https://www.w3.org/TR/xml-c14n10/` | `https://www.w3.org/TR/xml-c14n11/` |
| ファイル | `xml-c14n10.html` | `xml-c14n11.html` |
| バイト数 | 76,370 | 90,696 |
| SHA-256 | `09c02ef3bc0f8364b00b16fb06092637c08e8f38cf223d47a5862eacc2956bc0` | `d91a016ac03391255c64bd5f90035b292f1ee97c3ad4076ea8b33ef11fd9673f` |

> ⚠️ **ハッシュは上の取得日時点のものである。** W3C が改訂すると短縮名の中身は変わり、
> ハッシュも一致しなくなる。**一致しなかったら「改訂された」と読む**（壊れたと読まない）。
> 日付入り URL なら一致する。

## どちらの版を採るか

⭐ **`FR-021` の 4 つに対して、1.0 と 1.1 に差は出ない**（実測。記録の第 2 節）。

```
全文を節ごとに機械比較した結果
  完全一致   2.2 文書順 ／ 3.2 内容の中の空白 ／ 3.3 開始タグと終了タグ ／ 4.1 〜 4.7
  語句だけ   1.3 ／ 2.1 ／ 2.3 ／ 4.8
  本物の差   2.4 文書の部分集合（1.1 だけ 3.8 を持つ）

⭐ 1.1 が足したのは文書の部分集合の扱いだけであり、FR-021 は文書の全体を比べる
⭐ MSPDI は xml:lang / xml:base / xml:space / xml:id を 1 つも使わない（XSD で 0 件）
```

⛔ **それでも版を明記する必要はある。** ⚠️ **`SWS-6` が貼っている URL は短縮名であり、
その先はいま 1.1 である** —— 黙っていると、読む者が手にする版がその日の振り替えで決まる。
⭐ **推奨は 1.1 を日付入り URL で名指すことである**（記録の第 4 節の `Q1`）。
