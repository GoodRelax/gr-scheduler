> ## 4. 呼び出し口を作れ
>
> ⛔ **二重の正を作るな。** `package.json` には既に 50 本の script が在り、
> それが事実上の呼び出し口になっている。`.bat` を別系統で組むと、同じことを
> 2 か所が述べる形になり、必ず離れていく。
>
> ⭐ **`npm run` を正にする（利用者の裁定 2026-09-12）。**
>
> 1. **用途ごとに `npm run` を 1 本**立てる（`npm run guard:spec` のように）。
>    中身は既にある script と `check.sh` を並べるだけにする。
> 2. **`.bat` は薄い皮**にする。`npm run …` を呼ぶだけの 1 行。Explorer から
>    叩きたいときのためであって、そこに手順を書かない。
> 3. ⛔ **どの検査が赤になったかを潰すな。** `check.sh` は検査ごとに節を
>    印字する。束ねた口も同じように、**落ちた検査の名前が画面に残る**こと。
>
> ⚠️ 環境の事実: この repo に `.bat` / `.ps1` は **1 本も無い**。`check.sh` は
> bash であり、利用者は Git Bash と PowerShell の両方を持っている。`.bat` から
> bash を呼ぶ形になるので、**パスの受け渡しを実際に走らせて確かめること**。

> ## ⛔ 踏んだ罠（同じ穴に落ちるな）

>   scratchpad にファイルを書いて**パスで走らせろ**。前の巡で 6 回踏んだ。

>   試すために原稿を汚したら、戻す前にコミットしておけ。1 回踏んだ。

> - **「規則は 1 行である」と読む道具を疑え。** 前の巡で、試験 7 本・検査 3 本が
>   その思い込みで壊れた。仕様書では**規則は段落**であり、1 文ごとに行が終わる。
