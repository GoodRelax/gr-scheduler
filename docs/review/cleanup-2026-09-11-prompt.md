## 11. 進め方の作法

- ⭐ **赤を先に出せ。**直す前に「いまの造りが本当に間違っている」ことを測る（規則 04）
- ⭐ **手ごとにコミットせよ。**⛔ 週を 1 コミットに混ぜるな
- ⭐ **機械的な作業は体に投げよ**（利用者の裁定 2026-09-08）。⛔ ただし**体は委ねて止まる** —— 報告の文ではなく**木の状態を数えて**確かめること
- ⭐ **体には必ず書け**: 「原典を読め。⛔ 申し送りを信じるな。⛔ このブリーフも間違う」
- ⛔ **コミットの前に毎回、個人情報の点検を行い、実測した数を報告してから**コミットすること（利用者名・個人の絶対パス・メールアドレス・秘密が各 0 件、`.gitignore` が私的な資料を覆っていること）
- ⛔ **コミットメッセージに attribution を書くな**
- ⛔ **一時ファイルはセッションの scratchpad へ。**⛔ **このリポジトリの外のファイルを書き換えるな**（読むのはよい）
- ⛔ **コードとスクリプトは英語・ASCII で書く**（日本語の仕様書・記録は例外。逐語の引用も例外）
