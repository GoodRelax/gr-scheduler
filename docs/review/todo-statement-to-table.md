## 1. ⛔ 何が問題か —— 字数ではない

**1 つの段落に MUST が何本も入っていると、その MUST たちに住所が無い。**

| | |
|---|---|
| 表の行なら | `` 表 T-023d の `GR-5` `` と**名指せる** |
| 長い STATEMENT の中の MUST は | ⛔ **「`FR-001` の STATEMENT」としか言えない** |

⇒ ⛔⛔ **引きたい規則に住所が無いと、人は引用するしかない。**

```
健全:  `FR-011` が定める
実物:  `FR-011` は「両端を動かさないこと（MUST）」と定めている
```

**後者は参照ではない。指し先ラベルの付いた写しである。**⇒ **原本が動いても写しは動かない。**

**引き先が違う席（9）／撤回済みを現在形で引く（4）／完全性の主張が偽（5）。**

⭐ **逆の証拠もある** —— **`GR-5` や `EP-9` のような行 ID を持つ規則には、引用の腐りがほとんど無い。指せるからである。**
