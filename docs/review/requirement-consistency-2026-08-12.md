## `IC-01` 深さ 1 の行が 1 画面に収まらないとき — **Critical**

`FR-055` :1860「最も浅い階層のすべてが 1 画面に収まること（MUST）」×
`FR-077` :1834「文字が下限を割るときは、表示する行の量を減らすこと（MUST）」。
深さ 1 には畳み先が無く、`fontMin` は既定 12・**下限も 12** で下げられない。

| 案 | 内容 | 帰結 |
| --- | --- | --- |
| 1 | `FR-055` に「表示できる行数の上限を超えたときは適用しない」但し書き | 保証が条件付きになる |
| 2 | `FR-077` に「深さ 1 の行は減らさない」を加える | **文字が可読の下限を割る絵を認めることになる** |
| 3 | **行の最小高さを定め、それを超えたら保証を外してスクロールを残す** | `FR-055` 既存の方針に合流 |

**推奨: 案 3。** `FR-055` は全体について「収まることは保証しない。収まらない軸はスクロールを残す」と
既に定めており、**深さ 1 についてだけ無条件の MUST を置いたのが強すぎる。** `FR-055` 自身の
RATIONALE が「読めない絵で収まったと主張しない」と書いているので、案 2 はその理由と衝突する。

# D. `IC-68` — `FR-075` に端のぼかしをどう描くかが無い

- **重大度**: High ／ **区分**: 自動（形は公開実装から確定、既定値は 🔎 設定値）
- **箇所**: `FR-075` :899〜917

`FR-075` は「バーの端をその日数ぶん**ぼかして**描くこと」としか書いておらず、`fadeInDays` /
`fadeOutDays` を**形にどう反映するか**が無い。表も無い。「ぼかす」は視覚効果（blur）とも読めるが、
**公開実装（<https://goodrelax.github.io/gr-scheduler/>）は多角形の変形で描いている。**

## 公開実装から復元した規則（2026-08-12 に実測）

多角形の 4 点。`start` / `end` は日、`上` / `下` は行内のバーの上端 / 下端。

```
(start,           下)
(end − fadeOut,   下)
(end,             上)
(start + fadeIn,  上)
```

| 状態 | 形 |
| --- | --- |
| `fadeIn` のみ | 開始側の左辺が下から上へ傾く**台形** |
| `fadeOut` のみ | 終了側の右辺が上から下へ傾く**台形** |
| 両方 | **平行四辺形**（`fadeIn` = `fadeOut` のとき厳密に平行四辺形） |
| どちらも 0 / `null` | 矩形（要素は `rect`。フェードがあるときだけ `polygon` に差し替える） |

- **掴み点は `fadeIn` が上辺の左端、`fadeOut` が下辺の右端。** 引継ぎ資産 `ui-detail-spec-ja.md`
  の「バー左上の角 / バー右下の角」と一致する
- **掴み点は選択中のタスクにだけ出す**
- **矢羽根では別扱い**。フェード長が矢羽根の切り込み深さを置き換え、`fadeIn + fadeOut` が
  バー幅を超えるときは**両方を比例縮小**する
- **矩形では切り詰め規則が違う**。`fadeIn` を `[0, 期間]` に丸めた後、`fadeOut` を
  `[0, 期間 − fadeIn]` に丸める（**`fadeIn` が勝つ**）
- **取り込み時は丸めずに拒否する** —— 「フェードを持つタスクは終了日を持つこと」
  「`fadeIn + fadeOut` がタスク長を超えないこと」「いずれも 0 以上」

## 既定値

⚠️ **`poc-integrated.html` と `appheader-palette-icons.html` にフェードの実装は無い**
（`fade` / `taper` / `台形` / `平行四辺` いずれも 0 件）。**出どころは公開実装しか無い。**

| 用途 | 実測値 |
| --- | --- |
| 掴み点の半辺 | **4.5 px**（正方形 9 × 9 px を点の中心に置く） |
| 掴み点の枠線 | **1.5 px** |
| `fadeInDays` / `fadeOutDays` の既定 | **`null`**（0 と区別する。表 T-016 `PR-14` と一致） |
| 矢羽根の切り込み（フェード 0 のとき） | `max(2, min(バー幅 ÷ 2, バー高 ÷ 2))` px |

**すべて `tbl-settings.md` に行を立てて 🔎 を付ける。マジックナンバーとして埋めない。**

⚠️ **矩形と矢羽根で切り詰め規則が違う点は、実装がそうなっているだけで根拠が無い。**
仕様書では**どちらかに統一するのが望ましい**が、見た目に差が出るため
**骨格で実物を見てから決める**（表 T-026 `RC` に 1 行として送る）。
