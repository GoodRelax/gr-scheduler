## 5. 直しの恒等

測り方: `shots.mjs` で直す前（`23804102`）と後（層ごとの切り抜き）の 2 ビルドを、窓 1920×1080 と 1280×720、画素比 1 と 2、状態 24（起動・スクロール・Ctrl・Alt・Shift のホイール、ポインタは右下へ逃がす、時計は固定）で撮る。画面の撮影と、同じ SVG を空のページで画像として描いた絵（書き出しの道）を `cmp-shots.py` で 1 画素ずつ比べる。

- 192 枚が 1 画素も違わない。撮った画面は 24 状態のうち 18 通り。SVG の文字列は違う（切り抜きの参照 2 → 9）
- 壊した写し: 切り抜きの幅を 1 px 縮める → 48 枚すべて赤。層を切り抜かない → 48 枚すべて赤
