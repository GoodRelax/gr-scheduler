## 行と色

1 行が 1 つの持ち手である。第 1 波と第 2 波の行は、その仕事を持つ子セッション 1 つ（括弧の中はアプリの子セッションの名）。子セッション 1〜5 の行は、並行に動く子セッションの並びで、1 つの行は 1 度に 1 つのタスクだけを持つ（仕事ごとに新しい子セッションでもよい。調整役の行だけは重なってよい）。

| 色 | 意味 |
|---|---|
| 濃い灰 | 済み（実績の開始と終了を持つ。2 つの「済み」の行と、147 の再開の印。248 の棚卸しは済んだが色は緑のまま） |
| 緑 | 片付け・リファクタ・確かめ・棚卸し・道具 |
| 青 | CR の当て（不具合・新機能）と裁定の問い |
| 青緑 | AI 連携 |
| 茶 | 性能 |
| 薄い灰 | 仮置き（チェックリストで出る直しなど） |
| 紫 | 調整役の合流と関門、週の使用量の戻り |
| 橙 | 利用者の手番 |
| 赤（星） | α 版のリリース・β 版のリリース・計画の終わり |

第 1 波の 6 タスク（247・192・193・195・249・250）は実績の開始 10-22 08:15 だけを持つ（進んだ率は 0 —— 下の「スキーマで迷った点」の 1）。棚卸し 248 は実績の終わり 08:39（`f63c4948` のコミットの時刻）を持つ。

**依存線**は「前が終わってから始める」だけを使い、同じ行の中の線・調整役の合流へ集まる線は描かない（利用者の指示 2026-10-15）。描いたのは、利用者の答えを待つ所・合流の前の最後の仕事・棚卸しを待つ第 2 波の最初の仕事・リリースの手順の線だけである。⚠️ 描かない線は文書の依存にも無いので、遅延診断（`BD-2`）はその先の遅れを出さない。集まる仕事と順の決まりは、調整役の行のコメントが言う。
