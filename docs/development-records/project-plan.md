## 行と色

1 行が 1 つの持ち手である。第 1 波・第 2 波・第 2 波の後・10-24〜 の行は、その仕事を持つ子セッション 1 つ（括弧の中はアプリの子セッションの名）。子セッション 1〜5 の行は、並行に動く子セッションの並びで、1 つの行は 1 度に 1 つのタスクだけを持つ（仕事ごとに新しい子セッションでもよい。調整役の行だけは重なってよい）。済んだタスクは、同じ子セッションが一緒に当てたもの（202・206・236、204・205、217・293、241・244）が同じ実績を持ち重なる。

| 色 | 意味 |
|---|---|
| 濃い灰 | 済み（実績の開始と終了を持つ。2 つの「済み」の行と、147 の再開の印。248 の棚卸しは済んだが色は緑のまま） |
| 緑 | 片付け・リファクタ・確かめ・棚卸し・道具・この予実の更新 |
| 青 | CR の当て（不具合・新機能）と裁定の問い・CR-851 のレビュー |
| 青緑 | AI 連携 |
| 茶 | 性能 |
| 薄い灰 | 仮置き（チェックリストで出る直しなど） |
| 紫 | 調整役の合流と関門、週の使用量の戻り |
| 橙 | 利用者の手番 |
| 赤（星） | α 版のリリース・β 版のリリース・計画の終わり |

済んだタスクは実績の開始と終わりを持ち、予定の開始と終わりも実績に合わせた（アプリは予定の長さから完了率を数え直すので、合わせないと `RS-52` を告げる）。前の予定は点線の輪郭（`baselineTasks`）に残る。動いている 295・300 は実績の開始だけを持つ（進んだ率は 0 —— 下の「スキーマで迷った点」の 1）。止めて待つ W4 前半は、済んだ計画の部分を 286 に分け、27 はまだのまま置いた（中断と再開の欄 `stop`・`resume` は使っていない）。

**依存線**は「前が終わってから始める」だけを使い、同じ行の中の線・調整役の合流へ集まる線は描かない（利用者の指示 2026-10-15）。描かない線は文書の依存にも無いので、遅延診断（`BD-2`）はその先の遅れを出さない。集まる仕事と順の決まりは、調整役の行のコメントと下の「組み方」が言う。
