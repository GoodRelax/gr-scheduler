## 行と色

1 行が 1 つの持ち手である。席は並行に動くセッションで、5 つ。1 つの席は 1 度に 1 つのタスクだけを持つ（調整役の行だけは重なってよい）。

| 色 | 意味 |
|---|---|
| 濃い灰 | 済み（実績の開始と終了を持つ。2 つの「済み」の行）。この席の記録と計画だけは実績の開始だけを持つ |
| 緑 | 片付け・リファクタ・確かめ |
| 青 | CR の当て（不具合・新機能） |
| 青緑 | AI 連携 |
| 茶 | 性能 |
| 薄い灰 | 仮置き（チェックリストで出る直し） |
| 紫 | 調整役の合流と関門、週の使用量の戻り |
| 橙 | 利用者の手番 |
| 赤（星） | α 版のリリース・β 版のリリース・計画の終わり |

**依存線**は「前が終わってから始める」だけを使い、同じ行の中の線・調整役の合流へ集まる線は描かない（利用者の指示 2026-10-15）。描いたのは、利用者の答えを待つ所・合流の前の最後の仕事・リリースの手順の線だけである。⚠️ 描かない線は文書の依存にも無いので、遅延診断（`BD-2`）はその先の遅れを出さない。集まる仕事と順の決まりは、調整役の行のコメントが言う。

## 数の出し方

| 種類 | 出し方 |
|---|---|
| 済んだ仕事の実績 | 終わり = git のコミットの時刻（その仕事の最後のコミットか、統合の枝への合流）。始まり = 前の仕事の終わり、または同じ席の前のコミット。10-20 03:30 の始まりだけは推定（前のコミットが 10-19 12:13 で、あいだは休み） |
| 見積 | 大きさの段 S ＝ 2 時間・M ＝ 4 時間・L ＝ 8 時間・XL ＝ 16 時間（壁時計の時間）。前の計画の見積を持つタスクはその値 |
| 関門 | 合流 1〜2 時間・合流と `GT-2` は 3 時間・最後の PERF と `GT-2` は 6 時間 |
| 組み方 | 席ごとに順に並べ、依存の終わりより前には始めない。使用量の休みに掛かるタスクは休みの後へ送る。利用者の行は利用者の時間帯に収める。組んだ道具は記録の席の作業メモ（追跡外） |
