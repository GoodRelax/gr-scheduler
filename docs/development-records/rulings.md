### ⛔⛔ `R-04` のうち、まだ着地していないもの

⚠️⚠️ **利用者と仕様で「1 日」の意味が食い違っている。⛔ これが `R-04` を 2 度問い直させた原因である。**

```
利用者のモデル   「タスクのダミーは1日とする。 だから = は1日」（2026-09-08、逐語）
                ⇒ 開始日 = 終了日 は 1 日である
仕様の設計表     実績の右端 ＝ 開始日 ＋ 長さ（稼働日）
                ⇒ 開始日 = 終了日 ⟺ 長さ 0 日
```
⇒ **同じ言葉が 2 通りに読める。⛔ 体はこの食い違いに気づかず「実績側に穴は無い」と結論し、
前に立つ者はそれを受け入れた。**
⭐ **利用者の裁定が正である。**⇒ **「開始日 = 終了日 は 1 日である」を仕様に明記し、
ダミーの印（1 日）を押したら実績の終了日を掴むようにすること。**

⭐⭐ **着地した（2026-09-08）。****開始日 ＝ 終了日 は 1 日である、を `FR-011` の 1 か所だけに置いた。**⭐ **食い違いの正体は、位置（実績バーの右端）と日付（実績の終了日）を同じ語で呼んでいたことであった。**⛔ **だから 表 T-069 の `RV-1` と `DV-9`（`Task/Stop`）は 1 文字も変えていない**（どちらも位置を求める行であり、変えると往復が 1 日ずれる）。⭐ **変えたのは 表 T-021a の `PV-2` だけである** —— **`actualFinish` は 実績バーの右端 ではなく 実績の終了日 になった。**
