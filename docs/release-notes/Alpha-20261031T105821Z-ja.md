# GoodRelax Scheduler -- Alpha-20261031T105821Z

[English](Alpha-20261031T105821Z.md) | 日本語

- 版: `2026.1031.105821`
- タグ: `Alpha-20261031T105821Z`（ビルド版はコミット `28109ba0`、2026-10-31）
- 状態: α 版

GoodRelax Scheduler（GRS）の 2 つ目の α 版です。1 つの HTML ファイルでできた日程表のエディターで、ブラウザーで動き、インストールもサーバーも要りません。`Alpha-20261019T022508Z` の次の版で、頼まれていた 2 つの変更が入りました。基準日線を 15 分刻みで動かせます。ウィンドウにドロップしたファイルは、すぐに開きます。

## できること

- タスク・マイルストーン・依存関係で日程表を描き、日程表の上のドラッグやプロパティパネルで編集する。
- タスクグループで 1 つの行に複数のバーを置き、アウトラインを畳んで見たい粒度で見る。
- 進捗マーカーで進み具合を記し、コメントボックスとハイライトボックスを日程表に置く。
- 検索パネルと担当リストでタスクを探し、チェックした行だけを日程表に出す。
- 遅延診断を実行する。遅れる所に印を付けて理由を示し、修正案を出し、修正の記録を `.tsv` で保存する。
- すべての編集を元に戻す・やり直す。
- 英語と日本語、ライトとダークを切り替える。
- ファイルを 1 つウィンドウにドロップするか、［開く］で日程表を開く。
- GRS JSON で保存し、MSPDI（Microsoft Project の XML）を読み込み・書き出す。日程表を PNG・SVG・1 ファイルの HTML で書き出す。

## AI を使う人への新しいこと

- ダウンロードページに、AI アプリへコピーして貼る文が 2 つある。1 つは GRS を開くアドレスを AI に尋ねさせる文、もう 1 つは GRS Relay との接続がうまくいかないときに AI に自分で原因を探させる文。
- ダウンロードページは、1 つの AI デスクトップアプリでも、チャットとコードのセッションがそれぞれ自分の GRS Relay を起動し、アドレスも別になることを説明する。
- GRS Relay とサーバー連携デモは、中身が変わるまで同じ版・同じファイルのままである。だから版の番号が新しくなったら、インストールし直す新しい中身がある。
- 「日程の画像をデータ化するプロンプト」は本文だけをコピーし、同じ押下でスキーマを `grs-document.schema.json` というファイルでダウンロードする。

## 分かっている制約

- 描画は目標の 60 fps に届いていない。大きな日程表ほど遅い。
- α 版なので、版が上がると GRS JSON の形と画面が変わることがあり、古い版で保存したファイルを新しい版で開けない場合がある。使っている版の `GRS.html` を、ファイルと一緒に残しておくこと。
- スクリーンリーダーには対応していない。
- 残っている項目は [引継書](https://github.com/GoodRelax/gr-scheduler/blob/main/docs/development-records/handoff.md) と [変更要求](https://github.com/GoodRelax/gr-scheduler/tree/main/change-request) にある。

## データの置き場所

- 日程表のデータは、あなたの PC に置かれる。ファイルとしてその PC に保存し、GRS 自身はどのサーバーにも送らない。
- GRS Relay が通信する相手は、同じ PC の `127.0.0.1` だけである。
- 例外は 1 つだけ: GRS Relay を通して AI に読ませたものは、その AI アプリが、そのアプリの規約に従って扱う。
- サーバー連携デモが通信する相手は、同じ PC の上のダミーのサーバーだけである。

## インストール方法

- **ダウンロードせずに使う:** <https://goodrelax.github.io/gr-scheduler/> をブラウザーで開く。
- **オフラインで使う:** <https://goodrelax.github.io/gr-scheduler/download/>（またはこのリリースの添付ファイル）から `GRS.html` をダウンロードし、好きな場所に保存してブラウザーで開く。
- **AI と使う:** `grs-relay.mcpb` をダウンロードし、ダウンロードページの手順に従ってインストールする。
- **サーバー連携デモ（Windows）:** `grs-server-sync-demo.zip` をダウンロードして展開し、中の README に従う。
