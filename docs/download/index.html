Use GRS from Claude

Use Claude (chat) or Claude Code in the Claude desktop app.

With GRS Relay installed, Claude on your PC can read and edit the schedule you have open in GRS — for example “Which tasks are late?” or “Move the review one week later.” You keep working in GRS as usual; Claude works on the same screen. Everything you need is on this page.

What you need

  • The Claude desktop app (Claude Desktop) — for Windows or macOS, signed in. It is the app you install, not claude.ai in a browser. If you do not have it yet, get it from claude.com/download.
  • A Chromium-based browser (Google Chrome or Microsoft Edge).

You do not need to install Node.js or anything else: Claude Desktop runs GRS Relay automatically.

Download grs-relay.mcpb

Version (written when the page is published), built (written when the page is published) (UTC). Claude Desktop shows the same version in Settings › Extensions.

GRS Relay: the small program that lets Claude Desktop reach the GRS page in your browser. It already contains the same GRS as GRS.html above.

Steps

  1. Download grs-relay.mcpb with the button above.
  2. Install it in Claude Desktop. Open Settings › Extensions in Claude Desktop, and drag grs-relay.mcpb onto the place that says Drag .MCPB or .DXT files here to install.
  3. A screen for GRS Relay opens. Click Install, and click Install again when asked to confirm.
    Do not drag and drop the file onto the chat box: that only attaches it to a message and installs nothing. Double-clicking the file does not install it either.
    Claude Desktop shows a red warning that the extension gets access to everything on your computer and that its developer is not verified by Anthropic. It says this for every extension that is not from its directory. GRS Relay comes from this page; all it does is serve the GRS page on 127.0.0.1 and carry Claude’s calls to it. It writes only the files Claude saves for you, and only into the save folder you choose (below).
  4. Check that it is on. In Settings › Extensions, open GRS Relay: the Enabled switch is on.
  5. Ask Claude for the address of the GRS page. In Claude Desktop, start a new conversation in Claude Code (or Claude (chat)) and send this text as it is: 
    Call agentApiVersion of GRS Relay and show the pageUrl it returns exactly, including everything after #.
    If Claude asks whether it may use a tool of GRS Relay, allow it. Claude answers with an address that starts with http://127.0.0.1: and has a long part after #. If it does not, see Claude gives no address below.
    The address differs between Claude (chat) and Claude Code. Open the address you got where you will work with Claude.

    We plan to make asking for the address simpler in the beta.

  6. Open that address in your browser. Copy the whole address, including the part after #, and open it in a new tab. GRS opens.
  7. Open your schedule in that tab with the Open… button in the header. You can also try it with the sample that is shown.
    Use this tab for work with Claude. A GRS.html you opened from a file on your PC does not connect to Claude.
  8. Press the Agent API button in the header so that it looks pressed. The tab is now connected.
  9. Ask Claude what you want. For example: Read the schedule open in GRS and list the tasks that are late. Changes Claude makes appear on your screen at once. You can undo them like your own edits.
  10. Save as usual with Save As… in that tab. You can also ask Claude to save, for example Save it as plan.json. Claude then saves into the GRS Relay’s save folder and tells you where the file is.

Where Claude saves files, and how to change it

By default Claude saves into the folder GRS under your Documents folder. To change it: in Claude Desktop open Settings › Extensions, click Configure on the GRS Relay row, pick a folder with Browse in the Save folder field (the default is ${DOCUMENTS}/GRS), and click Save.

If your Documents folder is moved to OneDrive, the default is C:\Users\<name>\Documents\GRS. That is not the Documents folder Explorer shows (C:\Users\<name>\OneDrive\Documents). If you want the files somewhere else, pick the folder with Browse.

Confirm before overwrite (on by default) decides what happens when you ask Claude to save and a file with the same name is already in the save folder:

  • On: GRS Relay first refuses to replace the file, and Claude asks you whether it may. The file is replaced only after you say yes.
  • Off: the file is replaced without asking.

Either way, the file as it was before is kept in the same folder as the original name plus .bak (for example plan.json.bak). Only one is kept: the next replacement turns the newer old file into the .bak.

Each time Claude Desktop starts GRS Relay again (for example when the app restarts), the address changes and the tab disconnects. Ask Claude for the address again (step 5), open it, open your file, and press Agent API again (steps 6 to 8). Save your work before you quit Claude Desktop.

What Claude can and cannot do

It can

  • Read the schedule open in the tab: tasks, dates, what you have selected, search results and the delay diagnostics report.
  • Edit it. Every change goes through the same checks as your own edits, shows on screen at once, and can be undone.
  • Bring in another document’s contents, and hand back the schedule as GRS JSON, MS Project XML, an image or one HTML file.
  • Show or jump to tasks, and wait for your edits.

It cannot

  • Open or save files on your PC. You open and save in the GRS tab.
  • Work while the tab is closed or Agent API is off. It then answers that no GRS page is connected.
  • Connect to two GRS tabs at once. Only the first tab connects.
  • Edit read-only task groups, or write while you are dragging or still typing in a field.
  • Be reached from another computer.

What stays on your PC

  • GRS Relay runs on your PC and listens only on 127.0.0.1 (this computer). Other computers cannot connect to it.
  • Your schedule stays in the browser tab. GRS Relay keeps no copy and saves nothing. GRS itself sends nothing to the internet.
  • Only the tab that GRS Relay served, with the secret key of this start in its address, can connect. Other web pages cannot.
  • But what Claude reads becomes part of your chat and goes to the AI service (Claude) like anything you type. Let Claude read only a schedule you would also paste into the chat.

Turn it off or remove it

  • To stop for now, press Agent API again in the GRS tab. What Claude has already read cannot be taken back.
  • To turn GRS Relay off, open GRS Relay in Settings › Extensions of Claude Desktop and switch Enabled off. To remove it, click Uninstall there.

  that a GRS Relay tool returns while no page is connected.
  agentApiVersion is the lightest tool.

  Search the tools for "agentApiVersion" or "GRS_Relay"
  (names look like mcp__GRS_Relay__agentApiVersion).

  All Claude Code conversations share one address; the chat has a different one.

  Possible reasons: the extension is disabled (Settings › Extensions);
  Claude Desktop was not fully quit and started again after installing it
  (quit from the notification area icon, and check Task Manager for a Claude left running);
  this conversation was started before the extension was installed.

    Then send the text again in a new conversation. If that still does not help, try it once in Claude (chat), and then try again in Claude Code.
  • Claude says no GRS page is connected. Open the address it gives you (the whole address, with the part after #) and press Agent API in that tab.
  • The address does not open. Claude Desktop has started again, so the address has changed. Ask Claude for the address again.
  • Agent API is pressed but nothing connects. Check that you are in the tab opened from the address, not in a GRS.html opened from a file. Close other tabs with the same address: only one tab connects.
Other ways and checks (for advanced users)

Run GRS Relay with Node.js yourself

It may also work with AI apps other than Claude, but this has not been checked. For an AI app that starts MCP servers as a command, with Node.js 18 or later installed on your PC: download grs-relay.mjs (the same relay as one file) and register the command node with the saved file as its argument, for example:

{
  "mcpServers": {
    "grs-relay": { "command": "node", "args": ["FOLDER/grs-relay.mjs"] }
  }
}

Replace FOLDER with the folder where you saved the file. GRS Relay also writes the address to open to its error output.

Use it from Claude Code on the command line

With Node.js 18 or later, save grs-relay.mjs as above and run, in a terminal:

claude mcp add --transport stdio grs-relay -- node FOLDER/grs-relay.mjs

Replace FOLDER with the folder where you saved the file, then check with /mcp in Claude Code that grs-relay is connected. From step 5 on, ask Claude Code on the command line instead of Claude (chat).

Check the download

Claude から GRS を使う

Claude のデスクトップアプリの Claude（チャット）か Claude Code で使います。

GRS Relay をインストールすると、PC 上の Claude が、GRS で開いている日程を読んだり修正したりできます —— たとえば「遅れているタスクはどれ？」「レビューを 1 週間後ろへ動かして」。GRS はいつもどおり使えて、Claude は同じ画面上で作業します。必要な情報は、すべてこのページにあります。

必要なもの

  • Claude のデスクトップアプリ（Claude Desktop） —— Windows または macOS 用で、サインイン済みのもの。ブラウザで開く claude.ai ではありません。まだお持ちでなければ claude.com/download からダウンロードしてください。
  • Chromium 系のブラウザ（Google Chrome または Microsoft Edge）。

Node.js などのインストールは不要です。中継（GRS Relay）は Claude Desktop が自動で動かします。

grs-relay.mcpb をダウンロード

版 （ページの公開のときに書かれます）、ビルド （ページの公開のときに書かれます）（UTC）。Claude Desktop の 設定 › 拡張機能 にも同じ版が出ます。

GRS Relay（中継）: Claude Desktop からブラウザの GRS のページへ届くようにする小さなプログラムです。上の GRS.html と同じ GRS を内蔵しています。

手順

  1. 上のボタンで grs-relay.mcpb をダウンロードします。
  2. Claude Desktop にインストールします。Claude Desktop で 設定 › 拡張機能 を開き、「.MCPBまたは.DXTファイルをここにドラッグしてインストールしてください」と書かれた所へ、grs-relay.mcpb をドラッグ & ドロップしてください。
  3. GRS Relay の画面が開くので、右上の インストール を押してください。「GRS Relayをインストールしますか？」と聞かれたら、もう一度 インストール を押します。
    チャットの入力欄へドラッグ & ドロップしないでください。メッセージに添付されるだけで、インストールされません。ファイルをダブルクリックしてもインストールされません。
    GRS Relay の画面には「インストールすると、この拡張機能にコンピュータ上のすべてのデータへのアクセス権が付与されます。…」という赤い警告が出ます。ディレクトリに載っていない拡張機能には、必ずこの警告が出ます。GRS Relay の配布元はこのページです。GRS Relay がするのは、GRS のページを 127.0.0.1 で提供し、Claude からの呼び出しをそこへ中継することだけです。書き込むのは、Claude に保存させたファイルを、あなたが決めた保存先のフォルダ（下）へ書くときだけです。
  4. 有効になっているか確認します。設定 › 拡張機能 の「コンピューターにインストール済み」で GRS Relay の 設定 を押し、有効 のスイッチがオンなら大丈夫です。
  5. GRS のページのアドレスを Claude に尋ねます。Claude Desktop の Claude Code（または Claude（チャット））で新しい会話を始め、次の文をそのまま送ってください。 
    GRS Relay の agentApiVersion を呼び、返ってきた pageUrl を # 以降まで一字も変えずに示せ。
    GRS Relay のツールの使用許可を Claude が求めたら、許可してください。Claude は http://127.0.0.1: で始まり、# の後ろに長い文字列が続くアドレスを答えます。答えないときは、下の Claude がアドレスを答えない を見てください。
    アドレスは Claude（チャット）と Claude Code で別々です。Claude と作業する所で尋ねたアドレスを開いてください。

    アドレスを尋ねる手順は、β 版で簡単にする予定です。

  6. そのアドレスをブラウザで開きます。# の後ろまで含めて、アドレスをまるごとコピーし、新しいタブで開いてください。GRS が開きます。
  7. そのタブで日程を開きます。ヘッダーの 開く ボタン を使います。表示されている見本で試すこともできます。
    Claude と作業するときは、このタブを使ってください。PC のファイルから開いた GRS.html は Claude に接続できません。
  8. ヘッダーの Agent API ボタン を押して、押された見た目にします。これでタブが接続されました。
  9. Claude に頼みたいことを伝えます。たとえば: GRS で開いている日程を読んで、遅れているタスクを挙げて。 Claude が加えた変更は、すぐ画面に出ます。自分の編集と同じように取り消せます。
  10. いつもどおり保存します。そのタブの 書き出して保存 を使ってください。plan.json で保存して。 のように Claude に保存を頼むこともできます。Claude は GRS Relay の保存先のフォルダへ保存し、ファイルの場所を答えます。

Claude が保存する場所と、その変え方

既定では、ドキュメントの下の GRS フォルダに保存します。変えるには、Claude Desktop で 設定 › 拡張機能 を開き、GRS Relay の行の 設定 ボタンを押し、Save folder の欄（既定は ${DOCUMENTS}/GRS）で 参照 を押してフォルダを選び、保存 を押します。

ドキュメントフォルダを OneDrive へ移している PC では、既定は C:\Users\<name>\Documents\GRS です。これはエクスプローラーの「ドキュメント」（C:\Users\<name>\OneDrive\Documents）ではありません。別の場所に置きたいときは、参照 でフォルダを選んでください。

Confirm before overwrite（上書きの前に確認する。既定はオン）は、Claude に保存を頼んだとき、保存先のフォルダに同じ名前のファイルが既にある場合の動きを決めます。

  • オン: GRS Relay はいったん置き換えを断り、Claude が「置き換えてよいか」をあなたに尋ねます。あなたが許したときだけ置き換えます。
  • オフ: 尋ねずに置き換えます。

どちらでも、置き換える前のファイルは、同じフォルダに「元の名前＋.bak」（例: plan.json.bak）として残ります。残るのは 1 つだけで、次に置き換えると、その直前のファイルが新しい .bak になります。

Claude Desktop が GRS Relay を再起動するたびに（アプリを再起動したときなど）、アドレスが変わり、タブとの接続が切れます。もう一度 Claude にアドレスを尋ね（手順 5）、開き、ファイルを開き、Agent API を押し直してください（手順 6〜8）。Claude Desktop を終える前に、作業を保存してください。

Claude にできること・できないこと

できること

  • タブで開いている日程を読む —— タスク、日付、選んでいるもの、検索の結果、遅延診断のレポート。
  • 日程を直す。どの変更も自分の編集と同じ検査を通り、すぐ画面に出て、取り消せます。
  • 別の文書の中身を取り込む。日程を GRS JSON・MS Project の XML・画像・単体 HTML ファイルとして受け取る。
  • タスクを表示したり、そのタスクへ移動したりする。あなたの編集を待つ。

できないこと

  • PC のファイルを開く・保存する。開くのも保存するのも、GRS のタブで行います。
  • タブが閉じているとき、Agent API がオフのときに作業する。そのときは、GRS のページが接続されていないと答えます。
  • 2 つの GRS のタブに同時に接続する。接続できるのは最初の 1 つだけです。
  • 読み取り専用のタスクグループを直す。あなたがドラッグしている間や、欄に入力している途中に書き込む。
  • ほかのコンピューターから接続する。

PC の外へ出ないもの

  • GRS Relay はあなたの PC で動き、127.0.0.1（このコンピューター）でだけ待ち受けます。ほかのコンピューターからは接続できません。
  • 日程はブラウザのタブの中にあります。GRS Relay はコピーを持たず、何も保存しません。GRS 自身はインターネットへ何も送りません。
  • 接続できるのは、GRS Relay が提供したタブのうち、起動ごとの秘密の鍵をアドレスに含むものだけです。ほかの Web ページからは接続できません。
  • ただし、Claude が読んだ内容はチャットの一部になり、あなたが打った文と同じように AI のサービス（Claude）へ送られます。チャットに貼ってもよい日程だけを Claude に読ませてください。

止める・取り除く

  • いったん止めるときは、GRS のタブで Agent API をもう一度押します。Claude が既に読んだものは取り戻せません。
  • GRS Relay を無効にするときは、Claude Desktop の 設定 › 拡張機能 で GRS Relay の 設定 を押し、有効 のスイッチをオフにします。削除するときは、同じ画面の アンインストール を押します。

うまくいかないとき

  • Claude がアドレスを答えない・GRS Relay を知らない。下の文をコピーして、Claude Code（または Claude（チャット））の新しい会話に貼って送ってください。Claude が自動で原因を調べます。 
    【目的】
私は GoodRelax Scheduler（GRS）の日程を、あなた（Claude）に読み書きしてもらいたい。
そのために、GRS のページをブラウザで開いて、あなたと接続したい。
開くべきページのアドレスを、私に教えてほしい。

【手がかり】
- GRS Relay は、Claude Desktop に拡張機能としてインストールした MCP サーバーです。
  GRS のページを http://127.0.0.1:<口の番号>/#<鍵> というアドレスで出しています。
- アドレスは、ページが接続されていないときに GRS Relay のツールが返す断り
  （reason が pageNotConnected）の pageUrl の欄に入っています。
  agentApiVersion がいちばん軽いツールです。
  答えが普通の値（日時）なら、ページはもう接続されていて、アドレスは要りません。
- Claude Code では、ツールの説明が最初は読み込まれていないことがあります。
  ツールを「agentApiVersion」や「GRS_Relay」で検索してください
  （名前は mcp__GRS_Relay__agentApiVersion のような形です）。
- Claude（チャット）と Claude Code は、別々の GRS Relay を動かすので、アドレスも別です。
  Claude Code の会話どうしは同じアドレスで、チャットのアドレスとは違います。
- この会話に GRS Relay のツールが一つも無いなら、拡張機能がこの会話に渡っていません。
  考えられる理由は、拡張機能が無効になっている（設定 › 拡張機能）、
  インストールした後に Claude Desktop を完全に終了して起動し直していない
  （通知領域のアイコンから終了し、タスクマネージャーで Claude が残っていないか確かめる）、
  拡張機能をインストールする前にこの会話を始めた、などです。

【お願い】
- 自分で調べて、アドレスを # の後ろまでまるごと教えてください。
- 出せないときは、原因と、私が次にすることを、短い言葉で教えてください。
- アドレスを推測で作らないでください。
    「起動し直して」と言われたら、Claude Desktop を終了して、起動し直してください。ウィンドウを閉じるだけでは終了しません。
    • Windows: 画面右下の通知領域にある Claude のアイコンを右クリックして、終了（英語の画面では Exit）を選びます。そのあと Ctrl+Shift+Esc でタスクマネージャーを開き、プロセス に Claude が残っていないことを確かめます。残っていたら、それを選んで タスクを終了 を押します。
    • macOS: メニューの Claude › Claude を終了（⌘Q）を選びます。
    それから、新しい会話でもう一度送ってください。それでも駄目なときは、一度 Claude（チャット）で送って試し、そのあと Claude Code で試してください。
  • GRS のページが接続されていないと Claude が言う。Claude が示すアドレスを（# の後ろまでまるごと）開き、そのタブで Agent API を押してください。
  • アドレスが開かない。Claude Desktop が再起動したため、アドレスが変わっています。もう一度 Claude にアドレスを聞いてください。
  • Agent API を押したのに接続できない。ファイルから開いた GRS.html ではなく、アドレスから開いたタブを使っているか確かめてください。同じアドレスのタブがほかにあれば閉じてください —— 接続できるのは 1 つのタブだけです。
ほかの使い方と確かめ方（詳しい人向け）

Node.js で GRS Relay を自分で動かす

Claude 以外の AI アプリでも使える可能性がありますが、動作は確認していません。MCP サーバーをコマンドとして起動する AI アプリで、PC に Node.js 18 以降が入っているときは、grs-relay.mjs（同じ GRS Relay を 1 つのファイルにしたもの）をダウンロードし、コマンド node と、引数に保存したファイルを登録します。例:

{
  "mcpServers": {
    "grs-relay": { "command": "node", "args": ["FOLDER/grs-relay.mjs"] }
  }
}

FOLDER は、ファイルを保存したフォルダに置き換えてください。GRS Relay は、開くアドレスをエラー出力にも書きます。

コマンドラインの Claude Code から使う

Node.js 18 以降があれば、上のとおり grs-relay.mjs を保存し、ターミナルで次を実行します。

claude mcp add --transport stdio grs-relay -- node FOLDER/grs-relay.mjs

FOLDER は、ファイルを保存したフォルダに置き換えてください。Claude Code で /mcp を打ち、grs-relay が接続されていることを確かめます。手順 5 からは、Claude（チャット）の代わりにコマンドライン版の Claude Code に頼みます。

ダウンロードしたものを確かめる

grs-relay.mcpb.sha256 には grs-relay.mcpb の SHA-256 が書かれています。パッケージに署名はありません。どのソースからビルドしたかは、ビルドの来歴の証明に記録されています。

このページに、インストールの手順がすべて載っています。ほかの説明書は不要です。
