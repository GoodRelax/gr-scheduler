Get GoodRelax Scheduler (GRS)

GRS is one HTML file. Save it anywhere and open it in a Chromium-based browser such as Google Chrome or Microsoft Edge. Nothing to install, and it works offline.

Download GRS.html

To update, download it again here and use the new file instead of the old one. Your schedule files are separate files and are not changed.

Use GRS from an AI app (AI integration)

Use the Chat tab of the Claude desktop app. GRS relay does not work in Claude on the web (claude.ai in a browser) or on a phone. To use it from Claude Code, see “Other ways and checks” at the bottom.

With the AI integration, the AI app on your PC can read and edit the schedule you have open in GRS — for example “Which tasks are late?” or “Move the review one week later.” You keep working in GRS as usual; the AI works on the same screen. Everything you need is on this page.

What you need

  • The Claude desktop app (Claude Desktop) — for Windows or macOS, signed in. It is the app you install, not claude.ai in a browser. If you do not have it yet, get it from claude.com/download.
  • A Chromium-based browser (Google Chrome or Microsoft Edge).

You do not need to install Node.js or anything else: Claude Desktop runs the relay by itself.

Download grs-relay.mcpb

GRS relay: the small program that lets Claude Desktop reach the GRS page in your browser. It already contains the same GRS as GRS.html above.

Steps

  1. Download grs-relay.mcpb with the button above.
  2. Install it in Claude Desktop. Open Settings › Extensions in Claude Desktop. Then do one of these:
    • drag grs-relay.mcpb onto that page, where it says Drag .MCPB or .DXT files here to install, or
    • click Advanced settings, and in the Extension Developer section click Install Extension…, then choose the file.
    A screen for GRS relay opens. Click Install.
    Do not drop the file into the chat box: that only attaches it to a message and installs nothing. Double-clicking the file does not install it either.
    Claude Desktop shows a red warning that the extension gets access to everything on your computer and that its developer is not verified by Anthropic. It says this for every extension that is not from its directory. GRS relay comes from this page; all it does is serve the GRS page on 127.0.0.1 and carry the AI’s calls to it. It does not read or change your files.
  3. Check that it is on. In Settings › Extensions, open GRS relay: the Enabled switch is on.
  4. Ask Claude for the address of the GRS page. Open the Chat tab of Claude Desktop (not Code), start a new chat and send: Use GRS relay and tell me the address to open the GRS page. If Claude asks whether it may use a tool of GRS relay, allow it. Claude answers with an address that starts with http://127.0.0.1: and has a long part after #.
  5. Open that address in your browser. Copy the whole address, including the part after #, and open it in a new tab. GRS opens.
  6. Open your schedule in that tab with the Open button in the header. You can also try it with the sample that is shown.
    Use this tab for work with the AI. A GRS.html you opened from a file on your PC does not connect to the AI.
  7. Press the Agent API button in the header so that it looks pressed. The tab is now connected.
  8. Ask Claude what you want. For example: Read the schedule open in GRS and list the tasks that are late. Changes the AI makes appear on your screen at once. You can undo them like your own edits.
  9. Save as usual with Save to File in that tab. The relay saves nothing for you.
Each time Claude Desktop starts again, the address changes. Ask Claude for the address again (step 4), open it, open your file, and press Agent API again (steps 5 to 7). Save your work before you quit Claude Desktop.

What the AI can and cannot do

It can

  • Read the schedule open in the tab: tasks, dates, what you have selected, search results and the delay diagnostics report.
  • Edit it. Every change goes through the same checks as your own edits, shows on screen at once, and can be undone.
  • Bring in another document’s contents, and hand back the schedule as GRS JSON, MS Project XML, an image or one HTML file.
  • Show or jump to tasks, and wait for your edits.

It cannot

  • Open or save files on your PC. You open and save in the GRS tab.
  • Work while the tab is closed or Agent API is off. It then answers that no GRS page is connected.
  • Connect to two GRS tabs at once. Only the first tab connects.
  • Edit read-only rows, or write while you are dragging or still typing in a field.
  • Be reached from another computer.

What stays on your PC

  • The relay runs on your PC and listens only on 127.0.0.1 (this computer). Other computers cannot connect to it.
  • Your schedule stays in the browser tab. The relay keeps no copy and saves nothing. GRS itself sends nothing to the internet.
  • Only the tab that the relay itself served, with the secret key of this start in its address, can connect. Other web pages cannot.
  • But what the AI reads becomes part of your chat with Claude and goes to the AI service like anything you type. Let the AI read only a schedule you would also paste into the chat.

Turn it off or remove it

  • To stop for now, press Agent API again in the GRS tab. What the AI has already read cannot be taken back.
  • To turn the relay off, open GRS relay in Settings › Extensions of Claude Desktop and switch Enabled off. To remove it, click Uninstall there.

If something does not work

  • Claude says no GRS page is connected. Open the address it gives you (the whole address, with the part after #) and press Agent API in that tab.
  • The address does not open. Claude Desktop has started again, so the address has changed. Ask Claude for the address again.
  • Agent API is pressed but nothing connects. Check that you are in the tab opened from the address, not in a GRS.html opened from a file. Close other tabs with the same address: only one tab connects.
  • Claude does not know GRS relay. Check step 3, then start a new chat.
Other ways and checks (for advanced users)

Run the relay with Node.js yourself

For an AI app that starts MCP servers as a command, with Node.js 18 or later installed on your PC: download grs-relay.mjs (the same relay as one file) and register the command node with the saved file as its argument, for example:

{
  "mcpServers": {
    "grs-relay": { "command": "node", "args": ["FOLDER/grs-relay.mjs"] }
  }
}

Replace FOLDER with the folder where you saved the file. The relay also writes the address to open to its error output.

Use it from Claude Code

With Node.js 18 or later, save grs-relay.mjs as above and run, in a terminal:

claude mcp add --transport stdio grs-relay -- node FOLDER/grs-relay.mjs

Replace FOLDER with the folder where you saved the file, then check with /mcp in Claude Code that grs-relay is connected. From step 4 on, ask Claude Code instead of the Chat tab.

The Code tab of the Claude desktop app also gets GRS relay once it is installed in Settings › Extensions. The Chat tab and the Code tab each start their own relay, so each has its own address: ask for the address in the tab you are using.

Check the download

grs-relay.mcpb.sha256 holds the SHA-256 of grs-relay.mcpb. The bundle is not signed; the build records which source it was made from (a build provenance attestation).

This page holds every step of the setup. You do not need another manual.

GoodRelax Scheduler（GRS）を入手する

GRS は 1 つの HTML ファイルです。好きな場所に保存し、Google Chrome や Microsoft Edge など Chromium 系のブラウザで開いてください。インストールは不要で、オフラインでも動きます。

GRS.html をダウンロード

新しい版にするときは、ここでもう一度ダウンロードし、古いファイルの代わりに使ってください。日程のファイルは別のファイルなので、変わりません。

AI のアプリから GRS を使う（AI 連携）

Claude のデスクトップアプリの Chat（チャット）タブで使います。ブラウザで開く claude.ai や、スマートフォンの Claude では使えません。Claude Code から使うときは、いちばん下の「ほかの使い方と確かめ方」を見てください。

AI 連携を入れると、PC の AI のアプリが、GRS で開いている日程を読んだり直したりできます —— たとえば「遅れているタスクはどれ？」「レビューを 1 週間後ろへ動かして」。GRS はいつもどおり使えて、AI は同じ画面の上で作業します。必要なことは、すべてこのページに書いてあります。

必要なもの

  • Claude のデスクトップアプリ（Claude Desktop） —— Windows または macOS 用で、サインイン済みのもの。ブラウザで開く claude.ai ではありません。まだ無ければ claude.com/download から入手してください。
  • Chromium 系のブラウザ（Google Chrome または Microsoft Edge）。

Node.js などを入れる必要はありません。取次（relay）は Claude Desktop が自分で動かします。

grs-relay.mcpb をダウンロード

GRS relay（取次）: Claude Desktop がブラウザの GRS のページへ届くようにする小さなプログラムです。上の GRS.html と同じ GRS を中に持っています。

手順

  1. 上のボタンで grs-relay.mcpb をダウンロードします。
  2. Claude Desktop に入れます。Claude Desktop で Settings › Extensions を開き、次のどちらかを行ってください（日本語の表示では、同じ場所にある対応する項目です）。
    • そのページの Drag .MCPB or .DXT files here to install と書かれた所へ、grs-relay.mcpb をドラッグして落とす。
    • Advanced settings を押し、Extension Developer の欄の Install Extension… を押して、ファイルを選ぶ。
    GRS relay の画面が開きます。Install を押してください。
    チャットの入力欄へ落とさないでください。メッセージに添付されるだけで、入りません。ファイルをダブルクリックしても入りません。
    Claude Desktop は「この拡張はコンピューターのすべてに触れられる」「作り手を Anthropic は確かめていない」という赤い警告を出します。一覧に載っていない拡張には、いつもこの警告が出ます。GRS relay の出どころはこのページで、することは、GRS のページを 127.0.0.1 で配り、AI の呼び出しをそこへ運ぶことだけです。あなたのファイルを読んだり変えたりはしません。
  3. 有効になっているか確かめます。Settings › Extensions で GRS relay を開き、Enabled のスイッチが入っていれば大丈夫です。
  4. GRS のページのアドレスを Claude に聞きます。Claude Desktop の Chat タブ（Code タブではなく）で新しいチャットを始め、次のように送ってください。 GRS relay を使って、GRS のページを開くアドレスを教えて。 GRS relay の道具を使ってよいかを Claude が尋ねたら、許可してください。Claude は http://127.0.0.1: で始まり、# の後ろに長い文字列が続くアドレスを答えます。
  5. そのアドレスをブラウザで開きます。# の後ろまで含めて、アドレスをまるごと写し、新しいタブで開いてください。GRS が開きます。
  6. そのタブで日程を開きます。ヘッダーの 開く ボタン を使います。表示されている見本で試すこともできます。
    AI と作業するときは、このタブを使ってください。PC のファイルから開いた GRS.html は AI とつながりません。
  7. ヘッダーの Agent API ボタン を押して、押された見た目にします。これでタブがつながりました。
  8. Claude に頼みたいことを伝えます。たとえば: GRS で開いている日程を読んで、遅れているタスクを挙げて。 AI が加えた変更は、すぐ画面に出ます。自分の編集と同じように取り消せます。
  9. いつもどおり保存します。そのタブの 書き出して保存 を使ってください。取次は何も保存しません。
Claude Desktop を起動し直すたびに、アドレスが変わります。もう一度 Claude にアドレスを聞き（手順 4）、開き、ファイルを開き、Agent API を押し直してください（手順 5〜7）。Claude Desktop を終える前に、作業を保存してください。

AI にできること・できないこと

できること

  • タブで開いている日程を読む —— タスク、日付、選んでいるもの、検索の結果、遅延診断のレポート。
  • 日程を直す。どの変更も自分の編集と同じ検査を通り、すぐ画面に出て、取り消せます。
  • 別の文書の中身を取り込む。日程を GRS JSON・MS Project の XML・画像・1 つの HTML ファイルとして受け取る。
  • タスクを表示したり、そこへ移ったりする。あなたの編集を待つ。

できないこと

  • PC のファイルを開く・保存する。開くのも保存するのも、GRS のタブで行います。
  • タブが閉じているとき、Agent API が切れているときに働く。そのときは、GRS のページがつながっていないと答えます。
  • 2 つの GRS のタブに同時につながる。つながるのは最初の 1 つだけです。
  • 読み取り専用の行を直す。あなたがドラッグしている間や、欄に入力している途中に書き込む。
  • ほかのコンピューターからつながる。

PC の外へ出ないもの

  • 取次はあなたの PC で動き、127.0.0.1（このコンピューター）でだけ待ち受けます。ほかのコンピューターからはつながりません。
  • 日程はブラウザのタブの中にあります。取次は写しを持たず、何も保存しません。GRS 自身はインターネットへ何も送りません。
  • つながれるのは、取次が自分で配ったタブで、その起動の秘密の鍵をアドレスに持つものだけです。ほかの Web ページからはつながりません。
  • ただし、AI が読んだ内容は Claude とのチャットの一部になり、あなたが打った文と同じように AI のサービスへ送られます。チャットに貼ってもよい日程だけを AI に読ませてください。

止める・取り除く

  • いったん止めるときは、GRS のタブで Agent API をもう一度押します。AI が既に読んだものは取り戻せません。
  • 取次を無効にするときは、Claude Desktop の Settings › Extensions で GRS relay を開き、Enabled のスイッチを切ります。取り除くときは、同じ所の Uninstall を押します。

うまくいかないとき

  • GRS のページがつながっていないと Claude が言う。Claude が示すアドレスを（# の後ろまでまるごと）開き、そのタブで Agent API を押してください。
  • アドレスが開かない。Claude Desktop が起動し直したため、アドレスが変わっています。もう一度 Claude にアドレスを聞いてください。
  • Agent API を押したのにつながらない。ファイルから開いた GRS.html ではなく、アドレスから開いたタブを使っているか確かめてください。同じアドレスのタブがほかにあれば閉じてください —— つながるのは 1 つのタブだけです。
  • Claude が GRS relay を知らない。手順 3 を確かめてから、新しいチャットを始めてください。
ほかの使い方と確かめ方（詳しい人向け）

Node.js で取次を自分で動かす

MCP のサーバーをコマンドとして起動する AI のアプリで、PC に Node.js 18 以降が入っているときは、grs-relay.mjs（同じ取次を 1 つのファイルにしたもの）をダウンロードし、コマンド node と、引数に保存したファイルを登録します。例:

{
  "mcpServers": {
    "grs-relay": { "command": "node", "args": ["FOLDER/grs-relay.mjs"] }
  }
}

FOLDER は、ファイルを保存したフォルダに置き換えてください。取次は、開くアドレスをエラー出力にも書きます。

Claude Code から使う

Node.js 18 以降があれば、上のとおり grs-relay.mjs を保存し、ターミナルで次を実行します。

claude mcp add --transport stdio grs-relay -- node FOLDER/grs-relay.mjs

FOLDER は、ファイルを保存したフォルダに置き換えてください。Claude Code で /mcp を打ち、grs-relay がつながっていることを確かめます。手順 4 からは、Chat タブの代わりに Claude Code に頼みます。

Claude のデスクトップアプリの Code タブにも、Settings › Extensions で入れた GRS relay が出ます。Chat タブと Code タブはそれぞれ自分の取次を起動するので、アドレスも別です。使っているタブでアドレスを聞いてください。

ダウンロードしたものを確かめる

grs-relay.mcpb.sha256 は grs-relay.mcpb の SHA-256 を持ちます。束に署名はありません。どのソースから作ったかは、組み立てが記録しています（ビルドの来歴の証明）。
