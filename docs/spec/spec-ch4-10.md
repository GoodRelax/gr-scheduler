**ORIGIN**: UC-007

**RATIONALE**: 片方だけ見る実装は矛盾した組を通す。  
細目は 表 T-448 が持つ。  
`IMPS-1780` —— 2 つの幅の上限は互いに依存する。  
`IMPS-1781` ・ `IMPS-1782` —— `Schedule Canvas` の幅から `canvasPadding`（`S-56`）と 2 つの幅と縦のスクロールバーの太さを引いた残りが、`Task Group Lanes` の幅である（`U-50`。  
太さの決め方は `FR-051` の 表 T-447 の `IMPS-1759`・`IMPS-1760`・`IMPS-1762` 〜 `IMPS-1765` が持つ）。  
`IMPS-1783` —— 表 T-031 の SC-3 が常時表示を求めており、幅 0 は `SC-3` を破る。  
`IMPS-1784` —— 離すまで動かないと、どこで手を離せばよいのかを見ないまま離すことになる。  
`IMPS-1784` —— 床より細い幅は、離しても床で描くので手に入らない。  
床で止めて描くことが、どこで手を離せばよいのかを見せることである —— 床を当てずにポインターへ付いて行かせると、離したとたんに床へ跳ね戻り、手に入らない幅を見て手を離すことになる。  
`IMPS-1785` —— 離したときと別の式で描くと、掴んでいる絵と離した後の絵が食い違う。  
`IMPS-1786` —— 離したときの命令（`_assets/tbl-published-entries.md` の 表 T-064 の `PI-18` の `commandFromInput`）を当てた文書を、表 T-064 の `PI-35` の `regionsFromScreen` で描けば、掴んでいる幅が読める。  
⚠️ 離したときに保存する `S-79` は、表 T-252 の後の段が持つ。  
`IMPS-1787` ・ `IMPS-1788` —— 利用者の判断である。  
`IMPS-1790` —— 設定の面に要る幅とタスクに要る幅は違う（利用者の判断）。  
`IMPS-1794` —— タスクグループパネルの床と同じく、手に入らない幅を見て手を離させない。  
`IMPS-1795` —— 境界のドラッグは `S-248` より細い幅を作らない。  
`IMPS-1796` —— プロパティパネルの幅は読む人の画面の広さに依る値であり、起動のたびに中身の種の既定の幅から始める。  
⭐ 境界を掴む帯と、帯に重なるものとの優先は 表 T-023d の `GR-22` が持つ。  
`IMPS-1799` —— 出していないパネルの境界は画面の右端にあり、画面の右端は縦の `Scrollbars` を掴む唯一の場所である。  
`IMPS-1801` —— 表 T-028 の `IN-1` はポインター操作を押した時点で実行せず離した時点で確定し、中断は `Esc` で行うと定めており、途中の幅を書くと離す前に確定したことになる。
