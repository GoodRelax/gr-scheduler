**RATIONALE**: 分母は予定の期間である。  
`actualStart` が `start` より後でも分母は変わらない。  
分子と分母を同じ規則で数えるのは、予定どおりに終えたタスクを 100 と読ませるためである —— 片方だけが終わりの日を数えると、予定どおりに終えた 2 日のタスクが 200 と読める。  
⇒ 予定どおりに始めて予定どおりに終えたタスクは 100 であり、同じ日の 08:00 〜 17:00 のタスクの予定の期間は、既定の時間帯の暦で 480 分（1d）である。  
⚠️ 交換相手へ書く `Duration`（`_assets/fig-erd-detail.md` の `DV-8`）は、端の日が非稼働日のとき端の日を数えない —— 書き出す `PercentComplete` とのずれは 表 T-004 の `LM-22` が持つ。  
完了したかどうかは `actualFinish` の有無が表すのであって、完了率が 100 かどうかではない（表 T-019）。  
`IMPS-474` により、予定と実績の工数の差が完了率から直に読める。  
`IMPS-461` —— マイルストーンは長さを持たない点である。  
`IMPS-464` —— 分子も分母も文書の暦の稼働時間で数えるので、暦が変われば日付が 1 日も動かなくても正しい値が変わる。  
`IMPS-467` —— 暦の変更は取り消せるので、分けると取り消しが暦だけを戻し、数え直した完了率が残る。  
`IMPS-468` —— 日付が正である —— 人に入れさせない値を、ファイルを経て入れる道を残さない。  
`IMPS-469` —— 取り込んだ値を保つ（`FR-021`）。  
`IMPS-474` —— 予定 100 日のタスクを 80 日で終えれば 80、120 日かかれば 120 である。  
`IMPS-475` —— 書き出した完了率を受け取った側がどう解釈するかは未検証であり（`LM-7`）、後から式を変える判断があり得る。  
`IMPS-477` —— 積み順（`ST-2`）・遅れの量（表 T-021b）・完了率のいずれもが `start` と `finish` の両方の存在を前提にしている。  
`IMPS-479` —— `EX-5` が定める扱いでは日付が動かないので、積み順・遅れの量・完了率のどれも走らない。  
`IMPS-480` —— `FR-023` は超えた入力を部分適用せずに拒むと定めており、対象外にしておかないと中身のない行が 1 つあるだけで取り込みが丸ごと失敗し、`FR-021` の往復無損失も同時に落ちる。  
`IMPS-481` —— 負の期間は完了率の分母・イナズマ線の頂点・積み順の重なり判定をすべて壊す。  
`IMPS-484` —— 丸めると、データを黙って変えることになる。  
`IMPS-486` —— 完了かどうかは `actualFinish` の有無が表す。  
`IMPS-486` —— 予定の期間が 0 になるのは、マイルストーンと、`FR-011` の数えで稼働時間に 1 分も掛からないタスクである —— `UC-001` 拡張 2a が作る「開始日 ＝ 終了日のタスク」は、`GRS` が書く時刻（表 T-350 の `WT-1`・`WT-2`）の開始と終了を持つので、既定の時間帯の暦では 480 分である。

掴む的と押す的は分ける。  
⚠️ マーカーの描いた形がほかの掴み代に重なるときの分け方は `FR-105` の 表 T-267 の `HT-3` が持つ。  
⭐ マーカーを引いたときの効果は `FR-107` の 表 T-270 の `PE-8` と `PE-10` が持つ。  
⚠️ 未着手の記号は表 T-021 の `PM-1a` が持ち、扱いは `FR-013` が持つ。  
`PM-4` は他の行と必ず同時に成立する。  
3 つの条件はいずれも `PM-1` / `PM-1a` / `PM-3` のどれかに当てはまる状態を名指ししているためである。  
遅れの発見は独立したユースケース（`UC-006`）として立っており、状態の表示より優先される。  
⭐ 巡りの輪（未着手 → 進行中 → 完了 → 中断 → 未着手）と、巡りの輪の代償は `FR-107` の 表 T-270 の結びが持つ。  
進捗ステータスマークの寸法は `FR-094` が持つ。  
`FR-013` は寸法を持たない。  
`IMPS-488` —— 掴ませると、意図せず予定を動かす。  
`IMPS-489` —— 利用者が定めた。  
`IMPS-495` —— 遅れは `UC-006` が最も見つけたい対象であり、実績バーの色を継ぐと、淡い色のタスクで遅れが沈む。  
`IMPS-495` —— ⚠️ 表 T-236 は成果物に埋め込む定数であり、文書に保存しないので、`IMPS-494` の「独立した色を保存しない」と両立する。
