## Chapter 8. Use Case Tests (ユースケーステスト)

### 8.1 Test Cases (テストケース)

**Type**: SECTION

確かめるものは 表 T-334 の `VT-1`（Chapter 7）、置き場は 表 T-218 の `TS-1`、合格基準は 表 T-219 の `TW-1` が持つ。  
第 3.2 節のユースケースを、具体的な値で確かめる。  
シナリオは Gherkin で書き、受入基準を兼ねる。  
シナリオの原本は本節であり、`.feature` のファイルを作らない。  
シナリオを確かめる e2e の試験は、試験の題の頭にシナリオの ID を書き、題の末尾にシナリオの印のタグを書く（例: `SCN-1 SCN-5 UC-001 … @UC-001.OK`）。  
要求の ID のタグはシナリオだけが持ち、試験の題に写さない —— 試験はシナリオの ID でシナリオを指し、シナリオのタグが要求を指す。  
`@manual` のシナリオの結果は、テスト記録 `docs/development-records/test-records/manual-scenarios.md` に書く。

すべてのユースケースの印に、シナリオが 1 つ以上ある。  
印ごとのシナリオは、シナリオのタグで引く（例: `@UC-001.RJ1`）—— 印とシナリオの対応を別の表に写さない。
