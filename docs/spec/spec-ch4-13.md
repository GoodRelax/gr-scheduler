#### 表示する要素を切り替える

**Type**: FUNC_REQ
**UID**: FR-049

**STATEMENT**: 利用者が表示の切り替えを求めたとき、`GRS` は、`_assets/tbl-settings.md` の表 T-202 のうち、表示の可否を持つ項目をそれぞれ切り替えられるようにすること。

**ORIGIN**: UC-003 / UC-005 / UC-006 / UC-008

**RATIONALE**: 切り替えの対象は表 T-202 が持つ。  
細目は表に置く（1.9）。  
⚠️ **表 T-202 には切り替えでない項目も含まれる**（`IMPS-861`）。  
`IMPS-863` の 1 文目 —— 隠した要素を編集する経路まで消えると、`isProgressMarkerVisible` を `false` にしただけで着手済みタスクの状態を変える手段が無くなる。  
隠している要素の掴み領域は、表 T-023a の当たり判定の規則により残らない。  
⚠️ 依存線の行を 表 T-016 が持たないことは 表 T-018b が述べている。  
`IMPS-863` の 3 文目 —— 戻す入口が既に在り（表 T-109 の `IC-81`）、その押下は文書の現在値から反転する対称なトグルである。  
幾何は毎フレーム組み直されるので、戻した次のフレームで依存線は再び掴める。  
⭐ **選ぶ・ラグを編集する・削除するは、戻してから行う。**  
⚠️ **隠したまま行えないことは残る** —— 「できない」ではなく「戻してから行う」であり、面を 1 つ増やすほどの不便ではないという判断である。  
⛔ **`IMPS-863` の 2 文目の一般則は、依存線以外の要素について生きている。**  
表示の切り替えは取り消しの対象外（`UN-7`）なので、失った操作を履歴から戻せない。  
例えば `FR-014`（イナズマ線）は「基準日が置かれているとき」と書いているが、`isProgressLineVisible` が `false` のあいだは描かない。  
`IMPS-862` —— **この 1 文で一括して閉じる** —— 個別の要求文に条件を書き足すと、表 T-202 に行を足すたびに要求の追記が要る。  
`IMPS-864` の 1 文目 —— 画面の値 `delayDiagnosticsShown`（`_assets/tbl-settings.md` の 表 T-206 の `S-445`）が描く理由になる（`FR-133`）。

⛔ **本要求で 2 つを結ぶ条件を書いてはならない（MUST NOT）** —— **独立とは、片方を読む所がもう片方を読まないことである。**  
`FR-009` / `FR-013` と表 T-020a の `GD-1` がこの 2 つの値で分岐する。  
`IMPS-866` の 2 文目 —— トグルを押すたびにタスクグループが伸び縮みすると、見ている場所が動く。  
`IMPS-866` の 3 文目から 5 文目 —— 見た目は透明に描いたときと同じであり、表示を切り替えてもタスクグループの帯高も段も動かない。  
⭐ 選択は描いた図形だけを見る —— 何も描かれていないタスクを選ばせないことと、選択の枠が囲む図形は、`FR-081` の 表 T-023c の結びが持つ。  
⚠️ **描く札は動く** —— 名称ラベル・担当と進捗の札・進捗マーカーは `FR-109` の 表 T-272 の基準に付くので、実績を隠せば予定を基準に置き直される。  
⭐ 動かないのは占有と帯高であり、動くのは描く位置である —— 占有を残すのは、表示を切り替えるたびに段が組み替わらないためである。  
`IMPS-866` の 6 文目 —— 外すと、予定だけ・実績だけの表示に切り替えるたびに名称ラベルの位置と、`OC-1` を経た占有幅と、タスクグループの帯高が動き、段が組み替わる。  
⚠️ 進捗マーカーを描く位置は本段の対象ではない —— 表示の組で決めるのは `FR-013` であり、予定だけの表示ではマーカーは予定バーの右端の外側へ移る。  
⭐ 名称ラベルはその移った位置も数えて置く（表 T-243 の結びの ②）ので、マーカーの描く位置が動いても、名前・占有・帯高は動かない。  
**担当ラベルと完了率ラベルの既定が非表示である**のは、低ズームでの段数膨張の主因がこの 2 つであるためで、`GL-002` を守るための判断である。

#### 透かしに出す名前と解除パスワードを設定する

**Type**: FUNC_REQ
**UID**: FR-086

**STATEMENT**: 閲覧者が透かしの設定を求めたとき、`GRS` は、**透かしに出す名前**を入力させること（入力させる道を持たない間の描き方は 表 T-633 の `IMPS-867`）。

**ORIGIN**: UC-009.OK

**RATIONALE**: `tbl-settings.md` の `S-99a` は名前の保管先を定めるだけで、名前が入る経路は本要求が与える。  
`GL-007`（秘密の日程を画面に出した証跡が残る）は `FR-020` 1 本で支えられているので、**名前が入る経路が無ければ目標がそのまま未達になる。**  
⚠️ 名前を入力させる道と、解除パスワードを設定させる道は、いまは実装しない —— 道を持たない間の振る舞いは `IMPS-867` の 2 文目と `IMPS-869` の 2 文目が定める。  
⚠️ **代償を隠さない** —— `GL-007`（秘密の日程を画面に出した証跡が残る）が求めるのは「誰が」であり、全員が同じ名前で描かれるあいだ、その目標は満たしていない。  
⭐ **本要求の席は残す** —— 入口は後で足すので、そのときに書く先が要る。  
宛先は `docs/development-records/pending-decisions.md` の未裁定の行が持つ（仕様書の行 ID ではないので、ここでは番号を書かない）。  
⛔ **入口は仕様のどの表にも無いことを数えて確かめてある**（各表の行を引いて数えた）—— 表 T-109 の 138 行・表 T-036 の 28 行・表 T-234 の 14 行・表 T-103 の 66 行・表 T-016 のいずれにも 0 件。  
`FR-038` の辞書に透かしの語は 16 件あるが、名前を入れる面の見出しや札は 0 件である。  
⭐ **読む側は実物で効いている** —— `localStorage` に名前を書いて開き直すと透かしがその名前に変わり、空文字と未設定は同じ答えになる（`IMPS-868` の 2 文目の MUST NOT が生きている）。  
`IMPS-868` の 2 文目 —— 名前が空のままになる経路を作らないためである。  
⚠️ **OS のログイン名は使えない** —— ブラウザにそれを返す API が無く、`CN-1`（単一 `.html`・サーバー不要）を保つ限り取得できない。  
**将来サーバーと接続したときは、そこが持つ利用者名で置き換える**（`LM-12` と同じ見通し）。  
⚠️ 解除パスワードを設定させる道を実装しない代償を隠さない —— 全員が既定のパスワードのままであり、`LM-1` のとおりもともと弱い抑止である。  
⭐ 表 T-206 の `S-99c` の席は残す —— 入口は名前の入口と一緒に後で足す。

**名前を文書に保存しない規則と理由は `FR-020` が持つ**（置き場は `S-99a`）。  
既定の透かし解除パスワードは表 T-207 が持つ（`IMPS-869` の 3 文目）。

#### 透かしを重ねる

**Type**: FUNC_REQ
**UID**: FR-020

**STATEMENT**: `GRS` は、開いた者の名前と実行時の日時を、`Task Group Area`（`_assets/tbl-glossary.md` の `U-50`）へ斜めに繰り返し薄く重ねること。

**ORIGIN**: UC-009.OK、UC-009.RJ1

**透かしの規則は 表 T-242 が持つ。**  
**RATIONALE**: 証跡として意味があるのは「誰がいつ画面に出していたか」である。  
**作者の名前が他人の画面に出るのは誤りである。**  
`IMPS-872` の 2 文目 —— **保存すると、パスワードを知る 1 人が、下流の全員ぶんの証跡を恒久的に外せる。**  
⭐ 透かしが示すのは「誰がいつ画面に出していたか」であり、開くたびに作り直される値であって、文書の属性ではない。  
⇒ **保存しなければ、消したのはその場かぎりになる。**  
重ねる範囲を `Task Group Area` に限るのは、証跡が要るのが日程の絵だからである。  
日程の絵を写した画像には必ず `Task Group Area` が入るので、外側まで重ねても証跡としては足さない。  
**範囲を限っても `LM-1` と `LM-8` は変わらない** —— どちらも範囲の広さで決まる制限ではない。  
`IMPS-870` —— 地域時刻で示すと、画面を複写した者と受け取った者で読みが変わる。  
`IMPS-871` の 1 文目 —— 透かしが証跡として答えるのは「誰がいつこの内容を画面に出していたか」であり、内容が変われば答えも変わる。  
`IMPS-871` の 2 文目 —— 描くたびに文字が変わると、同じ日程を描いた 2 つのフレームが違う絵になり、`FR-102` の記録も 1 秒ごとに別物になる。  
`IMPS-871` の 5 文目 —— 名前は表 T-206 の `S-99a` が別枠で持ち、実行の間は動かない。
