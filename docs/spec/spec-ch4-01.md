**UID**: FR-083

1 つのタスクグループ ＝ 1 対象がマルチバーの中核であり、器を作る手段が無ければ日程表が始まらない。  
表 T-014 の `ST-4`（1 か所へ集めたいときは人が専用のタスクグループを作る）と `FR-058`（上限が掛かるのは人が階層を作るとき）は、`FR-085` が与える経路を前提にしている。  
順序と範囲での選択は定めない（実装の裁量とする）。  
⚠️ タスクグループの選択は、表 T-023c が定める描画領域の選択とは別の集合である（表 T-023c の `SL-1` がタスクグループを対象から外している）。  
⚠️ 別の集合でも、`Esc` と `Enter` はタスクグループの選択を対象の選択と一緒に解除する —— 規則は 表 T-028 の `IN-4` と 表 T-036 の `SK-19` が持つ。  
`IMPS-1958` —— 外さないと、貼り付け（`FR-033`）が在らないタスクグループを貼り付け先に渡す。  
表 T-015 の `HR-3` 〜 `HR-5`・`FR-032`・`FR-033`・`FR-042` が前提にしている「選ばれたタスクグループ」は `IMPS-1955` 〜 `IMPS-1958` が与える。  
`IMPS-1959` 〜 `IMPS-1961` —— ⭐ タスクの名前を変えるのと同じ振舞いである（`MK-13` のタスクの項）。  
⚠️ `Enter` でパネルが閉じるのは 表 T-036 の `SK-19` の 2 段目であり、`FR-085` は規則を何も足さない —— 編集を確定させる `Enter` が 1 度目、確定していないその場の編集が 1 つも無くなった `Enter` が 2 度目で、2 度目でパネルを出すのをやめる。  
⛔ `FR-085` に `Enter` の規則を書き写さない—— 同じ MUST が 2 か所に載ると、必ず離れていく。  
⭐ どの欄を出すかは `FR-042` が持つ —— `FR-042` がタスクグループの属性をパネルに出す規則そのものを持っている。  
⚠️ `GR-20` は 表 T-051 の `HF-15` が常に描くと定めており、置き場所は「インデントの後、名前のすぐ前」である。  
⚠️ `IMPS-1964` の式が引く `S-79` と `S-37` は、いずれも描いたときの幅である（`FR-039` の 表 T-252 の `DS-1` / `DS-9`）。  
⇒ 引かないと、式が名前に与える幅と、実際に与えられる幅が食い違う。  
`IMPS-1965` —— 重ねる形は `HF-6` が操作子について採っている形だが、掴み代は常に描くので、重ねると名前の頭が常に隠れる。  
`IMPS-1966` —— 書き出しでは操作子を描かないので（表 T-076 の `EP-4`）、変えると画面と書き出しで打ち切りの位置が食い違う。  
描いていないあいだも場所は確保したままにする（表 T-051 の `HF-6`）。  
`IMPS-1968` —— `IMPS-1967` が幅の判定を概算に定め、`FR-093` が字の実寸を測ることを禁じている。  
重ねて切ると、概算より実寸が広い名前に記号が 2 つ並び、書き出し（表 T-076 の `EP-3`）とも打ち切りの位置が食い違う。  
⚠️ 代償: `IMPS-1969` のとき、`IMPS-1962` が置いた `…` の一部か全部が隠れうる —— 係数（`S-30`）を選び直す義務は 表 T-026 の `RC-3` が持つ。  
`IMPS-1970` —— `truncateUnits` は名称ラベルがタスクの幅に収まらないときの前処理であり（`FR-002`）、パネルの幅で決まる `IMPS-1962` とは基準が違う。  
パネルの幅は文書に保存するので（`S-79`）、渡した相手も同じ位置で打ち切った絵を見る。  
全文を見たい者はパネルを広げる（`FR-052`）。  
`IMPS-1971` —— タスクグループの高さは載るタスクの段の数で変わる（`FR-003`）ので、縦の中ほどに置くと、名前がどの段の横に立つかがタスクグループごとに変わる。  
⭐ 上端に寄せれば、名前は常にタスクグループのいちばん上の段の横に立つ。  
書き出しは `IMPS-1971` の置き方に式で揃える —— 規則は 表 T-076 の `EP-3` が持つ。
