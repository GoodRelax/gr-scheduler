# セッションの呼び名 —— 開発の規則の用語集

⭐ **AI のセッションを親と子で動かすときの呼び名を、日本語と英語で 1 つに揃える**（利用者の裁定 `JDG-3042`、2026-10-22）。
⛔ 下の「止める旧い語」の表の語は使わない。検査 87 が、生きている文書に新しく書かれた旧い語を赤にする。

## 1. 呼び名

| 日本語 | English | 何を指すか |
|---|---|---|
| 利用者 | User | 開発を頼み、裁定を出す人。 |
| 調整役 | Coordinator | 子セッションを起こし、仕事を割り振り、報告を受け、利用者に問う役。いま親であるセッションが担う。 |
| 親セッション | Parent session | 子セッションを起こしたセッション。子は親に報告する。 |
| 子セッション | Child session | 親セッションに起こされ、1 つの仕事を受け持つセッション。 |
| サブエージェント | Subagent | 1 つのセッションの中で `Agent` の道具が起こす下請け。セッションではない。 |
| 引継書 | Handoff note | 次の調整役に渡す状態の文書。この開発では `docs/development-records/handoff.md` 1 本。 |
| セッション台帳 | Session registry | 調整役と子セッションの一覧・状態・番号の幅・枝・次の手。手元だけに置き、公開しない（`tools/handover_guard/`）。 |
| 調整役の交代 | Coordinator handover | 調整役が次のセッションに替わること。新しい調整役は、生きている子セッション全員に新しい親を伝え、台帳で全員の受け取りがそろうまで続ける。 |
| セッション完了 | Session complete | 子セッションが目的を果たし、結果を調整役に報告して、問題が無いことを宣言すること。台帳に「完了」と残る。 |

⭐ **公式の Agent teams の team lead とは別のもの**である。team lead は交代できない固定のリーダーで、調整役は交代する（`JDG-3042`。公式の頁 code.claude.com の agent-teams）。

## 2. 止める旧い語

検査 87 はこの表の 1 列目を読む（表の外に語の写しを持たない）。1 字の語は、前後に漢字が続かないときだけ数える（「全体」「座席」は数えない）。

| 旧い語 | 代わりに使う語 |
|---|---|
| 席 | 子セッション（または 調整役） |
| 体 | サブエージェント |
| 指令役 | 調整役 |

⭐ **数えないもの**: 「」の中（人の言葉の逐語と、本表のような語の名指し）・バッククォートの中・逐語の記録（`rulings.md`・`defects.md`・`fixed-defects.md`・`changelog.md`・`pending-decisions.md`・`previous-plan.json`（1 つ前の計画の写し）・`history/`・`change-request/`・`docs/review/`）。どのファイルを見るかは検査の道具の頭が持つ。

⚠️ **すでに書かれた旧い語は基準線に数えてある**（`.claude/skills/spec-graph-check/old-session-words-baseline.txt`）。基準線より増えたファイルだけが赤になる。置き換えは別の波で行う。
