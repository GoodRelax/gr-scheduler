## 2. 何が壊れていたか（**逐語**）

### #1 —— 取り消しで、監視者が古い内容を持ち続ける（⛔ `AG-6` の MUST 違反）

`AG-6`（`01-04-requirements.md:3523`）:

```
監視は「自分がまだ受け取っていない、自分以外の書き手が確定した変更と発話だけ」を
通知すること。日程データの変更は版数で選び、…（MUST）
```

⛔ **取り消しは、段に持っている以前の `Document` を刻印ごと復元する**（`undo-edit.ts` の `STOP` が「a step holds the whole earlier Document, stamp and all」と書く）。

| | 監視者が持っているもの | 文書が戻った先 | 版数で選ぶ（いま） | 等値で選ぶ（本 CR） |
|---|---|---|---|---|
| **場合 A** | `t2` の内容 | `t1`（`t2` より前）| ⛔ **`t1 > t2` は偽 → 通知しない。監視者は古い内容を持ち続ける** | ⭐ **`t1 ≠ t2` は真 → 通知する** |
| **場合 B** | `t1` の内容 | `t1` | ⭐ 通知しない（正しい）| ⭐ 通知しない（正しい）|

⚠️ **いま実害が出ていないのは、取り消しが `WS-6` へ届く経路がまだ無いからである**（`CR-196` が「決めていないこと」として記録）。⛔ **経路が開いた瞬間に出る。**

### #2 —— 1 本の整数が 4 つの判定に刺さっている

```
AT-127 revision  →  AG-2 の照合（等値）
                 →  AG-6 の選別（順序）
                 →  表 T-034 の起動時の比較（順序）
                 →  changeLog の主キー（一意性）
```

⛔ **`R2.2`（SRP）の違反である。** ⚠️ **`changeLog` は 18 実体のうち唯一、自前の鍵を持たず他の値を借りている。**

### #3 —— 壁時計が順序を決めている場所が 1 つ在る

`01-04-requirements.md:3279`:

```
負けた自動保存の扱い: 同じ文書で自動保存のほうが新しければ確認を求める。
```

⛔ **`R3.6` は「経過時間の計測に壁時計を使わない（`NTP` 補正や `DST` で逆行しうる）」と定める。** ⭐ **裁定 4 が既にここを等値へ移している。本 CR はそれを条文にする。**
