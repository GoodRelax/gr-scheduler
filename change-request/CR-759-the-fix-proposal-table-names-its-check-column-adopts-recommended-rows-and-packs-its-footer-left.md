### Q4 —— [推奨案をすべて採用する] の英語はどれにしますか？（C 部、`DFC-2603`）

### Q5 —— 採る行が 1 つも無いとき、[推奨案をすべて採用する] はどう見せますか？（C 部、`DFC-2603`）

### Q6 —— 択が 2 つ以上ある行で、択を選ばずに ✓ を押したらどうしますか？（E 部、`DFC-2612`）

⏳ 未 —— 利用者の不在のあいだは問わず先送りした（2026-10-15、調整役の指示）。✓ の振る舞いを変えるので、利用者が戻ってからこの席が問う。

- 場面: 修正案の表で、修正のしかたが「選ぶ」の行（例: `FA-15`「後続の予定を…送る ／ その依存線を消す」）の修正後の欄は「（選ぶ）」のまま。人が先に ✓ の箱を押す。今は箱に ✓ が見えるのに「修正件数」は増えず、[上書きして修正] を押してもその行は修正されない（`81d363bd` で写した）。⚠️ C 部が当たると、択が 1 つの行ではこれは起きない（✓ がその択を採る）。残るのは択が 2 つ以上の行だけ。
- 画面の名前: 修正案 / Fix Proposals、欄 修正 / Fix、修正後 / After、（選ぶ） / (Choose)。

| 択 | 中身 | 代償 |
|---|---|---|
| **A ✓ は付かず、その行の択の一覧を開く（推奨）** | 箱は外れたまま。焦点がその行の修正後の択の一覧へ移り、一覧が開く。択を選べば ✓ が付き、数える（今の `RW-16` の作り直しのとおり） | 箱を押しても ✓ が付かない。ただし次にすることが目の前に開く |
| B ✓ は付かず、短い知らせを出す | 箱は外れたまま、下の帯の知らせの行に「先に修正後の択を選んでください」と出す | 知らせの語が 1 つ増える。知らせの行（`JDG-2172`）が束の結果以外にも使われる |
| C ✓ は付いたまま、択を選べば数える | ✓ を「この行を採るつもり」と読み、択を選んだ時に数える | ✓ の見え方と件数が食い違う時間が残る（今の不具合そのもの）。✓ の箱に「未完」の見せ方を足す要がある |
| D 択を選ぶまで箱を効かなくする | 箱を薄く描き、押せない | 読み取り専用の行・外れた連鎖の行と同じ見せ方になり、なぜ押せないかが分からない |

推奨は A —— 理由: 表 T-373 の「人が選ぶまでチェックを入れない」を守ったまま、押した人が次にすること（択を選ぶ）を開いて見せる。語も見せ方も増えない。覆す裁定は無い（`JDG-1945` ① の「人が選んだ行だけを直す」のまま）。
