### ⛔⛔ 直しきれなかった理由を測った —— **別の不具合である（`D-123`）**

⭐ **`OP-10` の除外は効いている。**レイアウトは深さ 1〜3 の **68 行**を並べている。
⛔⛔ **しかし画面には 7 行しか出ない。**測った内訳:

| 測ったこと | 実測 |
|---|---|
| `Row Area` | y=85、高さ **977px** |
| レイアウトの先頭 8 行の高さ | 64 / 148 / 188 / 108 / 188 / 148 / 148 / 148 px |
| ⇒ 977px に収まる行数 | **7** |
| **その 7 行の深さ** | ⛔⛔ **全部 1** |
| 8 行目の深さ | **2** |

⛔⛔ **`order` は親ごとに 0 から振られており**（根が 0〜6、深さ 2 の子も 0 から）、**レイアウトは深さごとに並べている** —— 根 7 つ → 深さ 2 の 19 → 深さ 3 の 42、という順である。
⇒ **木の順ではないので、親と子が離れて並び、最初の画面には根しか来ない。**

⭐ **これは `OP-10` とは別の不具合である。**⛔ **`D-123` を立てた。**⚠️ **利用者の「階層が見えない」は、これが直るまで解消しない。**
