# CR-256 — 誰も手の届かなかった間引き

> **閉じるもの**: ⛔ **`FR-017` はルーラの目盛を 4 段階で刻むことを求め、`LF-1` がその間引きを定めるのに、間引きを答えるメンバが 表 T-064 に載っていない。**
> ⭐ **描く側は `ScheduleLayout` の外に居るので、載っていないものは呼べない。** ⚠️ **その結果、ルーラは 1 度も描かれていなかった。**

## 0. ⛔ 立ちどまって答える 3 つ

### ① この変更は `CH-` / `GL-` のどれを前へ進めるか

⭐ **`CH-2`（1 画面で全体を読める）。受ける目標は `GL-002`。**
⛔ **年月日の出ないルーラでは、どの日を見ているかが読めない。**

### ② レビュー観点のどの条項を当て、何が出たか

| 条項 | 当てた対象 | 結果 |
|---|---|---|
| **`R1.4`**（欠落が無い）| 表 T-064 の `PI-5` | ⛔ **`dateAtX` と `xFromDay` は載っているのに、間引きだけ載っていない** |
| **`R2.18`**（自己矛盾が無い）| `LF-1` と `PI-5` | ⛔ **前者が間引きを定め、後者が間引きを外へ出していない** |

| | 決めたこと | 何に載せたか |
