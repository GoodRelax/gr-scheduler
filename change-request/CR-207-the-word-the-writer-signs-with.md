# CR-207 — 書き手が名乗る語

> **閉じるもの**: ⭐ **利用者の裁定（2026-08-22）** —— **`PD-165` を「固定の ASCII 語 1 つ」で裁定する。**
> ⭐ **`lastEditedBy` に書く語の全数を 表 T-229 に置き、`FR-063` がそれを指す。**
> ⭐ **見分けられない場合が残ることを `LM-16` として制限事項に書く。**
> ⛔ **`AG-2` / `AG-6` / `AG-11` / `WS-5` は 1 文字も書き換えない** —— 判定はいまも等値のままであり、変わるのは**比べる文字列に何が入るか**だけである。

## 0. ⛔ 立ちどまって答える 3 つ（**検査 22 が空欄を許さない**）

### ① これは `CH-` / `GL-` のどれを前へ進めるか

⭐ **`CH-1`（作図ソフトと同じ操作感で描きながら、構造化した日程データを出す）。受ける目標は `GL-004`。**

⛔ **`lastEditedBy` は書き出す列である**（`AT-128`）。⚠️ **何を書いてよいかが定まっていないと、構造化データを受け取った側はこの列を読めない** —— 「人か、AI か」だけでは、どちらでもない `"template"` が既に出荷されている理由が説明できない。

⭐ **`GL-007`（秘密の日程を画面に出した証跡が残る）にも触れる。** ⚠️ **証跡としての「誰が」は、この列と対話欄の `author` の 2 つしか無い。**

## 2. 何が欠けていたか（**逐語**）

`AT-128`（`_assets/fig-erd-detail.md:430`）:

```
| AT-128 | `documentStamp` | `lastEditedBy` | 文字列 | 否 | — | GRS | — | 最後に書いた者。人か、AI か |
```

`FR-063` の `STATEMENT`（`01-04-requirements.md`）:

```
最後に書いた者を文書に持たせ、書き出す JSON にも載せること。
```

⛔ **どちらも「何を書くか」を述べていない。**

出荷している起動テンプレート（`src/framework/single-html-shell/startup-template.json:41029`）:

```
"lastEditedBy": "template",
```

⛔ **人でも AI でもない。** ⚠️ **意味欄の 2 値がその場で破れている。**

`AG-6` の判定を実装している側（`src/use-case/notify-change-watchers/change-notice.ts`）:

```
const changed = isScheduleUnseen && stamp.lastEditedBy !== watcher
```

⛔ **等値だけである。** ⭐ **だから語が重なった瞬間に、`AG-6` の MUST NOT が黙って通る。**

## 5. 試験（**期待値を曲げない**）

⛔ **通る試験を足しても何も証明しない**（規則 04 の 2.）。
⭐ **足すべきは 2 本である:**

```
1. 起動テンプレートの lastEditedBy を `template` 以外に壊したら落ちる試験
   ⭐ tools/generate_startup_template.py の STAMP_AUTHOR が唯一の持ち主なので、
      そこを変えると落ちる形にする
2. 同じ語を名乗る 2 体のうち一方の書き込みが、他方へ通知されない試験
   ⚠️ これは LM-16 が「起きる」と認めた側なので、⛔ 期待値は「通知が落ちる」である
      —— 制限事項を試験で固定することで、後で閉じたときに落ちる
```

⚠️ **画面が `user` を書く試験は、`FT-1` が結線されてからである。**

## 6. ⛔ 本 CR が閉じないもの（**黙って閉じたと読まれないために**）

| | 何 | どこへ |
|---|---|---|
| 1 | ⛔ **同じ語を名乗る呼び手どうしを見分けること** | ⭐ **`LM-16` として明記する。** 閉じるには `AG-6` の継ぎ目に識別子を足すことになり、分類 `E` の裁定である |
| 2 | ⛔ **`AT-128` の値に長さや文字種の制限を掛けること** | ⚠️ **`grs-document.schema.json` は `string` のままである。** ⭐ **制限を掛けるなら別の CR** —— 受理の境界は分類 `F` であり、緩く受理した文書は後から締め直せない |
| 3 | ⛔ **対話欄の `author`（`AG-11`）に同じ表を掛けること** | ⚠️ **`AG-6` は `author` にも同じ等値を当てている。** ⭐ **ただし発話の書き手は人の名を出す場所であり、入口の語とは別の問いである** |
| 4 | ⛔ **`lastEditedBy` を空にしてよい場合** | ⚠️ **`AT-128` は `nullable` が「否」である。** ⭐ **表 T-229 の 3 行が全数なので、空は許されない** —— 本 CR はそれを新たに禁じてはいないが、表が全数を名乗ることで空の余地が消える |
