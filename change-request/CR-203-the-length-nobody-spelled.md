## 2. 何が壊れていたか（**逐語**）

### #1 —— `EX-4` に従えない列が 1 つある

表 T-033 の `EX-4`（`01-04-requirements.md:2949`）:

```
取り込んだ値の書式を踏襲すること（単位・日付の形式を勝手に変えない）
```

`AT-35`（`_assets/fig-erd-detail.md:337`）:

```
Task | actualDuration | 整数（稼働日） | 可 | — | Consume | Task/ActualDuration |
実績バーの長さ。交換相手は時間の量なので、取り込むときに稼働日へ解釈し、
書き出すときに Project.minutesPerDay（空のときは 表 T-209 の S-128）で作り直す（FR-054）
```

⛔ **`Consume` は元の文字列を持たない。** ⭐ **「踏襲する」相手が存在しないので、`EX-4` はこの列に掛けようがない。**
⚠️ **日付でまったく同じことが起き、版 0.44 が `EX-7` を新設して閉じた** —— **時間の量には、その対がまだ無い。**

### #2 —— 綴りは実装だけが知っている

`src/adapter/document-codec/mspdi-codec.ts`:

```
function durationOfMinutes(minutes: number): string {
  const whole = Math.max(0, Math.round(minutes))
  return `PT${Math.floor(whole / 60)}H${whole % 60}M0S`
}
```

⭐ **その注記は根拠として `EX-4` を挙げている** —— ⛔ **だが #1 のとおり `EX-4` はこの列に掛からない。** **仕様に無い規則を実装が持っている。**

### #3 —— 規格は綴りを 1 つに決めない

`XML Schema Part 2` の 3.2.6.1（ローカル複製で確かめた）:

```
If the number of years, months, days, hours, minutes, or seconds in any expression
equals zero, the number and its corresponding designator may be omitted.
However, at least one number and its designator must be present.
```

⛔ **`PT40H0M0S` と `PT40H` は同じ長さの、どちらも妥当な綴りである。** ⭐ **そして同規格はこの型に標準字句表現を定めていない**（3.2.6 は字句表現・順序関係・ファセット比較の 3 節だけである）—— **`NR-4` が使えない理由がこれである。**

### #4 —— 割り切れない長さの扱いが、実装にしか無い

```
function workingDaysOfActualDuration(...) {
  …
  const days = minutes / minutesPerDay
  if (!Number.isInteger(days)) {
    run.notices.push(notice(…, 'is not a whole number of working days and was not read
                                (the rounding is undecided)'))
    return null
  }
```

⭐ **値を発明していない点は規則 06 のとおりである。** ⛔ **しかし「読まない」も 1 つの選択であり、裁定待ちの一覧に 1 行も無い。**
⚠️ **`actualDuration` は文書の列であり往復で書き戻される** —— **申告されないまま既定になってはならない。**

## 4. 原稿の中身（**書く前に置く**）

### 4.1 表 T-033 に足す `EX-9`

> | EX-9 | **`GRS` が書く時間の量は `PTnHnMnS` の形とし、時・分・秒の 3 つを必ず置くこと（MUST）。年と月を書いてはならない（MUST NOT）** —— 年と月の長さは、どこから数え始めるかで変わる。⚠️ **取り込んだまま編集していない値には掛からない** —— そちらは `EX-2` と `EX-4` が元の文字列のままを求める。⭐ **綴りが要るのは `Consume` の列だけである** —— 持ち回る値は文字列のまま戻る（表 T-053 の `DF-2`）|

### 4.2 表 T-228 に足す `NR-5`

> | NR-5 | 時間の量を比べる | 交換相手のスキーマが `xsd:duration` を与える要素は、**字句ではなく時間の量として**比べる。⛔ **年と月を持つ値は量として読まない** —— 長さが数え始めに依るので、比べようがない。⚠️ `NR-4` ではなく別の段取りにしているのは、この型に標準字句表現が無く、揃える先が存在しないためである |
