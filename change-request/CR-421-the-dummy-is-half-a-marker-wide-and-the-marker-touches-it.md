# CR-421 — 実績のダミーはマーカーの半分の一定の幅で描き、マーカーは実績とダミーに接して立つ

> **閉じるもの**: 利用者の裁定 `JDG-177` と `JDG-178`（2026-09-18）。逐語は `docs/development-records/rulings.md` が持つ。
> - `JDG-177`: 「年単位のスケジュールを引いているとき、実績ダミーの幅が1日なのは無理があった。<br>実績ダミーは一定幅がいいな。 今マーカーの50%の幅にしろ。」
> - `JDG-178`: 「実績/実績ダミーとマーカーの間は予定に触れないようギャップを無くせ。  マウスカーソルがちょうど実績とマーカーの間にある時、意図せず予定をシフトさせてしまう。<br>質問や意見があれば述べよ。」
>
> ⭐ **本書は仕様だけを当てる。** 表 T-240 の `DM-3` の幅を「1 日ぶんと `S-180` の小さい方」から「進捗マーカーの径 × `S-247`（0.5）と `S-180` の小さい方」に変え、`FR-013` と `LF-11` で実績（とダミー）の右端とマーカーのあいだの隙間を無くし、表 T-023d の結びに、マーカーの描いた形の上では予定の掴み代より `GR-7` を先に成立させる段を足した。読んだ木は `b6648920`。
> ⚠️ 2 つの裁定は同じ所（実績の右端の近くの印と掴み）を触り、`DM-3` / `GR-7` / `LF-11` / `FR-013` / `FR-043` が 33 員の閉路に入るので、1 本にまとめた（`CR-417` の第 3 節）。⚠️ `src/`・`tests/`・`tools/` は触っていない。

## 7. 試験が主張すべきこと

⭐ 名前は本書のとおりに写すこと: `S-247`（`0.5`）、`S-180`（上限 30px）、`DM-3`、`FR-013`、`LF-11`。

1. `DM-3`: 表示の倍率 100 で、未着手の矩形のタスクのダミーの幅が 5px —— `zoomX` を 0.02 と 64 にしても 5px。⭐ 1 日ぶんの幅に従う古い実装を赤にする。
2. `DM-3`: 表示の倍率 50 で 2.5px、200 で 10px。
3. `DM-3`: 左端は予定の開始日の列の左端（`DM-1`）。
4. 表 T-023d の結び: ダミーの左半分を押すと `GR-9`、右半分を押すと `GR-17`、印の 1px 外を押すとダミーを掴まない。
5. `FR-013` / `LF-11`: 実績のあるタスクで、マーカーの左端 ＝ 実績バーの右端。未着手のタスクで、マーカーの左端 ＝ ダミーの印の右端。
6. `FR-013` / `LF-11`: 予定だけを表示しているとき、マーカーの左端 ＝ 予定バーの右端 ＋ `S-23` × 描く比（`S-23` は 表 T-252 の `DS-1` の「進捗マーカー」群なので描く比が掛かる。既定で 4 × 0.625 ＝ 2.5px）。
7. 表 T-023d の結び: 実績の右端が予定の右端から 2px 左で終わるタスクで、マーカーの描いた形の中の点（予定の終了点の外側の掴み代の中）を押すと `GR-7`（状態を巡らせる）であり、予定の終了日は動かない。
8. 表 T-023d の結び: 実績の右端とマーカーの左端の境の 1px を押しても、`GR-12` と `GR-4` を掴まない。

## 9. ⛔ この変更でやらないこと ／ 返す問い

- ⛔ `S-23` の値と範囲、`S-180` の値を変えない。⛔ ダミーの当たり判定を印の外へ広げない。
- ⛔ `src/`・`tests/`・`tools/` と `retired.py` を編集しない。

**返す問い**（利用者の「質問や意見があれば述べよ。」に答える形で、前に立つ者が伝える）:

1. **ダミーの押せる広さ** —— 既定の表示の倍率で印は 5px、`GR-9` と `GR-17` は 2.5px ずつである。前に立つ者は「押せる広さは表示の倍率を掛けない最小を保つ」とも読んだが、`JDG-41`（印の外へ広げない）と表 T-023d の結びの MUST NOT に当たるので当てていない。推奨: まず 5px で触ってもらい、狭ければ「押せる広さは印を中心に `S-22` の半分（8px）を下回らない」を足すか問う（`JDG-41` を覆すことになる）。
2. **依存線がマーカーの上を通るとき** —— 表 T-023d で依存線（`GR-13`）は `GR-7` より上にあり、本書の段は予定の掴み代だけを `GR-7` の下にした。推奨: そのまま（依存線は描いた形状の上では線そのものだけを取るので、奪う幅は線の太さだけである）。
3. **予定だけを表示しているときの予定の右端とマーカーのあいだ（`S-23` の 4px）** —— そこは予定の終了点の掴み代（端の外側）であり、押すと予定の終了日を掴む。推奨: そのまま（実績を描かない表示であり、予定の端を掴む場所として正しい）。
