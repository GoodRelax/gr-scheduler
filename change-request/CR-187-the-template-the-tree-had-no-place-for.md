## 3. ⭐ `schemaVersion` を日付にした理由

| | |
|---|---|
| 形式の制約 | 表 T-052 の `DR-4` は「**文字列とすること**」しか定めていない |

## 4. ⛔ 成果物の `.json` が書けない —— 止まっている理由

⭐ **生成器は動き、100 行 / 1000 タスクを組み立て、`GRS JSON` スキーマに 8 個を除いて通った。**
⛔ **その 8 個が書けない。**

```
dualCursor  exportCanvas  importMaxDate  importMinDate
pinnedGroupIds  planActualGuidePattern  rulerFont  rulerHeight
```

⚠️ **これは生成器の欠陥ではない。** `SETTINGS_DEFAULTS` を書く `tools/generate_entity_types.py` が
**自らこう書いている** —— 「`settings.json` が機械可読な値として述べていないので、**推測せずに生成しない**」。

⛔ **`FR-024` は 97 個すべてを書き出すことを MUST で求めている。** つまり **8 個が欠けた文書は不正である。**

⛔ **生成器へ数を書き写すことはしない** —— 規則 03 の 1.（「仕様が持つ値は、写さずに生成する」）に正面から反し、
**CR-175 と CR-178 が取り除いたばかりの形**である。

⭐ **出口は 1 つで、しかも既に裁定が出ている**（裁定 ㊸ / CR-175）——
**「設定値の運び手は生成器の射程を広げて作る。値の正が 1 か所に戻る」。**

⚠️ **8 個のうち 2 個は値ではない** —— `dualCursor` は `null`（`S-65`）、`pinnedGroupIds` は空（`S-126`）であり、
**「無い」を書くだけである。** ⛔ **残る 6 個は本物の値で、`rulerFont` と `rulerHeight` は
文字サイズの段ごとの 3 つ組**（`fontScaleSizes` と同じ形）である。

⭐ **止まり方**: 生成器は**不正な文書を書かずに落ちる**。⚠️ **わざと走らせて、8 個を名指して落ちることを確かめた**（規則 04 の 2.）。
⛔ **中途半端な `.json` を木に残していない。**
