## 1. ⛔ 測った

出荷ビルド 1920 × 1080、`elementFromPoint` を掴み代の中央で撃った:

```
深さ 1  Whole Product      (24, 94)  -> GRAB-STRIP   16px 中 6px だけ空いている
深さ 2  Phase Bars         (40,166)  -> IC-59        押すと行が消える
深さ 3  Phone Sign In      (56,698)  -> IC-90        押すと 1 階層開く
```

**算術**（実測に基づく）:

```
名前の箱 = 170 − 16×深さ − 16 − 4  ->  134 / 118 / 102 / 86 / 70px（深さ 1〜5）
操作子   = 7 × 20                  ->  140px      ← どの深さでも名前より広い
```

⭐ **7 つとも `y=85` の 1 行に並んでいる**（x = 26/46/66/86/106/126/146）。
⛔ **`HF-1` の「2 × 2 の格子とすること（MUST）」が建っていない。**

⚠️ **格子を建てると塊は 100px になり、深さ 1〜3 の掴み代が空く。深さ 4〜5 は残る。**

### 2.3 表 T-051 の `HF-15` に 1 段（同じ振る舞いを段に依らせない）

⛔ **2026-09-03 訂正: 本節は当初 `HF-6` と書いていた。原稿では `HF-15` に入れた** —— **`HF-15` が掴み代そのものを定める行であり、「覆ってはならない」はその行に属する。**⚠️ **試験は `HF-15` を引用している。**
