## 1. ⭐ 裁定 1 —— 何が起きていたか（**実測 2026-09-05**）

```
表示位置がまだ記録されていないあいだ、viewSettings が FR-055 の全体表示を毎フレームやり直す
⇒ IC-12 / IC-13 / IC-15 / IC-10 を押して倍率を書いても、次のフレームで上書きされる
⇒ 4 つとも絵を 1 度も動かさない。縦に一度巻き取ると、5 つとも働き出す
```
⚠️ **`IC-14`（縮小）は前後とも動かない。⛔ 本件とは別である** ——
**行は既に `LF-3` の 48px の床に座っているので、縮める先が無い。**

### ⛔⛔ 上の枠の条件は広すぎた。⭐ 体が反証し、幹で測り直した（2026-09-06）

**「4 つとも絵を 1 度も動かさない」が成り立つのは、`OP-10` の枝に入っているときだけである。**

| 立ち上げ方 | 直す前の拡大 | |
|---|---|---|
| 同梱の起動文書（`BT-4`）| **6 → 6.6** | ⭐ **もともと効いていた** |
| ファイルを開いた（`BT-1` / `BT-2`）| **1.5044 → 1.5044** | ⛔ **動かない** |
| `RD-4` で差し替えたあと | 同上 | ⛔ **動かない** |

⇒ ⭐ **`viewSettings` は起動文書の枝で早く戻り、文書自身の倍率を保っていた。死んでいたのは、取り込んだ文書の枝のほうである。**
⛔ **本 CR の §1 の枠は、その区別をせずに書いていた。⭐ 裁定も直しも変わらない —— 変わるのは、どこで起きるかの記述である。**

### ⭐ 直したあと（幹で実測 2026-09-06）

```
ファイルを開いた状態   拡大 1.5044 → 6.6
                       全体表示 → 1.5044（7 行）
                       そのあとの拡大 → 1.6549 ＝ 1.5044 × 1.1
                       表示位置が座る（null → 2026-04-01 と行の id）
起動文書               6.6 / 68 行 / 先頭行 y=96 —— 前後で変わらない
```
⚠️ **直しが 1 つ穴を見せた（`D-336`）** —— **座っていない絵への 1 回目だけ、倍率が「描かれているもの」ではなく「保存されているもの」に掛かる。⛔ 最初に縮小を押すと絵が大きくなる。⭐ 全体表示を先に押せば起きない。**

### ⭐ 直す形

**人が拡大・縮小・全体表示を押したら、それが表示位置になる（＝ `null` でなくなる）。**
⇒ **次のフレームから `OP-10` の条件が成り立たなくなり、全体表示はやり直されない。**
⛔ **`HF-8` を働かせてはならない（MUST NOT）は動かさない。**
