### 裁定 1 —— 「`HR-5` の一押しを失う」は**偽**であった

```
∧∧ を 1 回押した : Whole Product / Phase Bars / Phase Gates / Mobile Client / Back Office / …
⇒ その行は残っているか: ✅ 残っている
⇒ その子は消えたか    : ✅ 消えた   ⇒ HR-5 と同じ絵である
```

⛔ **前に立つ者は 2 度「一押しを失う」と報告し、`PD-402` にもそう書いた。誤りである。**
⭐ **実際に変わるのは戻し方だけである** —— 旧 `HR-5` は畳む前の形を覚えて丸ごと戻したが、
新しい形は 1 階層ずつ開く。**そしてその「覚えていること」が `D-157` の正体であった。**

```
[L1 も畳む] ∧∧ 直後: (空)              ⇒ 頭の ∨ が効く
[L1 は残す] ∧∧ 直後: L1 の 3 行が残る  ⇒ 頭の ∨ は押したあと常に薄い
```

