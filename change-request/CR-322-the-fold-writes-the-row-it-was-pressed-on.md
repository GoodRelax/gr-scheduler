## 1. ⭐⭐ 見本を**触って**抜き出した（⛔ 原文を読んだのではない）

`scratch/probe/sample-truth.mjs` が見本を Chromium で開き、11 の入口を 1 つずつ押して
描かれる行を前後で記録した。**以下はすべてその実測である。**

### 行の 7 種

| # | 図形 | 何をするか | 薄いのはどんなときか |
|---|---|---|---|
| 1 | `∧` | **その行が描かれなくなる**（配下ごと畳み込む）| **薄くならない** |
| 2 | `∨` | **その行の畳みが解け、直下の子が描かれる**（孫は畳まれたまま）| その行が畳まれておらず、隠れている子も無いとき |
| 3 | `∧∧` | **その行が畳まれ、直下の子から下が描かれなくなる** | 直下の子が 1 行も描かれていないとき |
| 4 | `∨∨` | **その行と配下から、畳みと隠しがすべて取れる** | 抱えている畳み込みが 0 のとき |
| 5 | `⊞` | 配下の末子に、名前を空で立てる | **薄くならない** |
| 6 | `⊠` | その行を配下ごと消す | **薄くならない** |
| 7 | `📌` | 留める／外す | **薄くならない** |

### 頭の 4 種 —— ⭐⭐ **同じ 4 つを段 0 に対して行う**

| # | 図形 | 行の何に当たるか |
|---|---|---|
| 1 | `∨` | `∨`（2 番）を段 0 に対して |
| 2 | `∧∧` | `∧∧`（3 番）を段 0 に対して |
| 3 | `∨∨` | `∨∨`（4 番）を段 0 に対して |
| 4 | `⊞` | `⊞`（5 番）を段 0 に対して |

⛔⛔ **頭に `∧` と `⊠` と `📌` が無い理由は 1 つである** ——
**段 0 には畳み込む先の親が無く、消す実体が無く、留める行が無い。**
⭐ **入口が 4 つと 7 つに分かれるのは、この 1 つの違いからしか出ない。**

## 2. ⛔⛔ 実装は、頭と行で 1 階層ずれていた（実測）

| | 見本 | 実装（2026-08-31 の実測）|
|---|---|---|
| 行の `∧∧` | 直下の子が消える | ⛔ **直下の子は描かれたまま。消えるのは孫から下** |
| 行の `∨` | 直下の子が戻る | ⛔ **孫が戻る** |
| 行の `∧` のあと親の `∨` | その行だけ戻る | ⛔ **配下ごと全部戻る** |
| 頭の `∧∧` | 行 0 | ✅ 同じ |
| 頭の `∨` | L1 だけ | ✅ 同じ |

⭐ **頭は正しく、行だけが 1 階層ずれていた。**⇒ **同じ図形が 2 つの意味を持っていた。**
