# CR-182 — 「どれだけか」を測る規則を 3 つ与える

> **閉じるもの**: 繰り越し (b)（`FD-7` の下限が原稿で強制されていない）／ (i) と (w)（取り消しの 1 段の測り方）／ (o)（`CarryElement.children` の深さ）。
> **利用者の裁定**（2026-08-18）: **1 段は UTF-8 のバイトで測る／ carry の深さは 表 T-211 に行を新設**。
> ⭐ **3 つとも「値はあるのに測り方が無い」型である。** CR-173 と同じ族。

## 0. ⛔ 立ちどまって答える 3 つ（**検査 22 が空欄を許さない**）

### ① これは `CH-` / `GL-` のどれを前へ進めるか

| 本 CR の部分 | 答え |
|---|---|
| 取り消しの 1 段をバイトで測る | ⛔ **`CH-1` 〜 `CH-5` のどれも進めない。** ⭐ **ただし `NFR-004` の「端末で動く」を守る** —— 文字数で測ると和文の文書で上限が約 3 倍に緩み、端末のメモリ予算を 3 倍超過する |
| `carryMaxDepth` | ⭐ **`GL-004` を守る** —— 解釈しない要素を落とさず往復するのが `carry` の役目であり、**無制限の入れ子は信頼できない入力の受け口である**。⚠️ 進めるというより、開いている穴を閉じる |
| `FD-7` の下限を原稿へ | ⛔ **`GL-001` 〜 `GL-007` のどれも進めない。** 既に決まっている規則が原稿で強制されていなかっただけである |

### ② `review-standards` のどの条項を当て、何が出たか

| 条項 | 当てた対象 | 結果 |
|---|---|---|
| **`R6`**（試験品質）| 1 段の測り方 | ⭐ **試験を足し、実装を文字数へ戻して落ちることを確かめた。** ⚠️ **試験を書くのに 3 回作り直した** —— (1) 1 段しか無いときは捨てないので上限で測れない（`historyWithStep` が `done.length > 1` を条件にしている）(2) 測る対象は編集**前**の文書である (3) 使った命令を版が受け付けなかった。⭐ **最終形は「同じ文字数の ASCII と和文で、記録された大きさの差がちょうど 2 バイト × 文字数」** —— 文字数で測れば差は 0 になる |
| **`R3`**（エラー処理）| `utf8Length` | ✅ 純関数。`TextEncoder` を使おうとして ⛔ **`tsc` に拒まれた**（下記）|
| **`R7`**（純粋性）| `stepSize` / `utf8Length` | ✅ **引数だけを読んで返す。** グローバルにも実行環境にも触らない |
| **`R2`**（命名）| `carryMaxDepth` / `utf8Length` | ✅ 体を表す。⚠️ **`importMaxDepth` と紛らわしいので、備考で「別物」と名指した** |

## 1. 3 つの穴

| | 測った事実 |
|---|---|
| 1 | ⛔ **`FD-7` は「フェードはいずれも 0 以上」と定めるのに、原稿の `fadeInDays` / `fadeOutDays` は `minimum` を持っていなかった** —— 生成されたスキーマが負のフェードを通す |
| 2 | ⛔ **`S-95` は 64 MB（CR-178 で 1 MB = 1024 × 1024 バイトと定めた）なのに、実装は保存形の文字数で測っていた** —— ⚠️ **和文は 1 文字 3 バイトなので、上限が約 3 倍に緩んでいた。** ⭐ **実装は自ら「これはこのファイルの決めである」と書いていた** |
| 3 | ⛔ **`CarryElement.children` の意味欄が「深さの上限は定めない」と明記していた** —— `FR-023` の資源の上限は WBS の深さしか見ない |

## 2. ⛔ `TextEncoder` を使おうとして `tsc` に止められた

⭐ **最初の実装は `new TextEncoder()` で、コメントに「これは DOM ではない」と書いた。** ⛔ **`tsc` が `Cannot find name 'TextEncoder'` で拒んだ。**
⚠️ **`LR-6` は Entity と UseCase を DOM ライブラリ抜きでコンパイルすることで強制されており**（`tsconfig.entity.json`）、**私の「DOM ではない」という理屈は通らなかった。**

⭐ **規則が、読み手なら見逃したかもしれない場所で効いた。** 符号点から数える 8 行の純関数に置き換えた —— **実行環境のグローバルに触らないので、試験も素直である。**
