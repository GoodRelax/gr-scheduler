# CR-269 — 何も描かれない 56px

> **閉じるもの**: ⛔ **利用者の裁定（2026-08-27。案 B1）** ——
> 指摘は「**行タイトルパネルで操作子の場所が常に確保され、幅が無駄**」。
> 裁定は **`S-140` を 0 にし、操作子を行の名前に重ねて描く**。
> ⭐ **台帳の行は `D-63`。**

## 0. ⛔ 立ちどまって答える 3 つ

### ① この変更は `CH-` / `GL-` のどれを前へ進めるか

⭐ **`CH-2`（1 画面で全体を読める）。受ける目標は `GL-002`。**
⛔ **行見出しパネルの幅（`S-79`）のうち 56px が、`HF-6` により**画面のほとんどの時間で何も描かれない場所**に取られていた。**
⚠️ **その 56px は行の名前から引かれるので、名前は常に 56px ぶん早く `…` で打ち切られる。**

### ② レビュー観点のどの条項を当て、何が出たか

| 条項 | 当てた対象 | 結果 |
|---|---|---|
| **`R2.19`**（驚かせない）| `FR-085` の MUST NOT | ⭐ **覆さない。**「確保する場所を、操作子を描くかどうかで変えてはならない」は、**確保する量が常に 0 でも真である。**⛔ **0 は「変えている」ことにならない** |
| **`R1.4`**（欠落が無い）| 禁止の目的 | ⭐ **保たれる。**目的は「画面と書き出しで打ち切りの位置が一致すること」であり、書き出しは操作子を描かず場所も確保しない（表 T-076 の `EP-4`）。⇒ **両方 0 なら一致する** |
| **`R3.4`**（同じ算術を 2 か所に書かない）| `S-140` の行そのもの | ⛔ **消してはならない。**消すと `FR-085` の「`S-79` から インデント と 操作子に確保した場所 を引く」という算式が項を 1 つ失う。⭐ **0 という値を持たせる** |
| **`R2.19`** | ホバー中の見え方 | ⚠️ **代償が 1 つある** —— **ポインタが乗っているあいだ、長い行名の末尾が操作子に隠れる。**⭐ **`FR-085` は既に逃げ道を持つ**（「全文を見たい者はパネルを広げる」＝ `FR-052`）。⛔ **打ち切りの位置そのものは動かないので、書き出しとの一致は崩れない** |

### ③ 利用者に問わずに決めたこと（**覆してよい**）

| | 決めたこと | 何に載せたか |
|---|---|---|
| 1 | ⭐ **`HF-6` に「名前の上に重ねて描く」ことを 1 文で書いた** | ⛔ **`S-140` を 0 にするだけでは、操作子が名前とどう重なるかがどこにも無い。**⚠️ **`HF-4`（パネルの右端に揃える）と併せると重なりは必然だが、必然を読み手に導かせない**（規則 02）|
| 2 | ⛔ **`HF-4` / `HF-5` は 1 文字も動かさない** | ⭐ **右端に揃えることも、名前の上端に揃えることも、重ねても成り立つ** |
| 3 | ⛔ **`S-79` の既定は動かさない** | ⚠️ **パネルの幅は文書に保存され、人が動かす。**⭐ **本件が返すのは「幅のうち名前に使える割合」であって、幅そのものではない** |
