## 2. 何が食い違っていたか（**逐語**）

`FR-031`（`01-04-requirements.md:1557`）:

```
1 段の大きさは、その段の保存形を UTF-8 で符号化した長さ（バイト）で測ること（MUST）
```

実装（`document-change-plan.ts`）:

```ts
function stepSize(document: Document): number {
  return utf8Length(JSON.stringify(document))     // 詰めた形
}
```

保存する形（`json-codec.ts`）:

```ts
return JSON.stringify(document, null, 1) + '\n'   // 1 スペース字下げ ＋ 改行
```

⛔ **`JSON.stringify(document)`（詰めた形）は、製品のどこにも保存されない。数えるためだけに在る。**

⭐ **意図の証拠**: `CR-182` の同じコミットが**この文**と**実装の 1 行**を書き、直したのは「文字数 → バイト数」であって、直列化には触れていない。
