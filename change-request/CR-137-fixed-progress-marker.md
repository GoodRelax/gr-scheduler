# CR-137 — 進捗マーカーを固定サイズにする

## 1. 変更概要

**実装着手前レビューの `F-1`（Critical）を閉じる。** 同じ要素に相反する 2 つの MUST が立っていた。

```
FR-094 (:1044)  依存線と進捗マーカーと再開アイコンの寸法は、ズームに追随させてはならない（MUST NOT）
FR-013 (:2036)  進捗マーカーの大きさは実績バーに追随させ、実績バーより大きく描いてはならない（MUST NOT）
```

**実績バーの縦幅は `zoomY` に掛かる。** したがって `FR-013` に従えば必ず `FR-094` を破る。両者は「低いズームで読めなくなる」という**同じ理由から逆の結論**を出していた。

| # | 直すもの | 件数 |
|---|---|--:|
| ① | ⭐ **`FR-094` を採る。マーカーと再開アイコンは固定サイズ** | 要求 2 |
| ② | **`S-22` を `markerMin` → `markerSize`（固定値 16px）へ改名**（席は据え置き） | 設定値 1 |
| ③ | **`S-21 markerOfFont` と `K-21` を廃止**（席は欠番のまま残す） | 設定値 1 ／ 用語 1 |
| ④ | `S-63` に `FR-094` への指しを足し、`S-62` との非対称を消す | 1 |
| ⑤ | 表 T-026 に `RC-11`（16px を実物で選び直す）を足す | +1 行 |
| ⑥ | 検査の道具 3 本を直す | — |

## 2. 利用者の裁定（2026-08-15）

| 問い | 結論 |
|---|---|
| どちらの MUST を採るか | ⭐ **`FR-094`（固定サイズ）。** 理由 ——「**進捗マーカーは見えれば十分。複雑なロジックのできるだけ外に置きたい。**」 |
| 固定値 | **16px。** マジックナンバーでの実装を厳に禁ずる（設定値として持つ） |
| 保存の単位 | **文書ごと**（表 T-201 の他の寸法と同じ） |
| 細線の 2 形状でも 16px か | ⭐ **16px。レクタングル系と揃える。** ——「**サイズが揃っていないと逆に変だから。**」 |
| `FR-013` の「実績バーより大きく描いてはならない」 | **消す**（上の裁定と両立しないため） |

## 3. 確かめた —— いまの鎖

```
マーカー径 = markerOfFont(1.2) × fontOfActual(0.80) × actualOfPlan(0.73) × basePlanHeight(28) × zoomY
           = 19.6px × zoomY        …下限 markerMin(16px)
実績バー   =                         actualOfPlan(0.73) × basePlanHeight(28) × zoomY
           = 20.4px × zoomY        …下限 actualMin(16px)
```

⭐ **追随しているのは `zoomY` ≧ 0.82 の帯だけで、変化幅は 3.6px しかない。** それ以下では `markerMin` が効いて既に 16px 固定である。**本 CR は、いまの下限をそのまま全域に広げることに等しい。**

⚠️ **比 0.5 の細線（`shapeHeightOf.arrow` / `endpointSpan`）では、今日すでにマーカーが実績バーより大きい** —— 床が形状の比を掛ける前に当たるため、実績は 8px しかないのに `markerMin` の床で 16px になる。**固定化による悪化ではない。** 利用者は「サイズを揃えるほうを採る」と裁定した。
