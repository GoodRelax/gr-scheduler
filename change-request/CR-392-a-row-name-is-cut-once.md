> **閉じるもの**: 台帳の `DFC-612`（行見出しのラテン字の名前が、アプリの `…` とブラウザの CSS の `…` で二重に切られて見える）。前に立つ者の反証 2026-09-16: 係数 `labelCoef`（`S-30`）と「字の実寸を測らない」は `FR-093`・`LM-2a`・表 T-026 の `RC-3` が決めており変えない。原因は描く側の `text-overflow:ellipsis` が、`FR-085` で切った名前にもう 1 つ `…` を重ねることである。
