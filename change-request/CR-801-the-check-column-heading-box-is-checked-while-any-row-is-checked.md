- `R1.3`（同じことを 2 か所で言わない）—— 見出しの読みは `SQ-10` だけが持つ（`DT-8`・`RQ-1` は「`SQ-10` と同じ」）。コードは目の読み（`scheduleFilterReadinessOf`）を見出しにも使い、数え方を 2 つ持たない。
- `R1.4`（異常系・準正常系）—— 一覧に出ている行が 0 で見出しが空のとき（押しても何も足さない）、隠れた行だけが入っているとき（見出しは [レ]、押すと全部外す）を決めた。
