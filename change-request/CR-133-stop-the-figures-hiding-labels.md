## 1. 変更概要

**CR-132 で足した辺のラベルが、既存のラベルの上に印字されていた。** 図を PNG に書き出して目視して見つけた。

| # | 直すもの | 置き場 |
|---|---|---|
| ① | ⭐ **ラベルを、箱だけでなく既に置いたラベルからも避ける** | `build.py` |
| ② | ⭐ **配置に使う経路を、実際に描かれる経路（箱の境界で切った後）にする** | `build.py` |

⭐ **仕様書の文は 1 文字も変えない。** 表も図の番号も新設しない。**生成物 5 枚を作り直すだけである。**

## 2. 変更の背景・目的

### 2-1. 何が起きていたか

**CR-132 が `framework → layoutEngine` のクラスタ対を足した結果、図 F-013 で「layout once per frame」が「one operation」の上に重なった。**

```
CR-132 の前   … one operation …                    （1 行）
CR-132 の後   … layout once per frame              （2 行が同じ位置に重なる）
                 one operation
```

**`build.py` の `place_labels` は、ラベルを節点の箱から避けるが、他のラベルからは避けない。** 概要図では**すべての集約矢印が 1 本の通路を通る**ので、3 帯をまたぐ矢印と 1 帯だけの矢印が同じ点を選びうる。

### 2-2. ⭐ 同じ欠陥が前から在った —— **「converts」は隠れていた**

**直したあと、図 F-013 に現れるラベルが 8 本から 9 本になった。**

| | ラベルが見えている数 | 見えていなかったもの |
|---|--:|---|
| CR-132 の前 | **8 / 9** | `converts`（`calculates` の下に隠れていた） |
| CR-132 の後（本 CR の前） | **8 / 9** | `converts` ＋ `layout once per frame` が `one operation` に重なる |
| **本 CR の後** | ⭐ **9 / 9** | —— |

**図 F-015（読み取りの経路）でも 2 本が復活した。**

| ラベル | CR-133 の前 | 後 |
|---|---|---|
| `sizes + thresholds` | ⛔ `thresholds` に切れていた | ✅ 全部見える |
| `coordinates` | ⛔ 消えていた | ✅ 見える |

### 2-3. 欠陥② —— 中心から測ると、描かれる位置とずれる

**`_point_at` は箱の中心どうしを結ぶ折れ線の上で位置を測っていた。** ところが **draw.io は辺を箱の境界で切って描く。** そのため「経路の 0.60 の位置」は、実際に描かれる辺の 0.60 とは違う点になる。

⭐ **置き場所を書き込むときの値（`2 × fraction − 1`）は、描かれる辺に対する相対位置である。** つまり**測る経路と使う経路が食い違っていた。** ①だけを直しても、避けたはずのラベルが重なりうる。

**箱の内側に入る両端を落としてから測るようにした。**

### 2-4. 直った範囲と、直っていない 1 件

| 図 | 状態 |
|---|---|
| F-013 コンポーネントと層 | ⭐ **9 / 9 のラベルが分離した** |
| F-014 書き込みの経路 | **20 本すべて読める** |
| F-015 読み取りの経路 | **2 本が復活。**⚠️ **1 か所だけ残る**（§2-5） |
| F-016 / F-017 | 変化なし、または改善 |

### 2-5. ⚠️ 残る 1 件（**変更前から在り、本 CR で悪化していない**）

**図 F-015 の `presentation values` / `coordinates` / `what is selected` の 3 本が重なっている。**

**CR-132 の前の版を書き出して比べたところ、同じ 3 本が同じように重なっていた。** 本 CR は**この 1 か所を悪化させていないが、直してもいない。**

**原因は draw.io の側にある** —— 直交経路の辺では、draw.io は既定のラベル位置を「経路の中点」ではなく**中間の線分**から決める。折れ線の長さの比で測る本方式とは一致しない。**ここから先は draw.io の内部の再現になるので、本 CR では踏み込まない。**

## 4. 変更前の仕様

- `place_labels` は `LABEL_FRACTIONS` を順に当て、**節点の箱に掛からない最初の位置**を選ぶ
- **他のラベルとの重なりを見ない**
- 位置は**箱の中心どうしを結ぶ折れ線**の上で測る

## 5. 変更後の仕様

- **箱に掛からず、かつ既に置いたラベルの矩形とも重ならない最初の位置**を選ぶ
- 矩形は `文字数 × LABEL_CHAR_W`（6px）× `LABEL_LINE_H`（18px）で見積もる。**多めに取る**
- 位置は **`_trimmed` が両端を箱の内側で落とした後の折れ線**の上で測る —— **描かれる辺と一致する**
- **中点のまま動かさなかったラベルも「置いた」として記録する** —— しないと後続がその上に乗る
