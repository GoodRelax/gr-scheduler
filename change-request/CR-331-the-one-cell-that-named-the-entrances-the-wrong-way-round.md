## 1. ⛔ 測った —— 出荷ビルド、既定の 6.00px/日 から 1 回だけ押す

⭐ **px/日 は目盛の月ラベル 2 つの経度から読み直した。仮定していない。**

```
Shift + '+'   6.0000 -> 6.6000   拡大    ← SK-16 の語のとおり
Shift + '-'   6.0000 -> 5.4545   縮小    ← SK-16 の語のとおり
IC-12         6.0000 -> 5.4545   縮小    ← SK-16 は「拡大」と並べている  ✗
IC-13         6.0000 -> 6.6000   拡大    ← SK-16 は「縮小」と並べている  ✗

行軸（縦）も同じであった。単位は行の帯の平均間隔:
Alt + '+'     125.1429 -> 135.0651   拡大    ← SK-16a の語のとおり
Alt + '-'     125.1429 -> 116.3633   縮小    ← SK-16a の語のとおり
IC-14         125.1429 -> 116.3633   縮小    ← SK-16a は「拡大」と並べている  ✗
IC-15         125.1429 -> 135.0651   拡大    ← SK-16a は「縮小」と並べている  ✗
```

**仕様の側:**

```
表 T-036 の SK-16   「時間軸（横）を拡大 / 縮小する」 → Shift+'+' / Shift+'-' → IC-12 / IC-13
表 T-109 の IC-12   「時間軸を縮小する（S-75）」

表 T-109 の IC-15   「行軸を拡大する（S-76）」
```
