## 4. 書き直す所

### X-1 —— `FR-054`（「保存する日時の最小単位は 1 分とすること（MUST）。」の次）

```
⭐ 秒が `00` でない時刻（`2026-01-05T08:00:30`）は、分へ切り捨てて読むこと（MUST） —— 読めない値として断らない（利用者の判断）。
```

### X-2 —— `FR-054`（「丸 1 日の範囲 … その日の終わりと読む。」の次）

```
⭐ 時刻を書いていない日付の字（`2026-01-05`）は、表 T-350 の開始の側の列（`WT-1`・`WT-3`）ではその日の最初の時間帯の始まり、終了の側の列（`WT-2`・`WT-4`、`WT-5` のマイルストーンの開始の側）ではその日の最後の時間帯の終わりの瞬間と読むこと（MUST） —— 日付だけの値はその日の仕事の始まりと終わりを指す（利用者の判断）。
その日の時間帯は上の段の稼働時間とし、非稼働日では `FR-088` の 表 T-344 の `WC-8` の 1 組とする。
⚠️ `00:00:00` と読まない —— 終了の側で前の日の終わりになり、日付だけの文書の最後の日が 1 日消える。
```

### X-3 —— `FR-011`（「負なら `actualStart` から同じ分だけ戻った瞬間である …」の次）

```
⭐ 同じ稼働時間に当たる瞬間が 2 つ以上あるとき（時間帯の終わりと、次の時間帯の始まり）は、最も早い瞬間に置くこと（MUST） —— 08:00 から 240 分は 12:00、480 分はその日の 17:00 であり、13:00 や次の稼働日の 08:00 ではない（利用者の判断）。
仕事が尽きた所で止まったと読む —— 遅い方に置くと、休みの時間を挟んで `stop` が次の時間帯へ跳ぶ。
```

### X-4 —— 表 T-220 の `IV-14`（最初の文の次）

```
⭐ 秒が `00` でない時刻は分へ切り捨てて読むので、本行に反しない —— 時刻を書いていない日付の字も読める（どちらの読みも `FR-054`）。
```
