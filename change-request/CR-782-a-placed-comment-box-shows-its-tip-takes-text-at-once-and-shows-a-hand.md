# CR-782 —— 置いたコメントボックスは線先を左下へ少し出し、すぐ本文を打てて、本体の上ではてのひらになる

> 状態: ⭐ **当てた** —— 2026-10-17、作業木 `9171429f` の上に、起草と同じ席が当てた（変更履歴は 4.95、`perf-pending` は 229）。仕様だけを読む別の席が試験を書いた（`tests/contract/cr-782-*`）。
> 当てる裁定: `JDG-2447`（F2 の 1)）・`JDG-2450`（F2 の 3)・4)）。取り下げ: `JDG-2448`（F2 の 2)）。この CR の外: `JDG-2449`（F2 の 5)・6)、利用者の報告を扱う席が受ける）。
> 台帳: `DFC-2951`。

---

## 0. ⛔ 立ちどまって答える 3 つ

### ① この変更は `CH-` / `GL-` のどれを前へ進めるか

`GL-008`（押す前に何が起きるかが分かる）と `GL-006`。利用者がアルファの前に試して「□しか配置されず、コメントボックスに見えない」「置いても本文を打てない」「本体を動かせると分からない」と言った 3 つを直す。

### ② レビュー観点のどの条項を当て、何が出たか

`docs/development-rules/07-review-standards.md` の **`R2`**（規則の在り処が 1 つ）。
出たこと: ① 置いた直後に本文の欄へ焦点を置く道は、ダブルクリックの道（`FR-097`、`editInPlace` の `commentBoxText`）と同じ欄の名（`FIELD_ROW_OF_IN_PLACE_TARGET`）を読む —— 欄の行 ID を 2 か所に書かない。② 作ったものを選ぶ出来事は、選択の状態機械に `createdTaskSelected` と並べて 1 つ足す（`createdCommentBoxSelected`）。

### ③ 利用者に**問わずに決めた**こと（**覆してよい**）

1. ⭐ 線先を出す量は、本文の箱を線先から右と上へ同じだけずらす 1 つの値（表 T-217 の `S-600`、既定 12px 🔎）とした。置く命令（`CM-46`）がその値をずれ（`AT-115`）として書くので、エージェントが置いた箱も同じ形になる。読み込んだ文書のずれ `null` は今までどおり `{ 0, 0 }`。
2. ⭐ 置いた直後は、タスクの名前の欄（`FR-091`）と違い、`Enter` でパネルを閉じない —— 本文は改行を打てる欄（`MK-13`）である。
3. ⭐ てのひらは本体と引出し線の両方に付ける —— どちらを引いても本文の箱が動く（表 T-023d の結び）。線先は今までどおり `PK-11`。

## 1. 対応

| # | 直すこと | 仕様の ID | 直す物 |
|---|---|---|---|
| 1 | 置いた箱の本文を線先から右上へずらし、線先と引出し線を左下へ出す | `FR-019`・表 T-108 の `CM-46`・表 T-217 の `S-600` | `settings.json`、`edit-annotation.ts` の `createCommentBox` |
| 2 | 置いたら選び、パネルを出して本文の欄に焦点を置く | `FR-019`・表 T-023b の `AR-5`・表 T-016 の `PR-21`・状態機械の選択の領域（`createdCommentBoxSelected`） | `armed-placement.ts`（作ったものとしてコメントボックスを渡す）、`frame-loop.ts` の `standOnCreatedCommentBox`、`selection-values.ts`・`advance-screen-session.ts`・`file-flow-values.ts` |
| 3 | 本体と引出し線の上ではてのひら | `FR-106`・表 T-269 の `PK-8` | `pointer-shape.ts` の `pointerRowOf` |
