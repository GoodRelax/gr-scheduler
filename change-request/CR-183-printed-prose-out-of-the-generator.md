# CR-183 — 生成器が抱えていた刊行文を原稿へ出す

> **閉じるもの**: 繰り越し (u)（`erd_json_to_md.py` が刊行される日本語を自分で持っている）。
> ⭐ **CR-176 が「原稿の散文は言語ごとに持つ」と定めたが、生成器が持つ刊行文はその網の外に居た。**
> ⚠️ **検査 23 は生成器の中を見ない。** 今回もそれは変わらない —— **無くしたのは、見られていない場所に置かれた刊行文である。**

## 0. ⛔ 立ちどまって答える 3 つ（**検査 22 が空欄を許さない**）

### ① これは `CH-` / `GL-` のどれを前へ進めるか

⛔ **答えは「どれも進めない」。** 表 T-054 の `CH-1` `CH-2` `CH-3` `CH-4` `CH-5` と `GL-001` 〜 `GL-007` を 1 つずつ当てたが、当たる先は無い。
⭐ **刊行の基盤であり、日英で出すと決めた回に「記入だけで済むか」を決める作業である。** ⚠️ **`CH-` を進めない CR がこれで 4 本目**であり、そう並べて見えることは答えの一部である —— **W4 が `CH-` を進める側である。**

### ② `review-standards` のどの条項を当て、何が出たか

| 条項 | 当てた対象 | 結果 |
|---|---|---|
| **`R4`**（重複）| 表の見出しと罫線 | ⭐ **本物の重複を 1 つ消した。** 見出しの行と `| --- | --- |` の行は別々に書かれ、**生成器は「この 2 つのパイプの数が合っているか」を検査していた** —— 2 か所に書いたから要る検査だった。⭐ **罫線を見出しの数から導いたので、その検査ごと消えた** |
| **`R6`**（試験品質）| 契約 | ⭐ **わざと 6 通り壊して 6 件とも落ちた**（素の文字列へ戻す／言語鍵の無い見出し／`printed` を丸ごと消す／真偽の語を素で書く／宣言していない語／carry の意味を落とす）|
| **`R3`**（エラー処理）| `text()` | ✅ **`ja` を持たない辞書は `SystemExit`。** 空文字を返して静かに刷らない |
| **`R2`**（命名）| `printed` / `words` / `header_rows` | ✅ **`printed` は「刷られるもの」であり、`$comment`（刷られない注記）と対になる** |
| **`R7`**（純粋性）| —— | `src/` の関数を 1 つも書いていない |

### ⑧ 利用者に問わずに決めたこと（**覆してよい**）

| | 決めたこと | 何に載せたか |
|---|---|---|
| 1 | 見出しを**節ごと**（`sections[].header`）に置いた | ⭐ 見出しは表に属し、表は節に属する。⚠️ `settings.json` は `columns: [{field, ja}]` の形で、**あちらは列名で引くから field が要る。こちらは位置で組むので要らない** |
| 2 | 罫線を**生成する**（原稿に持たない）| 見出しの数から一意に決まる。⛔ **持たせると 2 か所になる** |
| 3 | `default_note` に `{value}` の差し込み口を作った | ⚠️ **原稿にテンプレートを置く形は初めてである。** `settings.json` の `prefix` / `suffix` が同じ役割を分解して持っており、どちらが良いかは決めていない |
| 4 | `type_detail_separator`（`・`）と `key_separator`（` ＋ `）も原稿へ | ⭐ **検査 23 が同じ思い込みを `settings.json` の「・」で捕まえたばかりである** —— 短い記号は言語に属さない、という思い込み |

## 1. 何が生成器に居たか

| 刷られていたもの | どこへ |
|---|---|
| 生成物のバナー 3 行 | `printed.banner` |
| 4 つの表の見出し（25 セル）| `documents[].sections[].header` |
| carry の辺のラベルと、派生する関係行の多重度・意味 | `printed.carry` |
| 「書き出す」/「**書き出さない**」/「あり」 | `printed.words` |
| 既定を刷る文（`。**既定は {value}**`）| `printed.words.default_note` |
| 型の詳細を繋ぐ `・`、鍵を繋ぐ ` ＋ ` | `printed.words` |

⛔ **これらは 表 T-056 〜 T-059 と 図 F-011 に実際に刷られている。** ⚠️ **日英で出すには Python を編集する必要があった** —— 裁定 ㊹ が「記入にするため」と書いた形になっていなかった。

### ⭐ 残したもの（**分類であって散文ではない**）

```
BRACE_TYPE   '{ dx, dy }' → 'オブジェクト'      型のトークン
split_type   '（' '）' で型の括弧を割る          型の解析
```

⛔ **どちらも `type` 欄の分類を読む処理であり、検査 23 が員数付きで免除している類そのものである。** ⭐ **分類の綴りを決める回に、この 2 つも一緒に動く。**
