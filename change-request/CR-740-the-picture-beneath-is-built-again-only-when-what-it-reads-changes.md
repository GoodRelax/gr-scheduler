## 11. 問い

調整役（利用者）への問い 1 つ。

### 問い 1 —— 下の絵の覚え置きを、範囲選択のあいだだけにするか、画面のフレームすべてにするか

- 場面: `Schedule Canvas` の何も無い所から左ドラッグで範囲選択（`MK-6`、画面の名 範囲選択 / Range Selection）をしているあいだ。ほかに、何も押さずに指を日程表の上で動かしているあいだ（指の形を変えるためにフレームが走る）も、絵が指から読むものが変わらなければ絵は同じである。
- 使う場面の例: 大きな見本（`Task` 257）で、何も無い所を押して右下へ大きく引き、10 本ほどのタスクを囲んで離す。引いているあいだの約 2 ms/フレームが消える。何も押さずに指を空いた日の列の上で動かしているときも、同じ 2 ms が消える。
- (A) 画面のフレームすべてで覚える（**推奨**） —— 鍵の規則は 1 つ。理由: 鍵の漏れ（絵が読むのに鍵に無いもの）は古い絵として出るが、すべてのフレームで覚えれば、シェルを回す数千の既存の試験が漏れを踏む。範囲選択のあいだだけだと、漏れは範囲選択のあいだだけに隠れ、試験も実物も見つけにくい。何も押さずに指を動かすフレームも速くなる。
- (B) 範囲選択（表 T-023a の `PTD-5`）を握っているあいだだけ覚える —— 鍵が漏れても害は範囲選択のあいだに限られる。代償: 漏れが見つかりにくい（上のとおり）。`CA-1` の ③ に「`PTD-5` を握っているあいだだけ」の一文が要る。
- (C) 覚えない（`DFC-2446` の ②、2 ms を残す） —— 鍵の漏れは起こらない。代償: 範囲選択のあいだ 2 ms/フレームが残る（`CR-736` の問い 1 の調整役の線を越えたまま）。
