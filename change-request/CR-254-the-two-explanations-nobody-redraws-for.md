# CR-254 — 誰も描き直してくれない 2 つの説明

> **閉じるもの**: ⛔ **CR-252 は「ポインタが乗っているあいだだけ出す」を `FR-085` の MUST にしたが、`FR-048` の名簿にその説明を足さなかった。**
> ⚠️ **名簿に無いものは「描く内容が変わる」に当たらないので、ポインタを動かしても描き直されない。**
> ⭐ **つまり「マウスをずらすと自動で消える」が、仕様のうえで成り立たない。**

## 0. ⛔ 立ちどまって答える 3 つ

### ① この変更は `CH-` / `GL-` のどれを前へ進めるか

⭐ **`CH-2`（1 画面で全体を読める）。受ける目標は `GL-002`。**
⛔ **消えない説明は日程を隠し続ける。**⚠️ **前の変更要求が閉じたつもりの穴の、残り半分である。**

### ② レビュー観点のどの条項を当て、何が出たか

| 条項 | 当てた対象 | 結果 |
|---|---|---|
| **`R1.4`**（欠落が無い）| `FR-048` の名簿 | ⛔ **`FR-085` も `FR-037` も挙がっていない。**⭐ **どちらもいまはポインタの位置だけで立ち消えする** |
| **`R2.18`**（自己矛盾が無い）| `FR-085` と `FR-048` | ⛔ **前者が MUST で「乗っているあいだだけ」と定め、後者が「その移動では描き直さなくてよい」と読める** |
| **`R1.4`**（欠落が無い）| `MC-8` の「4 つ」| ⛔ **数を写している。**⭐ **足せば黙って古くなる** |

### ③ 利用者に問わずに決めたこと（**覆してよい**）

| | 決めたこと | 何に載せたか |
|---|---|---|
| 1 | ⭐ **`FR-037`（スクロールバーの説明）も一緒に足す** | ⛔ **同じ形の穴である。**⚠️ **同要求は自分でポインタの条件を書いており、`FR-085` と違って前から正しかった。名簿だけが漏れていた** |
| 2 | ⭐ **`MC-8` から数を外し、名指しに替える** | ⛔ **規則 02 の罠そのものである** —— 数を写した注記は、原稿が動いても古い数を言い続ける |
| 3 | ⛔ **`NFR-010` の一般則は 1 文字も触らない** | ⭐ **判定を「描く内容が変わったか」に置く軸は正しく、本件はその名簿の話である** |
