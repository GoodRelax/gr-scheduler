### ① この変更は `CH-` / `GL-` のどれを前へ進めるか

`GL-006`（人と AI が同じ文書を触る）。仕様には「呼び手が申告した名」と書いてある。だが、申告する口はどこにも無い（`grep -rn "writer\|watcher" src/adapter/mcp-tool-translator src/framework/mcp-relay-server` で 0 件）。そのため AI の作り手は、仕様を読んでも渡す所が見つからない。本書はこの穴を閉じる。

### ② レビュー観点のどの条項を当て、何が出たか

`docs/development-rules/07-review-standards.md` の **`R1.2`**（検証できること）と **`R2`**（規則の在り処が 1 つ）。

- `R1.2`: 「呼び手が申告した名」は、申告の道が無いので試験が書けない。固定の語なら、出荷ビルドで書いた刻印を読めば確かめられる。
- `R2`: 書き手の語を持つのは表 T-229 だけとする。`FR-063` の「名乗ってはならない」は、語が 3 つとも固定になると表の 3 行が互いに違うことの言い直しになる。だから 1 文に縮めて表を指す。
