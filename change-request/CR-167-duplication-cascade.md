# CR-167 — 表 T-050 に対になる「複製の連鎖」を置く

> ⛔ **未適用である。利用者の裁定を受けて起草した。**
> **閉じるもの**: W3 の裁定 8 件のうち **2 件**（`pasteTaskSubtree` ／ `pasteTaskGroupSubtree`）。
> ⭐ **裁定は「見た目も担当も連れて行く」である**（本セッション）。

## 1. 出どころ

**削除には 表 T-050（削除の連鎖）が在るのに、複製には対になる表が無い。**
`FR-033` は散文で 5 つを決めているが、**一緒に複製されるものの全数を持っていない。**

### ⭐ `FR-033` が既に持っているもの（本 CR は触らない）

| | 逐語 |
|---|---|
| WBS の子孫 | 「選ばれた `Task` とその WBS の子孫を**部分木ごと**複製する」 |
| 載る行 | 「複製した `Task` は、複製元と同じ行に載せること（MUST）」 |
| 依存 | 「部分木の**内側で閉じている依存だけ**を複製すること（MUST）。外へ出る依存を複製してはならない（MUST NOT）」 |
| `UID` | 「複製元と同じ `UID` を使ってはならない（MUST NOT）。採る `UID` の決め方は `FR-001` が持つ」 |
| `TaskOrigin` | 「複製に `TaskOrigin` を付けてはならない（MUST NOT）」 |
| 段と深さ | `ST-7` の安全弁に達したら受け付けない。貼り付け後の深さが `FR-004` の上限を超える複製を受け付けない |

### ⭐ 調べたら穴ではなかったもの

⛔ **「その `Task` に付いた注記を写すか」は問いとして成り立たない** —— `CommentBox` は `anchorDate` と `anchorGroupId`、
`HighlightBox` は日付 2 つと行の識別子 2 つで位置を持つ（`FR-019`）。**どちらも `Task` を指していない。**
表 T-050 の `CD-1`（`Task` を消す）が注記を挙げていないのも同じ理由である。

### ⛔ 本当に無い 3 つ

| | 無いもの |
|---|---|
| (a) | **`TaskVisual` を複製するか** —— 写さないと、矩形・青のタスクを複製したときに既定の形・色に戻る |
| (b) | **割当（`Assignment`）を複製するか** |
| (c) | **行の部分木を複製したとき、載っている `Task` をどうするか** —— ⚠️ **「複製元と同じ行に載せる」をそのまま当てると、複製した `Task` が元の行に載り、新しい行が空になる。** 着け先も無い |

## 2. 何をするか

**`FR-033` の中に 表 T-223 を置く**（表 T-050 が `FR-032` の中に在るのと同じ形）。

### 表 T-223（新設・2 行）

**表 T-223 — 複製の連鎖**

| 行 ID | 複製するもの | 一緒に複製されるもの |
| --- | --- | --- |
| DU-1 | `Task` | **その `Task` の WBS の子孫**、`TaskVisual`、`TaskGroupMember`、**部分木の内側で閉じた依存**、**その `Task` を指す割当**（`Assignment`）。⛔ **`TaskOrigin` は複製してはならない（MUST NOT）** |
| DU-2 | 行（`TaskGroup`） | **配下の行**、**その行に載っているすべての `Task`**（`DU-1` が各 `Task` に連鎖する）。⚠️ **複製した `Task` は複製した行に載せる。** ⛔ **その行を指す注記とピン止めは複製してはならない（MUST NOT）** |

**`DU-1` が複製するものは、表 T-050 の `CD-1` が消すものと、`TaskOrigin` を除いて一致すること（MUST）** ——
**複製してすぐ消したときに元と違う文書が残ってはならない。** `TaskOrigin` だけが外れる理由は `FR-033` が持つ（交換相手から来たものではない）。

**貼り付け先は、選んでいる行の子とすること（MUST）。何も選んでいないときは最上位に置くこと（MUST）。**
⚠️ **`FR-033` が「貼り付け後の深さが `FR-004` の上限を超える複製を受け付けてはならない」と書いているのは、着け先で深さが増えうることを前提にしているからである** —— 兄弟として着けるなら深さは変わらず、その MUST NOT は一度も働かない。

⚠️ **`DU-2` が「複製した行に載せる」のは、`FR-033` の「複製元と同じ行に載せる」が `Task` を単独で複製したときの規則だからである。** 行ごと複製したときにそれを当てると、**新しい行が空になり、複製の目的（同じ形の工程を対象ごとに横へ並べる）を満たさない。**

⚠️ **注記を複製しないのは、注記が `Task` にも行にも「付いて」いないからである** —— 位置は日付と行の識別子で持つ（`FR-019`）。行を複製したときに写すと、同じ日付に注記が二重に出る。
⚠️ **ピン止めを複製しないのは、`S-127` の上限を人の知らないうちに埋めるからである**（上限に達したときの扱いは `FR-098`）。

## 3. ⚠️ 書かないと決めたもの

| | |

| **複製した行の名前** | ⚠️ **射程外。** 行の名前は `FR-085` と `AT-54`（名前も導出元も無い行を残さない）が持つ |
