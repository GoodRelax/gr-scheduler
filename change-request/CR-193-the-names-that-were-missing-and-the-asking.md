## 4. `NT-7` に何を書き、何を書かないか

⭐ **書くのは作法だけである。**

```
書く    何が起きるかを示したうえで、続けるか取りやめるかを選ばせること（MUST）
        消えるもの・解かれるものがあるときは、その名前を挙げること（MUST）

        「はい」「いいえ」の語            ← どの要求も定めていない
        面の名                            ← 表 T-103 に行を足していない。確認は S-99g の面ではない
```

⭐ **裁定 D6（上書き確認）が `NT-7` を使えるようにしてある** —— **名前を挙げるのは「消えるもの・解かれるものがあるとき」の条件付きであり、
ファイルの上書きを問うときは名前の並びが空になる。** ⛔ **空を許さない形にすると D6 が使えない。**
