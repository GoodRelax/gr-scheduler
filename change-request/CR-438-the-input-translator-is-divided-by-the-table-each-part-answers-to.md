## 13. 書くときの作法（⛔ 当てる体はここを読んでから書く）

- **CJK の直後に `**` を開いて、その中を code span で始めない** —— docutils が壊れる。
- 「表 X の N 行」と書かない —— 検査が X の行数についての主張として読む。**行 ID を名指す。**
- `python tools/fix_line_breaks.py` を、触ったファイルすべてに掛ける。
- 検査は**終了コード**で判ずる。⛔ `FAIL` を `grep` しない —— `check-function-size.py` は `FAIL` と刷るが、`check_layer_rules.py` は `VIOLATION` と刷る。検査 11・12・33 は `FAIL` の行を刷らずに赤になる。

- `git log -L` は範囲を 1 つずつ掛ける（4.0）。
