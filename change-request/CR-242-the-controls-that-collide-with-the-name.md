# CR-242 — 行名とぶつかる操作子

> **閉じるもの**: ⛔ **表 T-051 の `HF-5` は「名前が操作子より大きいときは上端で揃える」と定める。**
> ⛔ **利用者の訴え（逐語、2026-08-24）: 「`>` 、折りたたみ、ピン止めをタスクグループ名の少し下において、タスク名と干渉しないようにしろ。」**
> ⚠️ **実測: 描く側は上端でも下端でもなく中央で揃えている** —— ⛔ **`HF-5` の後半はいま守られていない。**
> ⭐ **利用者の裁定（2026-08-24）: 下げ幅をタスクグループのフォントサイズで決める。**

## 0. ⛔ 立ちどまって答える 3 つ

### ① この変更は `CH-` / `GL-` のどれを前へ進めるか

⭐ **`CH-4`（説明を読まずに操作できるようにする）。受ける目標は `GL-006`。**
⚠️ **`HF-4` の理由が「名前ごとに位置が変わると狙えない」であり、`HF-5` はその縦の相方である。**
⛔ **名前と操作子がぶつかると、狙えるかどうかが名前の長さと文字サイズで変わる。** ⭐ **`HF-4` が横で禁じたことを、縦で許してしまっている。**

### ② レビュー観点のどの条項を当て、何が出たか

| 条項 | 当てた対象 | 結果 |
|---|---|---|
| **`R1.4`**（欠落が無い）| `HF-5` の「上端で揃える」 | ⛔ **揃え方は書かれているが、その結果が名前とぶつかることを誰も見ていない。** ⭐ **「少し下」という量を持つ行が無い** |
| **`R1.1`**（矛盾が無い）| `HF-5` と実装 | ⛔ **食い違っている。** 仕様は上端、実装は中央。⚠️ **どちらが正かは仕様が決める** |

### ③ 利用者に問わずに決めたこと（**覆してよい**）

| | 決めたこと | 何に載せたか |
|---|---|---|
