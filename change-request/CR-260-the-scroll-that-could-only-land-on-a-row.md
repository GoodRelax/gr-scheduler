# CR-260 — 行の上にしか着地できなかったスクロール

> **閉じるもの**: ⛔ **利用者の裁定（2026-08-25）: スクロール位置を JSON に保存する。**
> 「飛び飛びだと UI 上気持ち悪くて『ぬるサク』を達成できない。」
> ⛔ **`S-77` は日付、`S-78` は行の識別子でしか位置を持てないので、1 日・1 行より短い移動は何も動かさない。**

## 0. ⛔ 立ちどまって答える 3 つ

### ① この変更は `CH-` / `GL-` のどれを前へ進めるか

⭐ **`CH-2`（1 画面で全体を読める）。受ける目標は `GL-002`。**
⛔ **見たい場所へ運べないスクロールは、1 画面に収まらない日程を読む唯一の道を塞ぐ。**

### ② レビュー観点のどの条項を当て、何が出たか

| 条項 | 当てた対象 | 結果 |
|---|---|---|
| **`R2.18`**（自己矛盾が無い）| 「パンは等倍とすること（MUST）」と `S-78` | ⛔ **行まるごとでしか持てない値で等倍は表せない。**⭐ **どちらかが偽であり、偽なのは値の側である** |
| **`R2.20`**（届く）| 短いドラッグ | ⛔ **1 行（実測で 40px 前後）より短い操作が何も起こさない** |
| **`R3`**（境界）| ズームと画面幅 | ⭐ **`FR-080` が px を禁じた理由はここにある。**⛔ **端数を px で持てば同じ罠を踏む** |

### ③ 利用者に問わずに決めたこと（**覆してよい**）

| | 決めたこと | 何に載せたか |
|---|---|---|
| 1 | ⛔ **端数を px で持たない。`S-77` / `S-78` が指す錨の「自分の大きさ」に対する比で持つ** | ⭐ **`FR-080` の MUST NOT は 1 文字も動かさない。**⚠️ **同要求が px を禁じた理由は「ズームや画面幅が変わると別の場所を指す」であり、比なら指す場所は変わらない** |
| 2 | ⭐ **錨は残す** —— 日付と行の識別子はそのまま | ⛔ **捨てると `OP-10`（指す行が無いときの規則）と `WY-1`（書き出しの再現）が拠り所を失う** |
