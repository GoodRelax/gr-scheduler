### 4.3 選択・結ぶ・外す（状態遷移）

選択は 1 つで、構えの外と中で共有する。クリックは選び、ドラッグは結ぶ —— 手の意味は、構えの前後でも選択の有無でも変わらない（`JDG-1135`）。

| いまの状態 | 操作 | 次の状態と結果 |
|---|---|---|
| 構えなし・選択なし | 親定義を押す | 構え・選択なし |
| 構えなし・子を N 件選んでいる | 親定義を押す | 構え・選択はそのまま（N 件が子） |
| 構え | バーをクリック（`Shift`、`Ctrl` で足す・外す） | 選択が変わり、家族の矢印が追随する |
| 構えあり・なし | 何も無い場所をドラッグ | 範囲選択（`SL-3`、囲みきったものだけ）—— バーと実線の矢印。点線は黙って除く |
| 構えあり・なし | 何も無い場所をクリック | 選択を外す |
| 構え・選択 S | S の中のバーから親のバーへドラッグ | S のすべてを結ぶ（決定 8）。構えと選択はそのまま |
| 構え・選択 S | S の外のバーからドラッグ | 選択をそのバー 1 つに替えて結ぶ |
| 構え | 何も無い場所で離す | 何もしない（`AR-4` と同じ） |
| 構え | マイルストーンの上で離す | `RS-<新1>` を `OK` 1 つの面で出す。書かない（決定 15） |
| 構え | 自分・子孫の上で離す | 結ばない。`RS-<新3>` で、どの子がなぜかを告げる |
| 構えあり・なし（矢印が見えている） | 実線の矢印をクリック（`Shift`・`Ctrl` で足す） | 矢印を選ぶ。`Del` で子の親を外す（決定 9） |
| 構えあり・なし（矢印が見えている） | 点線の矢印をクリック | 選ばない。`RS-<新2>` を告げる（決定 10） |
| 構えあり・なし | 選択にタスクと矢印が混ざった | `QN-<新1>` の 2 択をポインタの近くに出す: 「[== ==] 親子関係を定義するため子タスクを選択」（構えていなければ「タスクを選択」）／「[↑ ↑] 親子関係を削除するため矢印を選択」。選んだ種類だけ残す。`Esc` か外を押すと混ざる前の選択に戻る（`JDG-1142`）—— ⭐ 混ざった選択は残らないので、`Del` がタスクを消すことは無い |
| 構え | `Esc` か親定義の再押下 | 構えなし・選択はそのまま |
