> **問い**: 表 T-024a の `OP-10` が言う「**その文書が覆う最初の日**」は、**何の日付を数えた最小値か。**

### 機構

⛔ `OP-10` は CR-286 で「**その文書が覆う最初の日と、行の木の先頭から描くこと（MUST）**」を得た（`01-04-requirements.md:3254`）が、**「覆う」を定める行が仕様書に 0 件である。**⇒ **`Task` の日付だけを数えるのか、`HighlightBox` / `CommentBox` の日付や暦の例外日も数えるのかで、最初の日が変わりうる。**

⭐ **根拠は仕様の逐語 2 つである。**

⚠️ **③ は退ける** —— 暦の例外日は `Exception.fromDate` の備考が自ら「**繰り返しの起点であって実日付の範囲ではない**」と書いており、**日付の範囲として数えられる列ではない。**
