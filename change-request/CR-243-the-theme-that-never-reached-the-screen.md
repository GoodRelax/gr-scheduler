# CR-243 — 暗いテーマが暗くならない

> **閉じるもの**: ⛔ **利用者の訴え（逐語、2026-08-25）: 「ダークモードで色が変わるが、ダークになっていない。」**
> ⭐ **実測した原因は「色が違う」ではなく「地が無い」である:**
> ⛔ **`color-scheme` は `src/` に 0 回しか現れない。地の色を塗っている場所が 1 つも無い。**
> ⛔ **`themePreference`（`S-72`）を読む場所は 3 か所あるが、そのどれも DOM へ届いていない。**
> ⚠️ **画面の道具はすべて OS のシステム色（`Canvas` / `CanvasText` / `ButtonFace` / `GrayText`）で描かれており、これは OS に追随して `S-72` には追随しない。**
> ⛔ **行の帯（`FR-041` / `FR-042`）は、そもそも 1 本も描かれていない。**
> ⭐ **あわせて利用者の裁定（2026-08-24）: 依存線は山吹、イナズマ線は赤茶。テーマ色相には追随させない。**

⚠️ **`CH-4` にも触れる**（`GL-006`）—— ⛔ **暗い部屋で白い地が出るのは「読まずに使える」以前の問題である。**
