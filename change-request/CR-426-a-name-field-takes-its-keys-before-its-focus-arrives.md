## 7. 試験が主張すべきこと

⭐ 名前は本書のとおりに写すこと: 表 T-028 の `IN-5a` / `IN-5b`、表 T-263（`IR-1`〜`IR-3`、列「行 ID・何を・書き方」）。

1. `IN-5a`: タスクをダブルクリック（`MK-13`）した直後、名称の欄に焦点が入る前に `P` を押しても、コマンドパレットの表示が切り替わらず（`SK-14` が起きない）、焦点が入った名称の欄に `P` が入る。`F`（`SK-18`）も同じ。
2. `IN-5a`: 同じあいだに `Delete` を押しても、選択しているタスクが消えない（`SK-3` が起きない）。
3. `IN-5a`: 求めのあいだに `Esc` を押すと求めが取り下げられ、そのあとの `P` はショートカットとして効く。
4. `IN-5b`: 名前の欄を求めたフレームで欄がまだ描かれていないとき、次のフレームで焦点が入る（置き直す）。
5. `IN-5b`: 置き直す前に人が別の欄をクリックして焦点を移したら、名前の欄へ焦点を戻さない。
6. `FR-102` / `IR-1`〜`IR-3`: 記録しているあいだの各フレームの行に、焦点の種類（例: 表 T-016 の `PR-1`）、プロパティパネルの状態（`S-99h` の 3 値のどれか）、出ている通知の理由の行 ID（例: `RS-25`）が並ぶ。⛔ 名称の欄の中身の文字列が記録に現れない。
