# CR-361 — 文書名は、出ているその場で編集する

⭐⭐ **利用者の裁定 2026-09-06（逐語）**: 「**提案通り (b)とせよ**」

**同じ欠落で止まっているもの**: **担当者ラベルのその場編集**、**`FR-091`（作った直後に打てること）**。

## 1. ⭐ いま何が起きているか（**実測 2026-09-06**）

```
翻訳側   F2 を受けて「文書名をその場で編集せよ」を出している
         （input-command-translator.ts の SK-9 の枝）
殻       その命令を受け取り、taskName と rowName の 2 つの枝で処理し、
         文書名は STOP へ落ちる ——「SK-9 のためのその場編集器は存在しない」
描画側   文書名はヘッダの素の文字であり、
         「この文字は編集できる」という記述も、打たれた字を報せる継ぎ目も無い
```

⭐ **似た 2 つが動いている理由**: **タスク名も行の名前も、主体（選ばれたもの）と'
プロパティ表の行を両方持つので、パネルの道が通る。**
⛔ **文書名はどちらも持たない。**
⚠️ **`FR-091` は先例にならない** —— **あちらがパネルへ差し戻されたのは、
タスクが主体と表の行を両方持つからである。**
