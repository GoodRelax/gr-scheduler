# CR-253 — 開く幅を持たないパネルと、形を持たない端点

> **閉じるもの**: ⛔ **利用者が実物で「タスクをダブルクリックしてもプロパティパネルが出ない」「タスクの端でカーソルが変わらない」と言った。**
> ⭐ **どちらも実測で原因が確定した。** ⛔ **前者は幅が 0 のまま画面の右端に置かれているからであり、後者は形を定める行が無いからである。**

## 0. ⛔ 立ちどまって答える 3 つ

### ① この変更は `CH-` / `GL-` のどれを前へ進めるか

⭐ **`CH-1`（絵の上で直に編集できる）。受ける目標は `GL-004` と `GL-006`。**
⛔ **開かないパネルは `FR-072` の経路をそのまま塞ぎ、形の変わらないカーソルは「そこで何ができるか」を隠す。**

### ② レビュー観点のどの条項を当て、何が出たか

| 条項 | 当てた対象 | 結果 |
|---|---|---|
| **`R1.4`**（欠落が無い）| `S-80` の欄 | ⭐ **同行が自分で「開いたときに取る幅を定める行はまだ無い」と書いている。**⛔ **その理由（「開く経路そのものが `src/` に無い」）は、経路が実装された時点で偽になった** |
| **`R1.4`**（欠落が無い）| 表 T-028 の `IN-2` | ⛔ **形を 3 つしか挙げていない。端点の形はどこにも無い** |
| **`R2.20`**（届く）| ダブルクリック | ⭐ **入力の鎖は 4 段とも通っている。**⛔ **幅 0 の矩形が画面の右端に置かれているだけである** |

### ③ 利用者に問わずに決めたこと（**覆してよい**）

| | 決めたこと | 何に載せたか |
|---|---|---|
| 1 | ⭐ **開いたときの幅は `S-80` ではなく 表 T-206 の新しい行が持つ** | ⛔ **`S-80` は文書に保存される値であり、いま持っているのは「閉じている（0）」という状態である。**⚠️ **開く幅は成果物が持つ既定であって、渡した相手の絵を変えるものではない** |
| 2 | ⚠️ **推奨値は 280px。⛔ 測って決めた値ではない** | ⭐ **可逆コストは 1 セル ＋ 生成である**（規則 06 の分類 `A`）。**印を付けて進め、後から裁定を受ける** |
| 3 | ⭐ **端点の形は横方向の伸縮の合図とする** | ⛔ **発明していない** —— 利用者の裁定が `←‖→` と綴っている。⚠️ **`IN-2` は形の名前を書く行であり、綴りそのものは環境が持つ** |
| 4 | ⛔ **`IN-2` に「何もできない場所」の行は足さない** | ⭐ **同行は「何ができるかを示す」であって、できないことを示す行ではない** |

## 1. 測った

⭐ **実物（`dist/index.html`）で測った。**

| 測ったこと | 実測 |
|---|---|
| ダブルクリック後の `propertiesShowing` | `'selection'` —— ⭐ **開く経路は通っている** |
| そのときのパネルの箱 | ⛔ **1280, 37, 17 × 763** —— **画面の右端に、幅 0 で置かれている** |
| `propertyPanelWidth` の既定 | **0** —— ⭐ **これが「閉じている」である** |
| 幅を 280 にしたとき | ⭐ **1000, 37, 280 × 763。読める形で出た** |
| `src/` で `cursor:` を書いている場所 | **5 か所。すべて画面の道具の上**。⛔ **日程の描画領域には 1 つも無い** |
| `IN-2` が挙げる形 | **3 つ**（範囲選択の合図／握った手／作図の合図）。⛔ **端点は無い** |
| 誘導部分グラフの閉路 | ⛔ **無し** —— `S-80` と `IN-2` は互いを指していない |
