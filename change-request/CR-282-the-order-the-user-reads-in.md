# CR-282 — 利用者が読む順と、ホイールを言えなかった割当

> **閉じるもの**: ⛔ **利用者の指摘 3 件**（`D-105` ヘルプの字と並び順 ／ `D-106` Tips の字 ／ `D-107` Tips にキーが出ない）。
> ⛔ **1 つの変更要求にする理由**: **3 つとも「入口の説明に、何を、どの順で、どの大きさで添えるか」である。**別々に書くと、ヘルプと Tips が同じものを違う形で出す。

## 0. ⛔ 立ちどまって答える 3 つ

### ① この変更は `CH-` / `GL-` のどれを前へ進めるか

⭐ **`GL-006`（マニュアルを読まずに使える）。**⛔ **利用者の逐語**:
「**ヘルプの書式は アイコン 説明 マウス操作/ショートカットキー の順に書け 例: ⇔ 時間軸を拡大 Shift ＋ ホイール**」
「**Tips にショートカットキーも表示しろ**」
