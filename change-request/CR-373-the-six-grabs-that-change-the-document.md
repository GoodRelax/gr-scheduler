## 2. ⛔ 測っていて見つけた別件（本書では閉じない）

⛔⛔ **訂正 2026-09-13 —— 本節は当初「13 通り」と書いていた。実測は 10 であり、うち閉じるべきは 8 である。**
⚠️ **13 は仕分け表を目で数えた数で、`端のぼかし 2 つ` と `フェード 2 つ` を二重に数えていた** —— 同じ 2 行（`GR-1` / `GR-2`）である。⭐ **方法を書かずに散文へ数を置いたのが誤りの形であった。**

⭐ **測り直した方法**: 表 T-023d の 21 行それぞれの行そのものを読み、どのセルにも `FR-nnn` を 1 つも引いていない行を数える。

| | 実測 |
|---|---:|
| 表 T-023d の行 | 21 |
| 行の中で要求を引いている | **11** |
| **引いていない** | **10** |
| うち `GR-10` / `GR-11` は ⛔ 掴んで動かさない（MUST NOT）ので**掴みが無い** | −2 |
| ⇒ **掴めるのに、その結果を定める要求が無い** | **8** |

```
GR-1  フェードイン          GR-2  フェードアウト
GR-3  予定の開始点          GR-4  予定の終了点
GR-6  実績の終了点          GR-13 依存線
GR-14 コメント／ハイライトボックス  GR-15 実績のマイルストーン
```

⛔⛔ **`GR-3` / `GR-4` がここに居ることが、いちばん重い** —— **予定バーの端を掴んで開始日・終了日を変えるという、この道具でもっとも普通の操作**の結果を定める要求が 1 つも無い。⭐ `GR-12`（バー本体）と `GR-5`（実績の開始点）は `FR-011` を引いており、端だけが抜けている。
⚠️ **この測り方は行そのものしか読んでいない** —— 表の下の閉じの散文が名指している可能性は残る。⛔ **次に閉じる者が最初に確かめること。**
⛔ **別 CR として立てるかどうかは、いずれ裁定が要る。**
