# CR-326 — 文書は、行を必ず 1 つ持つ

⭐⭐ **利用者の指示（2026-09-01、逐語）**

> **すべてのタスクグループを削除した時は、自動的に L1 で No name のタスクグループを作れ**

**台帳の行**: `D-175`。⛔ **裁定は下りている。問い直さない。**

---

## 0. ⛔ 立ちどまって答える 3 つ

### ① この変更は `CH-` / `GL-` のどれを前へ進めるか

`GL-003`（1 つの正）。

⛔ **行が 1 つも無い文書では、`Task` がどの行にも載らない。**
⭐ **`FR-004` は行の深さを親から導いており、`TaskGroupMember` が `Task` を行に結ぶ。**
⇒ ⛔ **行が 0 のとき、置いた `Task` は「どこにも載っていない」という、どの表も定めていない状態になる。**

### ② レビュー観点のどの条項を当て、何が出たか

`docs/development-rules/07-review-standards.md` の **`R2`**（規則の在り処が 1 つであること）。

⭐ **「行が 0 になったら作る」を削除の側にだけ書くと、同じ穴が別の経路から開く** ——
**取り込み（`FR-023`）・置き換え（表 T-024a の `OP-3`）・取り消しのやり直しも、行を 0 にしうる。**
⇒ ⭐ **だから規則は「文書は行を必ず 1 つ持つ（MUST）」という**不変条件**として書き、
削除の表はそれを名指すだけにした。**⛔ 経路ごとに書き写さない。**

### ③ 利用者に**問わずに決めた**こと（**覆してよい**）

1. ⭐ **作るのを「削除の一部」とし、取り消し 1 回で元へ戻ることにした。**
   ⛔ **別の 1 手にすると、`Ctrl`＋`Z` を 2 回押さないと消した行が戻らない。**
   **表 T-027 の取り消し対象は操作の単位であり、これは 1 つの操作の結末である。**
2. ⭐ **語は `No name` をそのまま使う** —— **`display-words.json` の `defaultNames` に
   `use: row` として既に在る**（`D-171` が起こした枠）。⛔ **2 つ目を作らない。**
   ⚠️ **日本語モードでも `No name` と綴る**（利用者の裁定 2026-09-01）。
3. ⭐ **作る行は、深さ `L1`・親を持たない・並びの先頭とした。**
   ⛔ **深さは親から導かれるので**（`FR-004`）、**親を持たない行は `L1` にしかなれない。**
   **並びは `order` が持ち、ほかに行が無いのだから先頭のほかに置き場が無い。**
4. ⚠️ **「0 になったら作る」であって「消させない」ではない。**
   ⛔ **最後の 1 行の削除を拒む形にはしなかった** —— **利用者の逐語は「削除した時は…作れ」であり、
   拒むことではない。**⭐ **拒むと、載っている `Task` ごと消す道が無くなる。**

## 1. ⛔ 測った —— いま何が起きるか

出荷ビルドで行を全部消すと、**行が 0 の盤面になる**（利用者の指摘 2026-09-01）。
⭐ **そのうえで `Task` を置く入口は構えたままである。**

仕様の側を引くと、**行が 0 でよいと書いた行も、いけないと書いた行も無い:**

```
表 T-050 の CD-2   行を消すと、その行の Task と配下の行と注記とピン止めが消える
                    ⇒ 最後の 1 行を消したときに何が残るかは書いていない
FR-004             行の深さは親から導く
                    ⇒ 行が 0 のときの Task の居場所は導きようがない
```

⇒ ⛔ **穴は「行 0 を禁じる規則が無いこと」である。**

## 2. ⭐ 書くもの

**表 T-050 の直下に、不変条件を 1 つ足す（MUST）:**

> ⛔⛔ **文書は、`TaskGroup` を必ず 1 つ以上持つこと（MUST）**（利用者の指示 2026-09-01）——
> **`Task` はいずれかの行に載るものであり**（`TaskGroupMember`）、**行が 1 つも無い文書では、
> 置いた `Task` の居場所を定める規則がどこにも無い。**
> ⭐ **ある操作の結果として行が 0 になるときは、その操作の一部として、
> 深さ `L1` の行を 1 つ作ること（MUST）。名前は `FR-038` の辞書の `defaultNames` の
> `row` の語（`No name`）とすること（MUST）。**
> ⛔ **取り消しの単位を分けてはならない（MUST NOT）** —— **消したことと作ったことは 1 つの操作であり、
> `Ctrl`＋`Z` 1 回で消した行が戻ること。**
> ⚠️ **本規則は削除だけのものではない** —— **取り込み（`FR-023`）・置き換え（表 T-024a の `OP-3`）・
> やり直しも行を 0 にしうる。**⛔ **経路ごとに書き写してはならない（MUST NOT）。**
> ⛔ **最後の 1 行の削除を拒んではならない（MUST NOT）** —— **拒むと、その行に載る `Task` ごと
> 消す道が無くなる。**⭐ **消してよく、そのあと空でないことが本規則の求めである。**

⚠️ **`CD-2` は 1 文字も動かさない** —— **同行が定めるのは何が一緒に消えるかであり、
そのあと何が残るかは本規則が持つ。**
