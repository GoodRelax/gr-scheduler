# CR-345 — 目盛が、どの段に何を刷るかを言う

⭐⭐ **利用者の裁定（2026-09-03、逐語）**

> **提案通りに進めよ。**
> **下表に対して、いまは、月の表示が意図と違う不具合があるので直せ。**
> **また、日の表示が出る倍率が大きすぎる。1 画面幅に 2 か月分を 日 で表示できるようにしろ。**
> **ボトルネックは英語の曜日なので幅狭フォントを使うかフォントサイズを縮めて対応せよ。**
>
> ```
> |倍率|1行目  |2行目      |3行目|
> |----|-------|-----------|-----|
> |年  |yyyy   | -         |     |
> |月  |yyyy   |m          | -   |
> |週  |yyyy-mm|d(月曜の日)| -   |
> |日  |yyyy-mm|d          | 曜  |
> ```

**台帳の行**: `D-219`（段の名前が無い）・`D-240`（段の構成と月の表示）・`D-241`（日の段が出る倍率）。

---

## 0. ⛔ 立ちどまって答える 3 つ

### ① この変更は `CH-` / `GL-` のどれを前へ進めるか

`CH-1`（日程が読めること）。⛔ **目盛は日程表で最初に読む所である。**
⚠️ **いま「1 画面に 2 か月を日で」が出せないので、**
**日単位の計画を見るのに何度も横へ送ることになる。**

### ② レビュー観点のどの条項を当て、何が出たか

`docs/development-rules/07-review-standards.md` の **`R2`**（規則の在り処が 1 つ）。

⛔ **当てて出たこと**: **`FR-017` は段の「切り替わり方」を持つが、
各段が何を刷るかを持っていない。**
⚠️ **持っているのは、しきい値の行の備考が語る「年 ＋ 月 ＋ 週」という呼び名だけである** ——
**呼び名は構成ではない。**⇒ **どの段が `yyyy` を出し、どの段が曜日を出すかを、どの行も言っていない。**

### ③ 利用者に**問わずに決めた**こと（**覆してよい**）

1. ⭐ **構成の表は `FR-017` の下に置いた。**⛔ **しきい値の表（`S-83`〜`S-85`）へ足さなかった** ——
   **あちらは「いつ切り替わるか」を持つ表であり、「何を刷るか」は別の問いである。**
2. ⭐ **段の名前は、構成の表の行 ID をそのまま名前として使う。**
   ⛔ **`yearMonthWeek` のような綴りを仕様に持ち込まない** —— **行 ID が既に一意である。**
3. ⭐ **曜日の幅を詰める手は「文字サイズを縮める」を採った。**
   ⛔ **幅狭フォントは採らなかった** —— **`FR-039` が読む人の字を尊重すると定めており、
   フォントの family を道具が差し替えると、その約束と衝突する。**
   ⚠️ **利用者はどちらでもよいと言っている。**⭐ **縮める比は設定値として持つので、後から差し替えられる。**

## 1. ⭐ 実測（この要求の根拠）

```
いまのしきい値      S-83 = 1.4 ／ S-84 = 4.3 ／ S-85 = 26 （px/日）
1 画面に 2 か月     基準環境の幅 1600px（S-81）に 61 日 ⇒ 26.2 px/日 が要る
                    ⛔ いまの S-85 = 26 では、ぎりぎり足りるように見えて足りない
                      —— 行見出しパネル（S-79）が幅を食うので、日程に使えるのは
                        1600 − 200 = 1400px ⇒ 22.9 px/日 しか出ない
⇒ S-85 を 26 から 22 へ下げれば、1 画面に 2 か月が日で入る
```

⚠️ **`S-85` の備考は「導き方」を持っている。**⛔ **下げるときはその導き方も書き直すこと。**

## 2. ⭐ 書くもの

### 2.1 `FR-017` の下に 表 T-238 — 段が何を刷るか（`D-219` ／ `D-240`）

**表の下に置く文**（MUST）:

> ⛔ **各段は本表の行のとおりに刷ること（MUST）。本表に無い行を刷ってはならない（MUST NOT）**

> ⭐ **`RT-3` の 2 行目は、その週の月曜の日を刷ること（MUST）** ——
> **週の始まりは 表 T-201 の週の始まりの行に従う。**
> ⭐ **曜日の語は `FR-038` の辞書が持つ（MUST）。**⛔ **綴りを本表に書かない。**
> ⚠️ **どの段を出すかは `FR-017` が決める。本表は「出すと決まった段が何を刷るか」だけを持つ。**

### 2.3 `FR-039` の隣 — 曜日の字を縮める（`D-241`）

**足す 1 文**（MUST）:

> ⭐ **`RT-4` の 3 行目（曜）は、同じ段の他の行より小さく刷ってよい（MAY）。**
> **比は `_assets/tbl-settings.md` の 表 T-206 の `S-219` が持つこと（MUST）。**
