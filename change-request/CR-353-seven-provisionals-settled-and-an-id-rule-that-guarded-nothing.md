## 0. ⛔ 立ちどまって答える 3 つ

### ① この変更は `CH-` / `GL-` のどれを前へ進めるか

**`CH-5`（単一の `.html` で完結させ、特定の業種にも製品にも依存しない）／`GL-005`。**
⭐ **七つのうち三つ（入れ物の要素・その型・要素 id の形）は、単一 `.html` に予定表を
埋めて取り出す道そのものである。** ⛔ **どれか 1 つでも覆ると、保存済みの `.html` が読めなくなる。**

**`CH-1`（構造化した日程データを出す）** —— **残り四つのうち三つ（取り込んだ行の識別子・
`SaveVersion`・`CurrencyCode`）は、交換相手が読む値である。**

### ② レビュー観点のどの条項を当て、何が出たか

**`R3`**（コーディング品質の境界）—— ⭐⭐ **当てて出たのは、七つのうち六つが「境界を狭く取る」
判断であり、狭さの根拠がそれぞれ外にあることである。**
**公式スキーマの文書（`SaveVersion` の `12` は Project 2007 を指す）、ISO 4217（`XXX`）、
決定性（同じファイルを 2 度取り込んで同じ識別子になること）、再現性（`WY-2` の
「同じ状態の 2 回の書き出しは一致する」）。**⇒ ⛔ **好みに立っている値が 1 つも無い。**

⭐⭐ **`R2.18`（名前と契約）を当てて、七つ目が 1 つだけ違うことが出た** ——
**要素 id の「英字で始まること」だけは、外の根拠を持たない。**
**実測でその出どころが分かった**（本 CR の 1 節）—— **読み手が CSS セレクタを組み立てているからであり、
`CSS.escape()` を通せば消える制約である。**⇒ **禁止が守っているものが無い。**

### ③ 利用者に**問わずに決めた**こと（**覆してよい**）

1. ⛔ **七つの値を `docs/spec` へ書き写さなかった。**
   ⭐ **理由**: **裁定は「いまの値でよい」であって「仕様へ載せよ」ではない。**
   ⚠️ **規則 01 の ③ は「コードを見てもすぐ分からないことは仕様書に書く」と言うので、
   これは緊張を残す判断である。**⭐ **緩衝は、裁定済の行そのものが記録であり、
   検査 25 が印と行の一致を見続けることである。**
2. ⭐ **`CSS.escape()` を使う側の直しを、本 CR の対象に含めた。**
   ⛔ **含めないと「数字始まりを許す」と書いた瞬間に、読み手が例外を投げる。**
   ⇒ **裁定 ⓑ は 2 か所を同時に動かして初めて成り立つ。**
3. ⛔⛔ **制御文字を拒み続けることにした（実装しに行った体が自分で申告した）** ——
   **「割れる文字」だけを拒むと、空白でない C0 制御文字（NUL や `0x01` など）が
   通るようになる。⛔ 古い形は拒んでいた。**
   ⭐ **裁定は「数字始まりを許す」であって「制御文字を許す」ではない。**
   ⚠️ **規則 04 の 3 節が実測を持っている** —— **文字列の鍵に制御文字が 1 つ混じると、
   ブラウザが書き換え、成果物のハッシュが合わなくなってアプリ全体が止まった。**
   ⇒ **受理の境界を、裁定が求めていない側へ緩めない**（規則 06 の `F`）。
4. ⭐ **拒む文字を、いまの正規表現の裏返しではなく「割れる文字」で決めた** ——
   **空白・引用符（`"` `'`）・`<` `>` `&`。**⛔ **これらは開始タグを割って別の要素を作れる。**
   ⚠️ **`.` や `:` は CSS では意味を持つが、`CSS.escape()` が面倒を見るので拒まない。**

## 1. ⭐ 「数字始まりを許さない」の出どころ（**実測 2026-09-05**）

⛔ **禁止は 1 か所の副作用であった。** 要素 id の消費者は 2 つあり、**制約はそれぞれ別である:**

| 誰が | 何をするか | その制約 |
|---|---|---|
| `embedded-html-codec.ts:156` | **入れ物を HTML の文字列へ書き、文字列走査で見つけ直す** | ⭐ **開始タグを割らないこと。**空白・引用符が本物の危険 |
| `single-html-shell.ts:463` | **起動時に読み戻す。⭐ `querySelectorAll` で「ちょうど 1 つ」を数える** | ⛔ **CSS の識別子は数字で始まれない** |

⭐⭐ **数えるために `querySelectorAll` を使っている**（`getElementById` は最初の 1 つしか返さないので
重複を検出できない。`FR-067` の「ちょうど 1 つ」が検査できなくなる）。
⛔ **その結果、`#1foo` は 0 件を返すのではなく例外を投げる。**
⇒ ⭐ **「英字で始まること」は、`FR-067` を守るための制約ではなく、その検査の書き方の制約であった。**

⭐ **`CSS.escape()` を通せば消える** —— **`document.querySelectorAll('#' + CSS.escape(id))` は
数字始まりでも正しく数える。**⚠️ **実装する体が、対象ブラウザで在ることを実測すること。**
