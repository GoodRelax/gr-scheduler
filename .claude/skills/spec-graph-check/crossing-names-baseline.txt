# Known unlisted crossings of check 26b -- names that leave a component folder
# in src/ while table T-064, which calls itself the full count of the names
# callable from outside a component, does not name them.
#
# Measured 2026-08-23 by the audit in
# docs/review/audit-cadence-and-architecture-2026-08-23.md: 226 names cross a
# folder boundary, and 142 of them are in no row of the table. The forward walk
# of check 26b could never see this -- it starts from the table, so it can only
# ever confirm names the table already holds.
#
# A line here is a DEBT, not a permission, and every line has the SAME reason,
# which is why it is written once here instead of 142 times below: the name
# crosses today, the table does not account for it, and nobody has yet decided
# whether the row should be added or the crossing should stop. Closing one means
# DELETING its line, in the same change that adds the row to table T-064 or
# stops the import. The check goes red when a line no longer matches a real
# crossing, so a debt that was paid cannot sit here pretending to still be owed.
#
# ⛔ Adding a line is not a way to make the suite green. A new crossing that is
# in no row is a defect found: it means something outside a component reached
# for a name the specification does not publish.
#

# duplications:
#     <component> | <name>
# Blank lines and lines opening with "#" are ignored.
