# Known restatements of check 70 (provisional) -- hand-written value sets in
# src/ that repeat a set the tree already holds in generated form. Held by
# check-literal-restatement.py.
#
# A line in this file is a DEBT, not a permission. A "restates" record is a
# second copy of a generated set: when the manuscript behind the generated
# set changes, the hand copy does not, and nothing but a reader notices. The
# line says only that the copy was seen, read, and left standing as a unit of
# work of its own, so that a NEW copy cannot hide behind an old one and so
# that the suite can stop green (05-working-method.md section 1).
# A "coincidental" record is a set that shares enough members with a
# generated one to be found, and does a different job; it is held here so the
# check stays quiet about it, and its one line says why it is not a copy.
#
# Closing a "restates" record means DELETING its two lines here, in the same
# change that makes the hand code read the generated set (derive the type
# from it, key a Record over it, or read the generated file). The check goes
# red when a line no longer matches a hit, so a debt that was paid cannot sit
# here pretending to still be owed.
#
# ⛔ THIS FILE MAY ONLY SHRINK WITHOUT THE USER'S OK. Adding a line is not a
# way to make the suite green: a new hit is a new restatement, and the fix is
# to read the generated set instead of writing it again. A new line --
# "restates" or "coincidental" -- needs the user's decision behind it.
#
# FORMAT -- one record is two lines:
#     <hand-written name> | <shape> | <generated set it restates>
#     why: "restates ..." (name the manuscript or table behind the generated
#          set) or "coincidental: ..." (say in one line what job it does
#          instead). ASCII; printed on every run, so keep it readable.
# The key is the NAME of the hand declaration, its shape, and the name of the
# generated set -- never a file or a line -- so a record survives its file
# being split or moved. `--list` prints where each one stands today.
# Blank lines and lines opening with "#" are ignored.
#
# Measured 2026-09-26 on the tree of branch p3/cr-581-duplicate-prevention:
# 19 records, 14 restates and 5 coincidental.
