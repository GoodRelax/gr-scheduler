# Known gaps of check 26b -- members table T-064 publishes that src/ does not
# export yet. Held by check-published-members.py.
#
# A line in this file is a DEBT, not a permission. The member is still missing,
# the table still publishes it, and everything that plans against the table --
# a caller, a test, a change request counting members -- still plans against a
# name nothing answers to. The line says only that the gap was seen, weighed,
# and left standing as a unit of work of its own, so that a NEW gap cannot hide
# behind an old one and so that the suite can stop green (05-working-method.md
# section 1).
#
# Closing a gap means DELETING its two lines here, in the same change that
# writes the member. The check goes red when a line no longer matches a real
# gap, so a debt that was paid cannot sit here pretending to still be owed --
# a stale baseline is its own defect.
#
# Adding a line is not a way to make the suite green. A new gap is a defect
# found: write the member, or bring the line here with the user's decision
# behind it.
#
# FORMAT -- one record is two lines:
#     <row of table T-064> | <component> | <member> | <public entry file>
#     why: one line, ASCII, saying why it is not closed and where the work
#          belongs. It is printed on every green run, so keep it readable.
# Blank lines and lines opening with "#" are ignored.
