# The registry of copy comments in src/ -- held by check-twin-comments.py
# (check 70).
#
# One record per comment in src/**/*.ts that claims the code below it is a
# copy of code elsewhere, or must be kept equal to it ("a copy of X",
# "repeats X", "change both together", "must spell it the same", ...).
#
# A record in this file is a DEBT, not a permission. The copy is still there,
# and nothing but a comment keeps the two sides equal -- five of the records
# below name a twin that is gone, moved or renamed ("stale"), and three copies
# have already drifted from their original. The record says only that the copy
# was seen and weighed, so that a NEW copy comment cannot hide behind an old
# one and so that the suite can stop green (05-working-method.md section 1).
#
# Paying a debt means DELETING its record here in the same change that folds
# the copy (publish the original through its component's public entry --
# a table T-064 row when it is not published yet -- and import it; inside one
# component, fold it into one file). The check goes red when a record's claim
# is no longer found, so a paid debt cannot sit here pretending to be owed.
#
# This file may only SHRINK without the user's OK. Adding a record is not a
# way to make the suite green: a new copy comment is a copy found. Fold it, or
# bring the record here with the user's decision behind it.
#
# FORMAT -- one record is three lines:
#     <sort> | <symbol> :: <first 10 words of the claim>
#     twin: the original the comment names, as src/<path>.ts#<symbol> when it
#           can be located, else in words; "stale -- ..." when the comment
#           names a twin that is gone or renamed
#     why:  one line, ASCII: where the original lives and what stops folding
#           it today. Printed on every run, so keep it readable.
# sort is copy, spec-copy or coupling. The key (after the "|") is never a line
# number or a file path, so it survives a file being split or moved; a key
# changes when the declaration the comment sits on is renamed or the first ten
# words are reworded, and then the record is re-keyed in the same change.
# "stale" is written by hand; a src/<path>.ts#<symbol> twin that is not stale
# and cannot be found prints a NOTE on every run (never a failure).
# Blank lines and lines opening with "#" are ignored.
